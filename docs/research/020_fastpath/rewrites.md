# 研究 020 · 数学等价改写清单

> 每条写：数学依据 · 误差界 · 用在哪 · 状态。收益只填本机实测（`docs/experiments/exp012-fastpath/README.md`），这里不写估计数。
> 「逐位相同」= 每个浮点运算与运算顺序都不变；「误差有界」= 同一个式子，只改求和顺序或用融合乘加（FMA），误差界按标准浮点误差分析给。
> 记号：u = 2⁻²⁴ ≈ 5.96e-8（f32 单位舍入）；K = 一次归约的项数。

## 误差界的通用结论（下面各条引用）

- **E1 换求和顺序**：K 项和顺序求和的误差 ≤ (K−1)·u·Σ|aᵢ|；任意顺序（树形、多累加器）同一个界，树形的界更紧：⌈log₂K⌉·u·Σ|aᵢ|。所以「顺序 → 多累加器」不会让最坏误差变大。
- **E2 乘后加 → FMA**：a·b + c 从两次舍入变一次，误差 ≤ 原来的界。
- 端到端：每个改写都跑 BE-PARITY（与 ORT 逐值比，无一值差 > 1e-3、SNR ≥ 60 dB）；单个算子另有单元测试与原写法比（`gtcrn_native/v2.rs` 的 tests）。

## 考虑过、不做

| 改写 | 不做的原因 |
|---|---|
| LayerNorm 折进全连接 | LN 的均值、方差每帧随输入变，不是常数仿射，折不进去；只有它最后的逐元素仿射已经与「加回残差」合成一遍 |
| Winograd F(2,3) 做 3×3 深度卷积 | 每帧只有 16 通道 × 33 频点 × 9 抽头 ≈ 4.7k 次乘加，Winograd 省乘法、多加法和变换，对 FMA 机器省不了指令；还改变数值 |
| im2col + GEMM 做编码卷积 | exp010 的 native-blas 就是这条，im2col 拷贝本身占时间，Accelerate 每帧分配 11 次；拆两相（#1）不用拷贝成矩阵也能连续读 |
| SME / AMX 矩阵单元 | 调研（怀疑派核实）：对这些十几乘几十的矩阵，进出流式模式的固定开销在微秒级，比算本身还长；Rust 稳定版没有 SME 内建函数 |
| int8 / fp16 | 改变数值，要过听测；超出「等价改写」范围，记为后续候选 |
| 按能量跳过整帧 | RNNoise / DeepFilterNet 的门限只在近乎数字静音时触发（怀疑派读源码核实），正常通话里有底噪不触发；而且改变输出 |
| 换更短的重采样滤波器 | 改变频响，不是等价改写；归重采样选型 |
