1. 读官方 GTCRN 源码与流式版，弄清瓶颈处形状（16 通道 × 33 子带，每 16 ms 一帧）与延迟账（R1）

3. 在真模型上挂钩子数每帧乘加和参数，与官方数字比对（可训练参数总数对上；逐模块未核）
4. 本机单线程测每帧耗时（torch，只看相对、不进结论）；用户端耗时按 020 手写 Rust 版实测 × 乘加比例做情景推算（推断）
