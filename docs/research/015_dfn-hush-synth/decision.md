## 一、DFN 实时版（A 路）

## 二、Hush 与竞争说话人（C 路）

**最大发现：Hush 的「辅助分离头」在发布的训练配置下没有参与训练。** `configs/default.ini:94-95` 是 `mask = spec` → 构造 `MaskSpecLoss`（`training/loss.py:345`），它没有 `erb_mask_compr`；`train.py:738` 的 `hasattr` 判断失败 → `sep_target = None` → 分离损失每步被静默跳过（`loss.py:742`）【源码，大总管已复核】。C 路读 checkpoint：分离头权重全在 ±0.0884（= PyTorch 默认初始化上界 1/√128）以内；实际形状 Linear(128→32)，不是 README 的 256→32。

| 事实 | 数字 | 出处 |
|---|---|---|
| Hush 自己没公布评测，唯一来源是 VoxLock 第三方基准 | Krisp 真实录音 WER 23.21→12.09%（DFN3 13.30%）；**AMI 33.03→33.00%，不如 DFN3 的 26.78%** | 【二手】 |
| 比 DFN3 好的那点只能归功于数据配方 | 60% 样本混背景说话人，SIR 12–24 dB；改过的数据加载器未公开，**不能照仓库复现** | 【源码】 |
| AMI 不改善的推断 | 训练里没有「只有背景人在说」的段：主讲一停，同事成了最响的人被留下；SIR 不覆盖负值 | 【推断】 |
| 新版「更响背景」 | 截至 10-31 未发布（HF 末改 03-31，GitHub 末推 07-18） | 【官方】 |
| 同类工作（已与 005 / 011 去重） | **因果 + 开源 + 真实录音证据 + 覆盖负 SIR 的无注册主讲人模型：一个都没有**。闭源天花板参照：ai-coustics Quail Voice Focus（AMI WER 11.9%）。可借思路：正 / 负注册片段对比 TSE（arXiv 2502.16611），仓库无 LICENSE，代码不能用 | 【论文】【官方】 |

**搬招**：把「训练时辅助头、推理零开销」**只搬进 D47 辅助小模型的训练**，第一个实验必须做「有头 / 无头」消融（Hush 自己恰好是个「无头」的反例）。不加到 GTCRN（违背 D47「主模型不动」，负 SIR 时「最响」标签会教它吃你的字）；不当教师（不如 VoxLock，且有 NC 数据）。

**冷启动组合（C 路建议，待实验）**：同一个辅助模型的「声纹置零」分支按「近讲且最响」判断，**只放开、不收紧**；满足严格条件才自动注册（babble 比你响时不注册）；锁定后以声纹为准。

## 三、合成数据（B 路）—— 给 D47 辅助小模型与 013 RL 环境

**结论：公开配方都不是为「你 vs 邻座」设计的，自己写「两条独立会话时间轴」生成器**（借 Landini 2022 按真实统计排停顿与重叠）。唯一覆盖负 SIR 的公开配方是微软个性化 DNS 合成器（第二说话人 −5~20 dB）。

| 参数 | 建议 | 依据 | 与 013 差异 |
|---|---|---|---|
| SIR | **−6 ~ +20 dB，约 20% ≤ 0 dB**；负 SIR 从课程第一档起就占 ≥ 10% | exp003 邻桌 −5 dB；Hush 12–24 dB 正好避开攻坚格 | 013 未定下限 → 补 |
| 每段重叠率 | 均值 15–25% | 两人电话 10.5–13%、会议 5–20%、晚餐 27.5–33.9%（REAL-T 表 1）；约 40% 换人间隔是重叠（Heldner & Edlund 2010）【论文】 | 013 只写「加重叠段」→ 补数 |
| 插话 | ≥ 30% 的段「你在邻座说话途中开口」 | 词首误关一票否决（V-SIM-GATE） | 新增 |
| 「只有干扰者」段 | ≥ 20% 的帧 | 治 Hush 在 AMI 上的病 | 新增 |
| 附和 / 笑声 | AMI 近讲轨（CC BY 4.0，剔串音） | 朗读语料没有 | 新增，待拍板 |
| WHAMR! 式混响 | T60 分三档 U(0.1,0.3) / U(0.2,0.6) / U(0.4,1.0) s，不是整段均匀抽 | WHAMR! 论文【论文】 | exp006 是 0.08–1.6 s 均匀 → 可并存 |

**两套生成器（013「训练 / 裁判分开」的具体选型）**

| | RIR | 噪声（许可） |
|---|---|---|
| 训练 | 自写 RIR（exp006）+ FRA-RIR（Apache-2.0） | MUSAN、FSD50K 中 CC0 / CC BY 片段、DNS5 的 Freesound CC0 部分 |
| 裁判 | **pyroomacoustics（MIT）** + 实测 RIR（dEchorate、METU，CC BY 4.0） | WHAM!、DEMAND、TAU（只评测） |

gpuRIR 是 AGPL-3.0，能不用就不用。**新发现冲突**：DEMAND 在 DNS README 写 CC BY-SA 3.0，Zenodo 现标 CC BY 4.0 → 复核前按更严的处理。

**sim-to-real**：PVAD 类模型「合成训、真实测」掉多少**没有公开数字**（空白）。最近的替代证据：EEND 只把合成数据的时间结构改像真实会话，CALLHOME DER 15.09%→8.64%，接近真实微调的 8.44%【论文】——**时间结构比声学更值钱**，这正是「两条会话时间轴」生成器的理由。

**接 RL**：只有「门控开关序列」不可微、需要 RL；逐帧概率用监督学习。奖励 = −(w₁·V-SIM-GATE + w₂·V-SIM-FA + w₃·max(0, V-SIM-SWLAT − 300 ms))，词首 200 ms 误关一票否决；监督损失留作锚点；顺序照 013 §4.4（先黑盒调门控参数，平台期后才上策略梯度）。课程学习证据薄、方向不一（TSE 约 +1 dB；噪声 ASR 反课程更好）→ 当可选超参数 A/B。
