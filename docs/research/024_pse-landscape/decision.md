# 结论卡 · 个性化降噪（先认人再提取）：有没有人做过 · 为什么难 · 我们怎么走

> 2026-11-04 · 手下 pse · 依 D83。只读调研，**没下权重、没跑模型**；所有效果数字是作者自测，除非注明。出处见 `sources.md`，原始笔记见 `notes/`。

## 一句话

**做过，但没人把整套开源出来。** Zoom、Teams 已在会中自动采你的声纹、再只留你的声音，但都闭源。开源里最接近的是 Alkove Focus：它从 GTCRN 改来，约 80 万参数，Apache-2.0。它在 M1 Max 上每 10 ms 约 0.56 ms，在预算内；但它要外部给声纹，且只有厂商自测。最难的是**旁人比你响**：微软的纯音频个性化模型此时只有 6.25% 选对人。建议先花约半天测 Alkove，再在 GTCRN 上自训（建议，待你定）。

**没人做到的组合**：开源 + 因果 + 预算内 + 会中自动注册 + 第三方验证。研究界也**没有完整的冷启动方案**，即从零开始、在线锁定、并防锁错（笔记 03）。

## 为什么难

| 难点 | 难在哪（机理） | 已知解法 · 出处 | 仍未解决 |
|---|---|---|---|
| ① 同时说话分不干净 | 小模型看不到未来，同性别、声音相近时线索少 | 说话人多样性比架构重要（REAL-T）；FiLM 注入（TF-MLPNet 50.9 万参数，SI-SDR 12.37 dB） | 没有公开的「参数量 × 旁人响度」曲线 |
| ② 误删你本人 | 声纹有波动，一时认不出就整段删；多删与漏旁人此消彼长 | 非对称损失 + 识别多任务（pDCCRN 学生 TSOS 14.61 → 0.60 s）| 纯音频因果模型的长时误删没有公认解法；pDNSMOS 量不出误删 |
| ③ 锁错人 / 声纹被污染 | 流式系统倾向锁「最先 / 最近」出现的人（NVIDIA 2506.22646）；「取最响 3 s」会选中电视 | 初始注册作锚点 + 相似度 > 0.5 才入库（EvoTSE）；只用稳定帧更新；本项目 exp005 注册器（合成 8 段 0 锁错） | 冷启动在线锁定没有论文方案；真实录音上没测过 |
| ④ 旁人比你响时提错人 | 条件模型跟住响的那个 | 训练时 35% 故意给错声纹、38% 样本你不在场（CARTSE，赛道第一）；伪说话人增广（提错 2.35 → 1.10%） | **AV-PVQE：干净注册下，目标更小声时只有 6.25% 选对**；纯音频无解，靠视频才降到 1.6% |
| ⑤ 声纹漂移 | 噪声、远场、换麦、情绪改变嵌入 | 在线细化声纹（2601.16235，但每秒多 44 MMAC，比 GTCRN 全模型还大）| 噪声 −20 dB 时 ECAPA 等错误率 31.86%；感冒无公开数据 |
| ⑥ 训练数据 | 公开合成集几乎全程重叠，和真实会议时间结构不同；好的真实会议语料多为 BY-SA 或非商用 | 真实会议 + 非因果教师伪标签（CARTSE、PS4：TER 0.83 → 0.64）；Libri2Vox 配方 | 缺许可干净、有会话结构、有干净参考的大训练集 |
| ⑦ 评测 | 真实会议录音里你的干净声音物理上拿不到 | REAL-T：有注册、无参考，量错字率 + 声纹相似度（CC BY-SA）；合成三轨量 TSOS 与提错人 | **没有公开集同时有「真实会议 + 同时说话 + 干净参考」** |
| ⑧ 学术界不放权重 | 找不到明说的理由 | — | 【推断】训练数据含非商用 / LDC；企业资产；可被用于定向监听；挑战赛不强制开源 |

## 小模型能到哪

- ≤ 100 万参数、因果、有数字的最好结果有两个，规模在 50–80 万参数，都是作者自测：
  - TF-MLPNet：50.9 万参数，两人混合 SI-SDR 12.37 dB
  - Alkove Focus：约 80 万参数，同响旁人时 SI-SDR 7.1 dB
- GTCRN 本身约 4.8 万参数。
  - 只加一层 FiLM 声纹注入：估计 5.4–7 万参数，计算量多不到 5%【推断，笔记 05】
  - 能分开同时说话的规模：现有证据都在 50–80 万参数，比 GTCRN 大 10–16 倍
  - **5 万量级有没有用：尚无判据，待测**
- 小模型更该个性化：同架构下，13.9 万参数个性化多 +1.0 dB，100 万参数时约为 0（Sivaraman 2021）。

## 我们怎么走（建议，待你定）

1. **先测现成的（约半天，要名额）**：下 Alkove Focus 和它的声纹模型（共约几 MB），在 M5 上计时。在 exp005 合成集上，按旁人响度分档量三样：提错人比例、TSOS、旁人残留。它和 GTCRN 都用 16 ms 步长，可能可直接复用共用频谱前端【推断，未核】。
2. **自训**：在 GTCRN 上加 FiLM 声纹条件，规模扫 5 万 / 20 万 / 80 万。数据按难点 ④⑥ 配：
   - 旁人比你响的样本要多，SIR 覆盖到 −10 dB
   - 约 35% 样本故意给错声纹（训练「目标不在场」）
   - 说话人要多（几千人）
   - 真实会议数据只用 CC BY 4.0 的（AMI、NOTSOFAR）
3. **自动注册**：沿用 exp005 注册器，加两条：
   - 初始声纹永久作锚点（EvoTSE）
   - 锁定前退回普通降噪，不用「留最响的人」（voice-isolator 的教训）
4. **评测**：合成三轨按旁人响度分档，量提错人比例与 TSOS；真实集用 REAL-T 量错字率与声纹相似度。门控类评分项要改成量「提取」，交评测线（5-app-5e）。

现有 verifier 都量门控，没有量「提取」的：**尚无判据，待测**。
