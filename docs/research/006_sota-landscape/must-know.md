## 四、我的预判（让调研去推翻）

| 我怀疑 | 请核实 |
|---|---|
| 专业工具（RX、CEDAR、Krisp）几乎不公开原理，开源界没有「实时」逼近它们的证据，只有离线 | 找官方页、论文、专利；找有 AB / MOS 的开源对比 |
| 2025–26 的新因果模型（Mamba / xLSTM 一类）在 ≤ 2 ms/帧 下没明显赢过 DPDFNet 一档 | 找参数、MACs、低 SNR / babble 数字 |
| 生成式（扩散 / 流匹配 / token LM）在因果实时下还不可行 | 找因果生成式 SE 的延迟与算力 |
| 榜单里 VoiceBank 已饱和，DNS 停在 2023，URGENT 是现在唯一还能信的大榜，但获胜系统都不能实时 | 核排名与获胜系统复杂度 |
| 没人公开量过「开着降噪一小时掉多少电」；ANE 对 10 ms 小帧不划算 | 找 powermetrics / 官方数字 |
| 衰减下限、快开慢关、部分去混响这类工程细节，论文给了方法但开源实现很少 | 每条找最好的公开做法 |
