## 一、这件事上，我不可妥协的是哪几条

| # | 不可妥协的 | 为什么它是命门 | 怎么算满足 |
|---|---|---|---|
| 1 | **本机离线跑，不上传音频；Apple Silicon 上能跑** | 意向书「不做什么」第一条：不联网处理、不上传、不存录音。评测集里会有作者本人在咖啡馆的真实会议录音，不能送进云端 API。评测要每次改动都跑，云端排队也撑不起飞轮 | 原生：权重可下载到本机，arm64 macOS 上 CPU 或 MPS/Metal 能跑，不需要 CUDA、不调用网络服务。部分：只能在 x86 或 CUDA 上跑，或需要 Rosetta / Docker。没有：只提供在线 API |
| 2 | **许可证允许我们开源评测工具；数据许可证不妨碍发布微调后的权重** | 项目是开源的，评测脚本要进仓、进 CI；`.42cog/intent.md`「不做什么」允许以后针对性微调，用 NC（非商用）数据训出来的权重能不能被别人商用，会被数据许可证卡住（设计稿 §12「注意许可证」） | 原生：代码和模型权重都是 MIT / Apache / BSD / CC-BY 一类宽松许可，数据是 CC-BY / CC0 / Apache。部分：代码宽松但权重或数据是 NC / 研究用途，**只能用于评测、不进训练集**。没有：GPL 传染到我们的发布物，或许可证不明 |
