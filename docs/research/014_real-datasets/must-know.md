# 决策点 · 选哪几个真实录音公开数据集做真实回归与 sim-to-real 校准

> 2026-10-31 · 手下 datasets 起草。人的原话：「这个实际上的东西或者真实效果的东西，帮我找公开数据集」。
> 背景：013 定「真实录音只做回放回归、永不进训练」+ 1.3 sim-to-real 校准；012 定「客观分都没在 DNN 降噪上验证，人耳是最终裁判」。攻坚场景 D42（笔记本内置麦 + 咖啡馆 / 开放空间一大片人）、D47（你和邻座同时说话）。

## 我要作的决定

**真实回归集首选哪 3–5 个公开数据集**（各管什么用、怎么拿、多大），并说清它们怎么接 013 的 sim-to-real 校准和 012 的 verifier 定标。

## 一、不可妥协的

| # | 不可妥协的 | 为什么是命门 | 怎么算满足（有 / 部分 / 没有） |
|---|---|---|---|
| 1 | **真实设备、真实声场录的**，不是合成混音 | 合成混音就是我们自己的模拟器，拿它校准等于自证 | 有 = 全部真实录音；部分 = 真实噪声 / 真实 RIR 但人工混合，或回放重录；没有 = 纯合成 |
| 2 | **有可对齐的参考**：近讲 / 头戴麦同步录音，或人工转写（含时间戳、说话人标签） | 没参考就只能靠无参考 MOS，而 012 已证它们在 DNN 降噪上不可信；有转写才能算吃字（V-EAT-ASR），有近讲才能分「你 / 别人」 | 有 = 近讲同步 + 转写；部分 = 只有其一；没有 = 两者皆无 |
| 3 | **许可允许我们这样用，且本人能拿到** | D26：SA / NC 只评测不训练；需签协议 / LDC 付费的要人拍板；拿不到的再贴近也白搭 | 写明：可训练 / 只评测 / 不可再分发；直接下载 / 注册 / 签协议 / 付费 |

接近度另打分（不是命门，用来排序）：①设备麦（笔记本 > 会议阵列 / 眼镜 > 远场专业麦）②嘈杂多人（咖啡馆 / 餐厅 / 晚餐 > 会议室 > 安静房间）③近距离干扰人声与重叠（D47）④语言（中英各至少一个）。

## 二、知道了它们，我要作的是哪一个决定

按「接近度 × 参考可用性 × 许可可得性」排出首选 3–5 个，定每个的用途：sim-to-real 校准 / 真实回归集 / 人耳听测素材 / 训练（只有许可干净的才可能）。

## 三、看起来相关，但知道了也不改变这个决定

- 各数据集上的 ASR / 分离 SOTA 排行、挑战赛名次
- 纯合成集（WHAM!、LibriMix、DNS 合成训练集）——命门 1 直接出局，只在备注里提一句
- 只有干净朗读的语料（LibriSpeech、AISHELL-1）——那是模拟器原料，013 已登记
- 视频 / 唇读部分（MISP、EasyCom 的视频）——我们只用音频
- 情感、说话人识别类集合（VoxCeleb、CN-Celeb）——除非能当「真实嘈杂设备麦」素材
