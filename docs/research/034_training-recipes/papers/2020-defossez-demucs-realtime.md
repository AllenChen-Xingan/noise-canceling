## 模型与参数量
- 波形进、波形出的 U-Net：L 层卷积编码器 + LSTM + L 层转置卷积解码器，带跳连（p.1–2 图 1）。
- 每层编码器：Conv1d(K, S) + ReLU + 1×1 卷积 + GLU（p.2）。
- 中间：2 层 LSTM，隐藏 2^(L−1)H；因果用单向，残差连接 R(z)=LSTM(z)+z（p.2）。
- 输入先用 sinc 插值上采样 U 倍，输出再降回（p.2）。
- 因果版：U=4, S=4, K=8, L=5, H=48 或 64；帧长 37 ms，帧移 16 ms（p.3）。
- 流式时加 3 ms 前瞻，总帧长 40 ms（p.3）。
- 输入除以标准差归一，输出乘回；流式时用累积标准差（p.3）。
- 参数量：文中未写。

## 训练数据与混音做法
- 两套数据：Valentini（400 epoch）与 DNS 2020（250 epoch），16 kHz（p.3）。
- 增强（p.3）：
  - 随机平移：0 到 S 秒，所有数据都用。
  - Remix：批内打乱噪声，重组含噪混合。只用于 Valentini。
  - BandMask：带阻滤波，按梅尔刻度均匀去掉 20% 频率。只用于 Valentini。
  - Revecho：给混合加 N 个衰减回声。初始增益 λ∈[0, 0.3]，早期延迟 τ∈[10, 30] ms，RT60∈[0.3, 1.3] s，均匀抽样。只用于 DNS。
- DNS 上比较了混响目标的几种处理（p.3 表 2）：去混响、保留、保留 10%、语音噪声用不同抖动（「两个声源」）。

## 损失
- 波形 L1 + 多分辨率 STFT 损失（p.2 式 1–2）。
- STFT 损失 = 谱收敛 + 对数幅度 L1，同 Parallel WaveGAN。
- 三组：FFT {512, 1024, 2048}，帧移 {50, 120, 240}，窗长 {240, 600, 1200}（p.2）。
- STFT 项权重 0.5，且只在 Valentini 上加；DNS 上只用 L1（p.3）。

## 优化器、学习率、批量、步数
- Adam，学习率 3e-4，β1=0.9，β2=0.999（p.3）。
- Valentini 用原验证集保留最好模型；DNS 不用验证集，保留最后一个（p.3）。
- 批量大小：文中未写。
- 初始化用 He 等人方案（p.2）。

## 评测方法与主要数字
- 客观：宽带 PESQ、STOI、CSIG、CBAK、COVL；主观：P.835 众包 MOS，100 句 × 15 人（p.2–3）。
- Valentini 测试集（p.3 表 1）：
  - 含噪 PESQ 1.97，STOI 91.5。
  - 非因果 DEMUCS（H=64）：PESQ 3.07，STOI 95。
  - 因果 H=48：PESQ 2.93；因果 H=64：2.91。
  - 因果 DeepMMSE：2.77。
- dry/wet 旋钮：输出 dry·x + (1−dry)·ŷ（p.3）。
  - dry=0.05：PESQ 2.91→2.88，但 MOS OVL 3.39→3.72（p.3 表 1）。
  - dry=0.1：PESQ 2.81，MOS SIG 最高 4.18，OVL 3.60。
  - 作者：漏一点原声（5%）提高整体感知质量（p.3）。
- DNS 盲测 OVL MOS（p.3 表 2，每类 100 句）：
  - 真实录音：含噪 2.6，去混响 3.2，「保留 10% + 两个声源」3.5（最好）。
  - 人工混响类：去混响只有 2.6，保留 10% 有 3.3。
- ASR（p.4 表 4）：SNR 0 dB 时 dev-clean WER 12.0→6.9。

## 消融里哪些做法真有效（带数字）
Valentini，因果 H=64，PESQ / STOI，单次训练（p.4 表 3）：
- 完整：2.91 / 95
- 去 BandMask：2.87 / 95（−0.04）
- 再去 Remix：2.86 / 95（−0.01）
- 再去 STFT 损失：2.68 / 94（−0.18）
- 再去随机平移：2.38 / 93（−0.30）
- 作者结论：STFT 损失与时间平移贡献最大；Remix 贡献很小（p.4）。
- 注意这是逐级累加去掉，各项贡献不是独立测的。

## 对 GTCRN 加训：能借什么（【推断】）
- 多分辨率 STFT 作为辅助项，在 16 kHz 降噪上直接可用；本文的消融是降噪任务上的证据（+0.18 PESQ）。
  但本文模型输出波形，基础损失是波形 L1；GTCRN 已有频域压缩损失，增益未必一样大。
- 随机平移极便宜，且本文增益最大（+0.30）。我们若按固定帧网格切片，值得加。
- 「保留少量混响、语音与噪声分开抖动」让真实录音 MOS 从 3.2 升到 3.5：
  对真实麦克风场景，目标不必完全去混响。
- dry/wet 混一点原声：几乎零成本，可用于缓解「停顿时背景不稳」的听感。但它是推理时旋钮，不是训练做法。

## 对 GTCRN 加训：不能借什么 / 要小心（【推断】）
- 随机平移的大收益可能部分来自波形模型的平移不变性问题；GTCRN 是 STFT 模型，收益可能小。
- DNS 上没用验证集、取最后模型；我们按已定流程仍应留开发份评估。
- BandMask 按 20% 梅尔带阻，可能和「字头」高频辅音冲突，用前要先测。
- MOS 每类只有 100 句，表 2 差值 0.1–0.3，置信区间文中未给。
