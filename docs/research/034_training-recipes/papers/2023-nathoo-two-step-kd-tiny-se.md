# 小模型降噪的两步蒸馏（Two-Step Knowledge Distillation for Tiny Speech Enhancement）

## 模型与参数量
- 老师、学生都是 CRUSE 结构（卷积 + 分组 GRU 的 U-Net）（p.2）。
- 输入：STFT 512/256 点，80 个 Mel 带，0.3 次方压缩（p.2）。
- 输出：0–1 实数掩码，用带噪相位重建（p.2）。
- 因果：因果卷积 + 因果累积层归一，算法延迟 32 ms（p.2）。
- 老师 1.9M 参数，13.34 MOps/帧（p.2）。
- 默认学生 62k 参数（老师的 3.3%），0.84 MOps/帧（p.2）。
- 另测 30k / 240k / 350k 三档学生（p.4 表 4）。

## 训练数据与混音做法
- 数据：DNS 2020 挑战赛，500+ 小时干净语音、100+ 小时噪声，16 kHz（p.3）。
- SNR 在 −5 到 15 dB 均匀抽（p.3）。
- SNR 用响度（LUFS）算，为了贴近感知、压低冲击噪声的影响（p.3）。
- 片段 2 秒（p.3）。
- 混响、电平随机、均衡：文中未写。

## 损失
- 监督项：相位敏感谱近似 PSA，以干净语音为目标（p.3）。
- 蒸馏项三类：输出对输出；层内相似度矩阵；层间「流」矩阵（p.2–3）。
- 层内相似度：每层激活在批内两两求内积，得 b×b 矩阵（p.2 式 1）。
- 本文细化到每个 (时间, 频率) 格各算一个，记 Gtf（p.2）。
- 好处：师生通道数不同也能比，不用对齐维度（p.2）。
- 总损失 L = γ·蒸馏 + (1−γ)·PSA，单步法 γ = 0.5（p.3 式 3）。
- 两步法：第一步 γ = 1 只蒸馏；第二步 γ = 0 只监督（p.3）。

## 优化器、学习率、批量、步数
- Adam，学习率 6e-5（p.3）。
- 每步 32 条 × 2 秒；每轮 5000 步（p.3）。
- 学生共 400 轮 = 2M 步，约 35.5k 小时音频（p.3）。
- 第一步预训练占其中 100 轮（p.3）。
- 老师训到收敛（p.3）。学习率调度、梯度裁剪：文中未写。

## 评测方法与主要数字
- 测试集：DNS 2020 无混响评测集 150 条（p.3）。
- 指标：SDR、宽带 PESQ、eSTOI、DNSMOS P.835，全部报相对带噪的提升（p.3）。
- 纯学生 ΔSDR 6.34 dB；老师 8.65 dB（p.3 表 1）。
- 两步法（Gtf 预训练 → 纯 PSA）ΔSDR 6.77、ΔPESQ 0.81、ΔeSTOI 6.38%（p.3 表 2）。
- 低 SNR 收益更大：−5 dB 时 ΔSDR 10.82 → 11.73（p.4 表 3）。
- 5 dB 时只 7.97 → 8.43（p.4 表 3）。
- 学生越小收益越大：30k 学生 ΔSDR 4.42 → 5.52（p.4 表 4）。
- 350k 学生只 7.51 → 7.54，收益趋平（p.4 表 4）。
- 摘要说 −5 dB 收益 0.9 dB、63× 压缩收益 1.1 dB（p.1）。
- 每格只有一次训练，未报方差或显著性检验（全文未见）。

## 消融里哪些做法真有效（带数字）
- 单步法里，输出蒸馏 ΔSDR 6.35、整体相似度 G 6.32，几乎无益（p.3 表 1）。
- 单步法 Gtf 最好：6.68，比纯学生 +0.34 dB（p.3 表 1）。
- 两步法 Gtf → 纯 PSA：6.77，比纯学生 +0.44 dB（p.3 表 2）。
- Gtf → 继续 Gtf 混合：6.75，与纯 PSA 相当（p.3 表 2）。
- 用按时间的层间流矩阵预训练反而略差：6.46（p.3 表 2）。
- 相似度分析（CKA）：预训练后对角相似 0.46 → 0.73；转监督后回落到 0.65（p.4 图 2）。
- 作者解读：先像老师，再自己找解（p.4）。
- DNSMOS SIG 各组都在 −0.04 到 +0.06 之间，蒸馏不改善语音失真（p.3 表 1–2）。

## 对 GTCRN 加训：能借什么（【推断】）
- 【推断】GTCRN 4.8 万参数，落在本文「收益最大」的 30k–62k 区间。
- 【推断】「先只蒸馏、再纯监督」可作一组对照，老师可用 DeepFilterNet3 类大模型。
- 【推断】Gtf 只要求同一批输入，不要求结构相同，可接 GTCRN 的中间层。
- 【推断】低 SNR 是我们弱场景之一；本文 −5 dB 收益最大，值得先测这一档。
- 【推断】LUFS 定 SNR 可借，能减少冲击噪声把 SNR 拉偏。

## 对 GTCRN 加训：不能借什么 / 要小心（【推断】）
- 本文是从零训学生，不是对已训好的模型微调（p.3）。【推断】对 GTCRN 微调未必有同样收益。
- 第一步不用干净目标，会先把学生推离原解。【推断】对已训好的 GTCRN 有遗忘风险，需配回放或 L2-SP。
- 收益只有 0.4–1 dB 量级，且单次训练、无方差（p.3–4）。【推断】需多种子复跑才能判。
- 训练量 2M 步、35.5k 小时（p.3）。【推断】云上加训预算远小于此，收益可能缩水。
- 老师和学生同是 CRUSE、同一数据（p.2）。【推断】换不同结构的老师，Gtf 层对应关系要另定。
- 无混响、真实录音测试（p.3）。【推断】对字头、停顿背景稳定的效果无证据。
