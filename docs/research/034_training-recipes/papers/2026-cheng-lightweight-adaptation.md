## 模型与参数量
- 两个底座。GRU 网络：输入 FC 128 → 2 层 GRU（128）→ 输出 FC 128（p.2 §4.1）。
- GRU 网络输入：128 个 ERB 带的压缩幅度谱，压缩 0.3；帧长 512、跳 256（p.3 §4.1）。
- GRU 网络输出：128 维 ERB 掩码，sigmoid 限到 [0,1]（p.3）。
- GRU 网络：230.14 k 参数，16.80 M MAC/s（p.3）。
- DPRNN 网络：STFT 帧长 320、跳 160；复掩码 tanh；4 个双路块，通道 32（p.3）。
- DPRNN 网络：89.25 k 参数，1503.32 M MAC/s（p.3）。
- 适配器：LoRA，W = W0 + β·B·A，底座冻结（p.2 式 7）。
- GRU 网络只在输入、输出 FC 上加 LoRA，秩 1、缩放 64，共 512 个可训参数（0.22%）（p.3、p.3 表 1）。
- DPRNN 网络在所有 FC 上加 LoRA，秩 1、缩放 8，共 708 个（0.79%）（p.3、p.3 表 1）。

## 训练数据与混音做法
- 底座训练：DNS Challenge 数据，760.5 小时干净语音，6,000+ 说话人（p.3 §4.2）。
- 噪声 65,000+ 段，150+ 类；全部 16 kHz；在线混音，SNR 均匀取 [-5, 20] dB（p.3 §4.2）。
- 自适应与测试：WSJ0 语音 + WHAM! 评测集噪声（咖啡馆、餐厅、酒吧、办公楼、公园）（p.3 §4.2）。
- 同一天同一地点录的噪声算一个场景；自适应与测试用不同片段（p.3–4）。
- 37 个噪声场景 × 3 档 SNR（[-8,0]、[0,5]、[5,10] dB）= 111 个测试场景（p.4）。
- 每场景 2–5 个说话人；测试每场景 20 条，共 2,220 对（p.4）。
- 自适应输入：老师（冻结原模型）先出伪干净 x̂，再混同场景噪声，SNR 取 [-5,5] dB（p.2 §3.1、p.4）。
- 语音与噪声都切 2 s 段后再混（p.4）。

## 损失
- 底座训练：估计谱与目标谱的 MSE（p.4 §4.3）。
- 自适应：逆 SNR（inverse SNR）作损失，目标是老师输出 x̂（p.4 §4.3）。

## 优化器、学习率、批量、步数
- 底座：Adam，初始学习率 1e-3；训练损失连续 2 个 epoch 不降就 ×0.1（p.4 §4.3）。
- 底座：批量 8，100 个 epoch（p.4 §4.3）。
- 自适应：Adam 固定学习率，GRU 1e-3、DPRNN 5e-4（p.4 §4.3）。
- 自适应：批量 24，每场景最多 20 步，共 240 条、480 秒音频（p.4 §4.3）。

## 评测方法与主要数字
- 指标：PESQ、STOI、SI-SDR（p.4 §5.1）。
- 两种设定：各场景独立从底座起（隔离）；111 场景随机排序连续适配（顺序）（p.4 §5.1）。
- 对照：RemixIT，需更新全部参数（GRU 230,144 个）（p.3 表 1）。
- GRU，[0,5] dB 隔离：本法 PESQ 1.44 / SI-SDR 8.36，RemixIT 1.39 / 8.27（p.3 表 1）。
- GRU，[5,10] dB 顺序：本法 PESQ 1.72 / STOI 91.64，RemixIT 1.51 / 88.63（p.3 表 1）。
- 同档底座：PESQ 1.57 / STOI 90.99；即 RemixIT 顺序适配后低于底座（p.3 表 1）。
- DPRNN 顺序，[-8,0] dB：两法 PESQ 都是 1.27；本法 SI-SDR 5.85，RemixIT 5.82（p.3 表 1）。
- 摘要：平均 SI-SDR 提升 1.51 dB，每场景 20 步（p.1）。
- 图 1：RemixIT 前几步涨得快，之后来回震荡；本法单调上升（p.3 图 1、p.4）。

## 消融里哪些做法真有效（带数字）
- 秩与缩放（GRU，全部场景平均）（p.4 表 2）：
- 底座：PESQ 1.36、SI-SDR 6.75。
- 秩 16/32/64、缩放 1：SI-SDR 7.85 / 7.91 / 8.03，参数 8,192–32,768。
- 秩 1、缩放 32/64/128：SI-SDR 8.04 / 8.17 / 8.14，参数都只 512。
- 结论：秩 1 配大缩放（64）最省且最好（p.4 §5.2）。
- 顺序设定下全参更新会累积漂移，变差；冻结底座 + 适配器不退化（p.4 §5.1、表 1 蓝色项）。
- 注意：无「全参微调 + 正则」对照，也无 LoRA vs 全参在同损失下的直接对比。

## 对 GTCRN 加训：能借什么（【推断】）
- 【推断】「冻结底座 + 很小的适配器」是防遗忘的强基线，可作 L2-SP 方案的对照组。
- 【推断】对比「全参连续更新会漂移」的证据，支持我们对全参微调加 L2-SP / 老师一致性。
- 【推断】「原模型出伪目标 + 再混噪声」可用于本机真实录音，无需干净参考。
- 【推断】GRU 网络帧长 512 / 跳 256、ERB 压缩 0.3，与 GTCRN 接近，数量级可参考。
- 【推断】评测分 3 档 SNR 报数，可照搬到我们的低 SNR 场景。

## 对 GTCRN 加训：不能借什么 / 要小心（【推断】）
- 【推断】本文是部署后在线自适应，每场景 20 步；我们是离线加训，目标不同。
- 【推断】伪目标来自原模型，上限受原模型限；原模型吞字头，伪目标也会吞。
- 【推断】GTCRN 只有 4.8 万参数，几乎没有大 FC 层；LoRA 能加在哪要另查。
- 【推断】数字为合成 WHAM! 场景，无真实录音、无主观听测。
- 【推断】本法提升幅度小（PESQ +0.0 到 +0.15），不能当大幅补弱的手段。
