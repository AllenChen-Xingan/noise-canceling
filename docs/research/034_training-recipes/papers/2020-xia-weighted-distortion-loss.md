## 模型与参数量
- 3 层 GRU + sigmoid 全连接，单帧进、单帧出幅度增益；不用卷积（p.2）。
- 因果，用带噪相位重建（p.2）。
- 参数 1.26M（p.4 表 3）。
- STFT：32 ms 汉明窗，75% 重叠（跳 8 ms），512 点（p.2）。
- 特征：幅度或对数功率谱，按频率在线均值方差归一，τ = 3 秒（p.2 式 7–9）。

## 训练数据与混音做法
- MS-SNSD 合成：训练 84 小时干净语音 + 84 小时噪声，14 类噪声（p.3）。
- 测试 18 小时（5500 条），9 类训练中没见过的噪声，含咀嚼、多人嘈杂、键盘（p.3）。
- 每条语音先按句做电平归一（p.3）。
- 噪声缩放到 40/30/20/10/0 dB 五档 SNR 之一（p.3）。
- 训练时随机截取语音与噪声片段再混（p.3）。

## 损失
- 基线：干净与增强幅度的 MSE（p.2 式 4）。
- 拆两项：语音失真项只在有声帧上算 |S − G·S|²；降噪项算 |G·N|²（p.2 式 10–11）。
- 有声帧判法：对干净语音 300–5000 Hz 能量 3 帧平滑，高于整句峰值 −30 dB 即有声（p.2）。
- 固定加权：L = α·语音项 + (1 − α)·降噪项（p.2 式 12）。
- SNR 加权：α = SNR / (SNR + β)，按每句全局 SNR 变（p.3 式 13）。

## 评测方法与主要数字
- 客观：PESQ、STOI、倒谱距离 CD、SI-SDR（p.3）。
- 主观：众包，每条 20 人评 1–5 分，剔除总打同一分的人（p.3）。
- 本文 α = 0.35：SI-SDR 14.3 dB，PESQ 2.65，STOI 90.7%（p.4 表 3）。
- 对照 RNNoise257（2.64M 参数，纯 MSE）：SI-SDR 13.0，PESQ 2.56（p.4 表 3）。
- 主观 MOS：带噪 2.63，改进版 RNNoise 3.26，本文 α = 0.05 为 3.93 ± 0.03（p.4 表 2）。

## 消融里哪些做法真有效（带数字）
- 训练片段长度：1 秒 SI-SDR 13.7、PESQ 2.58；10 秒 14.1、2.64；20 秒 14.0、2.64（p.3 表 1）。
- 作者建议片段不少于 5 秒（p.4）。
- 归一化：各种归一差别小，不归一会变差（p.4，未给数字）。
- 客观最优 α：STOI 与 CD 都在 α = 0.65；PESQ 与 SI-SDR 偏好更小 α（p.4 图 3）。
- SNR 加权最优 β 约 20 dB；固定加权在所有指标上略好于 SNR 加权（p.4）。
- 主观 MOS 随 α 增大而降：0.05 → 3.93；0.1 → 3.92；0.2 → 3.74；0.3 → 3.65（p.4 表 2）。
- 客观指标与作者本人偏好（α ≈ 0.35）都没预测到这一趋势（p.4）。
- α < 0.35 时作者听到明显语音失真（p.4）。
- 纯 MSE 与加权损失客观分相近，但主观差很多（p.4）。

## 对 GTCRN 加训：能借什么（【推断】）
- 【推断】「语音失真 / 残噪」拆两项、只在有声帧算语音项，可直接套在 HybridLoss 的幅度项上。
- 【推断】这给了一个旋钮：调大语音项权重治字头被吞，调大降噪项治停顿残噪。
- 【推断】有声帧判法（峰值 −30 dB）简单，可复用到我们的字头与停顿判据。
- 【推断】训练片段 ≥ 5 秒；GTCRN 的加训片段长度应查一下是否够。
- 【推断】众包听测偏好「更狠降噪」与作者听感相反（p.4）。我们的盲听必须由人做，不能由 AI 或客观分代判。

## 对 GTCRN 加训：不能借什么 / 要小心（【推断】）
- 众包 MOS 偏好的 α = 0.05 伴随明显语音失真（p.4）。【推断】与我们「别吞字头」目标冲突，不能照搬低 α。
- 客观指标与主观排序不一致（p.4）。【推断】加权扫参的选择不能只看 PESQ / SI-SDR。
- 测试 SNR 只有 0–40 dB 五档，无负 SNR（p.3）。【推断】低 SNR 结论无证据。
- 本文是从零训的 1.26M 纯 GRU，不是微调 4.8 万参数的 GTCRN。
- 单次训练；只有主观 MOS 给了标准差（p.4 表 2）。
- 损失按句全局能量算（p.2–3）。【推断】电平随机增强时，两项的尺度会随电平变，需做电平归一。
