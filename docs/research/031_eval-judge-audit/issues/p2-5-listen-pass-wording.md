# 成绩单「听感过」写清是「不比原声差」，不是「人觉得能用」

来源：调研 031 `audit.md` 第 5 条（P2）。

## 是什么
听感评估器（SCOREQ · Distill-MOS）判的是「输出比带噪原声差没差」（Δ），人耳题问的是「开会能不能用」。吃字评估器比的是「比带噪原声多错几个」，人勾吃字时对照的是干净原文。成绩单标题写「效果还可以」（`specs/rubric/scorecard.md:1`），读者容易把「听感过」读成「能用」。
实测：exp003 c12 三个模型都被人勾吃字，但带噪原声本身 20 个词错 19 个，评估器眼里谁都没多错（`docs/experiments/exp022-judge-tpr-tnr/results/tpr_tnr.json`）。

## 怎么做
- 成绩单开头（`src/eval/src/scorecard/card.rs` 生成处）加一句：「听感过 = 两个评分模型都说不比原声差，不等于人觉得能用；已量到的抓坏率见定标报告」
- `scorecard.md` 第〇节同步

## 怎么测
- `card.rs` 渲染测试断言这句在开头出现
