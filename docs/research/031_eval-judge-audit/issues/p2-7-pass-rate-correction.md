# 成绩单的「过」没标出评估器的判错率，也没按判错率修正

来源：调研 031 `audit.md` 第 7 条（P2）。

## 是什么
成绩单的区间只管分数的抽样误差（`src/eval/src/scorecard/aggregate.rs`），不管评估器判错。已知判错率时，可以用 Rogan-Gladen 公式修正：真实不过率 = (评估器判不过率 + 真阴性率 − 1) ÷ (真阳性率 + 真阴性率 − 1)。SCOREQ 现在的真阳性率 + 真阴性率 − 1 只有 0.07，公式几乎除以零：现有数据下，从 SCOREQ 的过关比例推不出人的过关比例。

## 怎么做
1. 先做：成绩单里每个感知项旁标「抓坏率 / 不冤枉率：x / y（n 条，来自定标第 k 轮验证集）」或「未量」，数据取 `vdn-eval calib` 的 `judges` 段
2. 验证集里每类 ≥ 30 条后，再加修正后的不过比例与区间（`docs/experiments/exp022-judge-tpr-tnr/stats.py` 的 `rogan_gladen` 可作对照实现）

## 怎么测
- 修正公式：用人造的真不过率与判错率生成观测值，修正后还原真值（exp022 `test_stats.py` 已有同类测试）
- 真阳性率 + 真阴性率 ≤ 1 时报「无解」，不出数
