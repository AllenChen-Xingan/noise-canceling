# 人耳「开会能用吗」三级里 marginal 算过还是不过，下轮前事先定

来源：调研 031 `audit.md` 第 8 条（P2）。

## 是什么
成绩单是过 / 不过 / 待测，符合二值判定。人耳题是 ok / marginal / no 三级，marginal 归哪边没写。exp022 两种切法都报了（宽：no = 不过；严：no 或 marginal = 不过），本批结论方向一致，但以后可能不一致；事后挑切法等于自己调自己考。

## 怎么做
- 下一轮听测的 build 清单里写死「定标用哪种切法」，揭盲前提交
- 或者改题：直接问「开会能用吗：能 / 不能」，另加一个可选的「勉强」备注
