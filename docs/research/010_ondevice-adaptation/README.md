## 这次要决定的

自适应的每样东西放哪条回路、给多少预算、用什么护栏；没有遥测时怎么在发布前找出长尾问题。

## 一句结论

自适应主要靠**记参数**（每场景一个偏好偏移、声纹向量、在现成配置里选当前最好），不靠改权重；权重只在空闲回路动 BN/LN 的约 580 个仿射参数与归一化统计，过影子比对才换，定期跟出厂版比。通话中不探索。耗电的大头是实时推理本身，空闲小更新一次只有几十焦耳。三件事要人定（`decision.md` 第五节）。
