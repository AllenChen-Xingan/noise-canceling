# 派活模板 · 设备端低功耗实时自适应 + 可靠性

> 2026-10-31。本次实际用过的派活方式，下次同类调研照填。Workflow 运行号 `wf_aca44f3f-a3b`（9 个代理：7 检索 + 2 怀疑派）。

## 共用前言（每路都带）

- **背景**：GTCRN 48.2K 参数、约 33 MMACs/s、本机最坏 0.62 ms / 16 ms 帧；端到端 ≤ 45 ms；三条回路（反射 10 ms · 判断约 0.5 s · 学习空闲）
- **硬约束**：察觉不到占用 · 无云端无上传无遥测 · 两层自适应（实时 + 空闲小更新，影子比对、可回滚、可关）
- **铁律**：**绝对不许构建、编译、安装或运行任何程序**，只许联网检索和读文件；只写指定的一份笔记；每条结论带出处与等级（官方 / 论文 / 源码 / 二手 / 推算，推算写算式）；找不到就写「没找到」
- **产出**：笔记 ≤ 2500 字写进 `notes/<key>.md`，末尾「对我们的含义：放哪条回路 · 预算 · 护栏 · 首选 + 备选 + 三个风险」；返回 ≤ 900 字摘要
