## 〇、一句话结论

1. **能做，但第一版要保守**：调节模型很小（约 7 千参数，每 0.5 s 一次），贵的是本机评分模型。
2. **评分模型要从 378 MB 缩到 ≤ 5 MB**（D60）。有现成先例：DistillMOS 把 4.78 亿参数蒸到 430 万，与人的相关只掉 0.05【论文 r1 B】。难点是短窗：老师用 4 s 片段，我们要滑动 2–4 s 窗、每 0.5 s 出一次分。
3. **评分模型不直接当奖励去优化**。公开证据：拿单一评分模型当奖励改权重，几乎都被钻空子；SCOREQ 被钻得最狠（留出评委从 4.51 掉到 1.26）【论文 r2 C1】。它在本机只做两件事：**在出厂候选里排序**、**报警**。
4. **红线一票否决，排在评分之前**：吃字、人声被压低、延迟、静音或坏值。评分再高也不许越线。
5. **离线比查表好多少：尚无判据，待测**（exp011 要量）。公开文献里「每段最优参数」相对「调好的固定参数」能涨多少，没查到任何数字【r2】。我的推算是平均只涨 0.05–0.15 分（5 分制），集中在 10–30% 的格子里——只用来定样本量，不当结论。

## 一、闭环结构

用户电脑上的五个部件，以及它们在哪条回路、占多少、进不进延迟账：

```
 麦克风 ─► [实时降噪 GTCRN + 门控 + 修音]  ─────────────► 虚拟麦（对方听到）
   │             ▲ 参数包（每 0.5 s 最多换一次，逐 hop 平滑）      │
   │             │                                                  │
   ├─► [感知层：35 维特征 / 16 ms] ─► [调节模型] ─► 候选参数 ─► [红线过滤] ─► [评分排序] ─┘
   │                                                                  ▲
   └──────────────► [本机评分模型（≤5 MB，滑动 2–4 s 窗）]  ◄── 处理后的声音
                                    │
                       决策日志（只存参数和分数，不存音频）
                                    ▼
                [学习回路：插电 + 空闲 + 没在开会 → 影子比对 → 换或不换]
```

| 部件 | 回路 | 算力 · 耗电（M1 能效核） | 进延迟账吗 | 依据 |
|---|---|---|---|---|
| 实时降噪 + 门控 + 修音 | 反射（每 16 ms） | GTCRN 约 33 MMAC/s，已在账上 | **进**（全链 ≤ 45 ms，D32） | `specs/rust/architecture.md` §3.7 |
| 感知层（35 维特征） | 反射算、判断取 | 复用模型的谱，约 0 附加 | 不进（只送特征） | §3.7「实时 → 判断」 |
| 调节模型（小网络） | 判断（0.5 s） | 约 7 千参数，每次 < 0.1 ms【推算 r3】 | 不进 | r3 含义 1 |
| 本机评分模型（学生） | 判断（0.5 s，可降到 2 s） | 流式小卷积：一颗能效核 3–10%；4M 参数版 13–40%【推算 r1 含义 5，未实测】 | 不进 | r1 |
| 红线过滤（便宜代理） | 判断（0.5 s） | 电平、字头能量等 DSP 量，≪ 1% | 不进 | r4 G3 |
| 吃字全量检查（语音识别） | 学习（空闲） | 只在插电空闲时跑 | 不进 | r4 G3、D58 |
| 影子比对 + 换版 | 学习（天级） | 空闲时离线同码路径重跑 | 不进 | §3.7.4b、r4 G8 |

**察觉不到（D37）的硬条件**：判断回路合计占一颗能效核 ≤ 10%【推算目标】；超了就把评分降到每 2 s 一次。这个数要在推理引擎线（019）落地后实测，现在是「尚无判据，待测」。

## 二、本机评分模型（回答「SCOREQ 378 MB 怎么变小」，D60）

**老师**：SCOREQ 无参考自然域版，只在开发机上跑。它在降噪输出上与众人最一致：语句级相关 0.789、系统级 0.926（URGENT 2024 人评）【实测 ears exp009，分数取自上游文件，本机只算了相关】。

**学生，两条路并行，谁过线用谁**：

| | 学生 S1「小卷积」 | 学生 S2「从 DistillMOS 起步」 |
|---|---|---|
| 结构 | log-mel → 6 层深度可分离卷积 → 注意力池化 | 现成 DistillMOS（430 万参数，MIT 许可）继续蒸 |
| 体积 | int8 < 1 MB | fp16 约 2–8 MB |
| 算力 | 约 25 MMAC / 次（流式）| 约 100 MMAC / 次 |
| 风险 | 谱特征单任务时比自监督骨干差约 0.27（Uni-VERSA 表 4）【论文 r1 已核改】 | 官方输入是 7.68 s 片段，短窗未验证 |

**蒸馏数据**：GTCRN 在各参数组下的合成输出（正好覆盖调节模型会去的区域）+ 公开集训练份（D63）的干净人声和噪声当原料；老师打软标签，同时对齐它的 256 维嵌入；混入约 20% 带人评的降噪输出当锚（DistillMOS 网格搜出的比例）。**故意加「讨好样本」**：过度压噪、吞字头、人声被压低。这些样本的分数不用老师给，由红线评测压低，免得学生继承老师的盲区。

**验收线（建议）**：

- 与老师：同分布留出集语句相关 ≥ 0.90
- 与人：URGENT 2024 语句相关 ≥ 0.74（比 SCOREQ 低 ≤ 0.05），且不输 DistillMOS（0.757）超过 0.01；系统级 ≥ 0.85
- **任一条不过 → 直接用 DistillMOS 原版**，D60 改成「只对 DistillMOS 做量化」

**多准才许它驱动调节**（建议，技术口径由我定）：

| 一致率 | 本机评分模型能做什么 |
|---|---|
| 过上面全部验收线，且在本项目人耳盲听上与人同向 ≥ 70%（D44 校准） | 在出厂候选里排序，驱动切换 |
| 只过与老师那一条 | 只观察：记进决策日志、在影子比对里当旁证，不驱动 |
| 都不过 | 不随包 |

**为什么不把它当奖励直接优化**：r2 C1 显示 SCOREQ 当奖励时被钻得最狠；r2 C5 显示只在 N 个候选里挑，N 超过 8–16 也会被钻。所以本机候选 ≤ 8 个，排序用**集成**（学生分 + DNSMOS 背景分 + DSP 制衡项），红线先过滤再排序（r4 G3–G6）。

## 三、调节模型

**输入**：已有 35 维特征（`src/scene/src/features.rs:46`）+ 当前场景分类的 7 类概率 + 认人门控状态。

**输出**（`ParamSet` 字段，第一版只放三项）：

- 第一版调：`strength`（模型湿干比）· `floor_db`（背景保留下限）· `detect_db`（门控灵敏度）
- 第一版不调：`release_s` / `hangover_s`（时间常数，单帧特征分辨不出，r3 含义 2）· `model` / `tone`（离散项，仍由场景表定）
- 形态：输出是「场景表参数 ± 有界偏移」，偏移上限就是安全带（r3 含义 4）。这样查表永远是兜底

**离线怎么训**（开发机，D62 全用合成数据）：

1. 在合成格上，每格用黑盒搜索（CMA-ES / 网格）找参数。**目标 = 评分集成，约束 = 红线评测**（越线的参数直接淘汰，不进加权和）
2. 每格的最优参数当标签，监督回归训调节模型。红线在搜索里是硬约束，模型学不到越线的参数；标签可审计、进 git
3. 用评分模型梯度或强化学习继续调：**第二步才考虑**，等评分模型到 D44 的可用级别

**本机怎么继续调（D38 两层）**：

- 快层（判断回路）：只在出厂候选里选，候选 ≤ 8，平滑过渡
- 慢层（学习回路）：只学 ≤ 4 维偏移（Widex 式成对比较 + 用户手动改动当信号）；不动调节模型权重、不动主模型（D56）；过影子比对才换，可一键回出厂

## 四、场景路由的迁移路径

查表（D40 / D41）不删，降级为调节模型的**输入和兜底**：

1. **现在**：查表决定全部参数（`TablePolicy`）
2. **第一版调节模型**：查表定离散项和基础值；调节模型只出三项偏移；调节模型输出非有限或置信低 → 退回纯查表
3. **以后**：exp011 及后续实验证明偏移有用（按评测）才扩大偏移范围；否则停在第 2 步

调节模型实现 `Policy` trait（§3.7.2），与 `TablePolicy` 并列、可单独替换；影子比对的对照组就是 `TablePolicy`。

## 五、红线与护栏

r4 列了 14 条护栏（`notes/r4-guardrails.md` 第三节）。下面 6 条是第一版必须有的：

| 护栏 | 挡什么 | 回路 |
|---|---|---|
| 坏值 / 静音 → 送原声并清状态 | 保命 | 实时 |
| 参数硬上下限 + 限速渐变（1 dB/s） | 跳变、真空感、调节模型输出离谱值 | 实时 |
| **红线一票否决，排在评分前**：人声电平下降、字头被压、延迟 > 45 ms；吃字（语音识别）空闲时全量查 | 评分再高也不许越线 | 判断 / 学习 |
| 评分集成 + 分歧大就不动 | 单一评分被讨好、分布外乱打分 | 判断 |
| 通话中不试新参数，新参数只在影子回路里试 | 对方听到试验 | 学习 |
| 影子比对 + 版本链 + 一键回出厂；用户手动改动立刻生效并计为否决 | 悄悄变坏、学坏后没法恢复 | 学习 / 任意 |

## 六、对 `vdn-types` 接口的建议（不改 `src/`，只列）
