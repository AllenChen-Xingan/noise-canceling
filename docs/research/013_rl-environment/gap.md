## 二、它们没做的

| 缺口 | 没顾上（机会）还是做不到（天堑） | 我们怎么办 |
|---|---|---|
| **笔记本内置麦（系统已做波束 / AGC）+ 一大片人的模拟** | **机会**：没人公开过；原始阵列不可得，但可用「回放重录 + 角度扫频」实测出系统链特性 | 交 scene 下一批：内置麦设备模型；本线建议的实测法见 decision §一 |
| 咖啡馆 babble 人数 / 距离分布的公开测量 | 没顾上 | 分两层建模（近处 1–3 人可懂 + 远处扩散场）；范围标【推算】，用本人实录校准 |
| 48K 量级模型上「判别器 vs 策略梯度」的对照 | 没顾上 | 不押注任一；先做不需要不可微奖励的部分 |
| GTCRN 在 MPS 上能否训 | ？：PyTorch MPS 的 GRU 有未修复的静默错误（issue #94691）；GTCRN 有 14 个 GRU 实例 | 需要一次有界冒烟（占重活名额）；不行走 CPU / MLX / 云 |
| 「分场景专家」vs「共享骨干 + 场景条件」在同参数同延迟下谁好 | 没顾上 | 留到训练线后段用实验定 |
| 感知类 verifier 的人耳定标 | 没顾上（evalstd 正在立流程） | 按 012 约 5–6 轮到 L2、每轮约 35 分钟（`verifiers.md:51,168`）；在此之前训练奖励里没有感知项 |
| 中文吃字的训练数据与 ASR 奖励 | 没顾上 | AISHELL-1（Apache-2.0）可用；ASR 裁判需含中文（Qwen3-ASR / SenseVoice） |
| 自噪声（本机键盘、风扇）与残余回声（D42 不戴耳麦，对方声音会外放漏进来） | 没顾上 | 写进模拟器缺口清单 |
| 训练规模的本机存储 | 天堑（本机）：剩约 176 GiB，DNS 解包约 1 TB | 待人拍板：外置盘 / NAS，或只用在线混合的小子集 |

## 三、一句话

**别人证明了两件事：多指标 + 留出裁判才压得住讨好；低维参数用黑盒优化就够、没人上线 RL。没人做过的是我们的核心场景——系统处理过的内置麦 + 一大片人——这块的模拟器要我们自己先实测出来。**
