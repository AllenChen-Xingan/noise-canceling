## 结论
1. **能直接当训练奖励的指标很少，只有 3 个**：语音帧能量损失（词首 50 ms 单独算）、ΔESTOI、SI-SDR。它们都需要干净参考。模拟器里有参考，所以它们只能在训练和模拟里用。吃字率（ASR）和无参考 MOS 都不可微，只能用在 bandit、RL 或偏好对排序里。【推算，依据 `specs/rubric/denoise.md:57-64`】
2. **单独优化一个无参考 MOS，在语音增强（SE）里已有实测会翻车**。只拿 DNSMOS 做奖励，听感 Elo 从 1476 掉到 1335，低于起点模型。三项合成奖励（DNSMOS + 1−WER + UTMOS）是 1571，胜率 71%。【论文 arXiv 2606.21458 §4.2 表 3】直接按音质指标做 DPO 会把发音关键的内容抹掉，作者称之为「灾难性讨好」。【论文 arXiv 2607.10191 摘要】
3. **KL 约束挡不住讨好，只相当于提前停**。它没有改善「真实分数 vs KL」这条前沿。【论文 arXiv 2210.10760 §1、§3.6】所以真正的防线是留出的裁判和人耳，KL 只控制走多远。
4. **ASR 惩罚两头都会出错**：会漏报，也会被讨好。exp003 里人耳勾吃字 8–9/12 段，ASR 只在 5 段报了新删词（`docs/experiments/exp003-offline-ab/results/README.md:73`）。Whisper large-v3 对非语音输入有 40.3% 会吐出文字【论文 arXiv 2501.11378 §II-B，转引自 007 must-know #17】。
5. **吃字和延迟、算力都不要放进加权和**。吃字做约束（拉格朗日，或一票否决），延迟和算力做可行域。【推算】

## 逐条

### 1. 可当奖励的指标

「需参考」：参=要干净参考，文=要参考文字，无=都不要。

| 指标 | 可微 | 单次成本 | 需参考 | 管哪把尺子 | 怎么被讨好 |
|---|---|---|---|---|---|
| 吃字 Δdel（Qwen3-ASR / Whisper） | 否 | 高：每段一次大模型推理；Qwen3-ASR 1.7B【dryrun-exp003:4】，具体耗时未测 | 文 | 清楚（权重 18） | 选 ASR 的盲区，比如残留的 babble 被转成字、把吃掉的字「脑补」回来。只罚删除时，模型可以靠多留噪音「保字」 |
| 语音帧能量损失 + 词首 | 是 | 极低 | 参 | 清楚 C3 | 整体调大音量。rubric 已规定增益为正时记 0（`denoise.md:81`） |
| 残留噪音 noise_att / resid_rel | 是 | 极低 | 参（或 VAD） | 清楚 C2 | 过度抑制，产生真空感 |
| 干扰者残留 IRL | 是 | 低 | 要分轨（模拟里有） | 清楚 C4 | 连主讲人一起压 |
| DNSMOS | 可近似（ONNX 约 2.9 MB）【004 must-know】 | 低 | 无 | 自然（只报警） | 2606.21458 和 2607.10191 都有实测；在 CHiME-7 上 CMGAN 的 DNSMOS 最好、听测最差【论文 2402.01413，转引 007 #12】 |
| NISQA | 是 | 低 | 无 | 自然 N2 | 权重是 NC 许可（`NISQA/README.md:166`），**按 D26 不能用来训练** |
| UTMOS | 是 | 中 | 无 | 自然 | 换到别的数据就崩：CHiME-7 上逐句相关只有 0.33【论文 2601.18438 表 10】 |
| SCOREQ | 是 | 中 | 无 | 自然 N1 | 证据少，同一来源里逐句 0.75 |
| PESQ | 否（有可微近似） | 低 | 参 | 自然（备查） | 直接优化能到 3.82 而专家听测垫底；只改第一个采样点就到 3.46【论文 2406.03460】；ITU 代码禁止分发 |
| ESTOI | 是 | 低 | 参 | 清楚 | 难讨好，但对音色和伪影迟钝 |
| SI-SDR | 是 | 极低 | 参 | 清楚、自然 | 不在乎听感伪影，宁可留残响 |
| LTASS 偏差 | 是 | 极低 | 参（或长时统计） | 自然 N4 | 用均衡器把整体频谱拉平，局部伪影照样在 |
| 背景波动 σ / 跳变 | 是 | 极低 | 无（要 VAD） | 自然 N3 | 把背景全压成死寂，σ 就低了 |
| 延迟、每帧耗时 | — | 实测 | 无 | 轻快 | 不进奖励（见第 2 条） |

### 2. 奖励的形态
- **可行域（硬约束，不打分）**：因果；附加延迟 ≤ 45 ms；最坏一帧 ≤ 周期的一半（V1–V3）；许可（V4）。不满足的候选直接剔掉，不给负分。
- **约束优化**：目标是 max J = 自然类分数 + 残留类分数，限制条件是 Δdel ≤ ε（每个场景组单独算）、词首能量损失 ≤ 3 dB、语音帧能量损失 ≤ 1 dB。约束违反时，用拉格朗日乘子自动加罚（PPO-Lagrangian 一类做法）【推算】。在策略层的 bandit 上，用词典序更简单：先过吃字，再比其余项。
- **训练指标和裁判指标分开**：
  - 训练用：能量损失、ESTOI、SI-SDR、LTASS、σ，再加一种 ASR（Whisper）。
  - 裁判用，不进梯度：SCOREQ、Qwen3-ASR 的 Δdel、Δins、作者的 AB 听测。
  - 这符合 013 命门 2 和 D44「奖励只能由 012 里置信度过线的 verifier 组成」（`docs/research/013_rl-environment/must-know.md`）。
- **加权项要封顶**：单一指标 ≤ 18，MOS 合计 ≤ 8（`denoise.md:74`）。训练时用排名或归一化后的分数，不用原值，免得某一项靠数值量级压过别的项【推算】。

### 3. 讨好奖励的案例与对策
- **SE 案例**：
  - 只用 DNSMOS 的 GSPO，Elo 1335，起点模型 1476【2606.21458 表 3】。
  - 只按音质做 DPO，把发音内容抹掉【2607.10191】。
  - FlowSE-GRPO：单奖励涨分很快，但音频保真度下降；改成多指标奖励后缓解【论文 arXiv 2601.16483，数字未读】。
  - URGENT 2025 的 T13：主观 MOS 第 1，总名次第 13【论文 2505.23212 §4.3】。
  - 在 AATC 上 DNSMOS 与人耳 ρ = −0.8，只有 4 个系统点【论文 2509.12974】。
  - exp002 实测：BAK 从 2.64 升到 4.00，同时 SIG 从 3.61 降到 3.40（`denoise.md:317`）。
- **MetricGAN**：它的判别器（学来的指标）很容易被骗，给出高分而真实 PESQ 却低【二手，Fu 的博士论文，检索摘要转述】。至于 MetricGAN+ 被听测证实出伪影，**没找到**。
- **RLHF**：Gao et al. 给出两条曲线（d = √KL）：
  - best-of-n：R = d(α − βd)
  - RL：R = d(α − β·log d)
  - 两条曲线都是先升后降，系数随奖励模型变大而平滑变化；策略模型变大并不会更容易过优化【2210.10760 §1、§3.4】。
- **DeepMind 的 specification gaming 列表**：「满足字面目标、没达成本意」【官方博客 2020-05，DeepMind Safety】。条目数未能核实。
- **对策**：
  - 多指标封顶加制衡对（第 2 条）。
  - 训练用奖励和裁判分开。
  - 按 Gao 的曲线，每隔一段 KL 量一次裁判分，裁判分转跌就停。
  - 周期性做人耳 AB，固定加一道「同一文件」检验题。
  - 对抗检查：把输出人为削词首、压成死寂、加 1 kHz 低通，奖励必须给这三种更低分（`denoise.md` §7）。
  - 奖励模型集成：用 2 种 ASR、2 种 MOS 的最差值或均值【推算】。

### 4. 拿 ASR 当奖励
- **已有工作**：
  - MMW 用 GRPO，奖励里含 1−WER【论文 arXiv 2507.05609】，是多麦眼镜场景。
  - 2406.18928：Whisper 冻结，前端只用 ASR 损失训练时不稳定，要加 L1 项【论文】。
  - 2606.21458：只用 WER 做奖励，Elo 1541，胜率 40%。
  - 1811.04224：用 CER 做 RL 调 SE【论文】。
  - 增强后 ASR 变差的主因是伪影而不是残留噪音；把原声按比例混回去（observation adding）能缓解【论文 arXiv 2201.06685】。
- **多 ASR 交叉的做法**【推算】：
  1. 训练只用 Whisper；Qwen3-ASR 留作裁判。
  2. 删除数取两者的较大值，即悲观并集。
  3. 两者分歧大的段（`asr_stable` = false，或两边删除数差 ≥ 2）不进奖励，送人耳听。
  4. 同时罚 Δins，防止残留 babble 被转成字、或模型脑补。
  5. 词首能量损失作为不依赖 ASR 的保底约束。

## 对我们最值得借的 3 件事
1. 训练奖励用三项合成（MOS + 1−WER + 另一个 MOS），并消融单项。单项 DNSMOS 是现成的负例【arXiv 2606.21458 §3.3、表 3】。
2. 用 Gao 的曲线做停训规则：按 KL 记录训练奖励和裁判分，裁判转跌就停；别指望靠调 KL 系数解决【arXiv 2210.10760 §3.6】。
3. 把 observation adding 当作保字的安全阀：做成一个旋钮（混回原声的比例），交给策略层学习【arXiv 2201.06685】。

## 预判：部分推翻
预判是「吃字率 + 一个参考指标 + 一个无参考 MOS + 留出的人耳 AB，就能防住大部分讨好」。
- **证实的部分**：多指标确实优于单指标【2606.21458】。
- **推翻的地方有三处**：
  1. 只用 ASR 删除率会漏报（exp003 已见），而且奖励能被模型对着那一个 ASR 学偏。要 2 个 ASR，再加 Δins 和词首能量损失。
  2. 一个无参考 MOS 不够：DNSMOS 会被讨好，UTMOS 换数据就崩。至少要 SCOREQ 加 UTMOS 互相制衡，而且裁判和训练用的 MOS 不能是同一个。
  3. 「留出的人耳 AB」只抽查到裁判，挡不住训练中途的过优化。还要按 KL 分段记录裁判分，并在训练里固定跑劣化对抗检查。另外，真空感和背景跳变这两类问题，三项里没有一项管得到，必须加上 σ / 跳变和 LTASS。
