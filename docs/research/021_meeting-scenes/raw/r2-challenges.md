# 挑战赛与论文的场景分组：14 个开会地点的覆盖情况（第 2 路）

## 要点
1. 几届 DNS 降噪挑战（DNS Challenge）的盲测集里，**只有 2022 年那届公布了噪声类型分布的数值**：859 条，19 类，按百分比给出（论文图 1，柱上印着数值）。其余各届只列类别、不给条数，或者按语言和情绪分组，不按地点分组。
2. 会议室的数据最多：会议转写挑战 NOTSOFAR-1 有约 30 间会议室，AliMeeting 有 13 间（8–55 m²），ConferencingSpeech 2021 有 12 间，AMI 有 3 间，ICSI 有 1 间。但它们**都用专用的麦克风阵列或会议设备录音，不用笔记本内置麦**。这些论文里也**都没有房间 T60（混响时间）和房间尺寸的实测表**。
3. 家里的场景（`home-family`）覆盖得最好，可以从三处得到支撑：DNS 2022 噪声分布里婴儿哭、狗叫、水流、餐具等合计约 29%【推断，由图 1 求和】；CHiME-5/6 在住户家的厨房、客厅、餐厅录聚餐对话；DNS 2023 列出的家庭噪声。
4. **有 6 个地点在所有公开挑战里都没有覆盖**：`rail-air-cabin`（高铁/飞机客舱）、`phone-booth`（电话亭/专注舱）、`hotel-room`（酒店房间）、`library-classroom`（教室/图书馆）、`cowork`（共享办公）、`canteen`（餐厅/食堂）。另外两个只出现在噪声名单里、没有条数：`transit-hub`（候车厅）只有「机场广播」一个标签（DNS 2023）；`cafe`（咖啡馆）只有「Café」一个标签（DNS 2023）。【推断，依据下文各表】
5. 回声消除挑战（AEC Challenge）的录音全部来自 Windows 设备，按「干净 / 有噪」和「单讲 / 双讲」分组，**不按地点分组**。

### 1.5 ICASSP 2023（第 5 届）
来源：【论文】https://arxiv.org/pdf/2303.11510 §2、§3.2、§3.3；【官方文档】https://www.microsoft.com/en-us/research/academic-program/deep-noise-suppression-challenge-icassp-2023

**赛道和条数：**
- 第 1 赛道是耳机（有线、无线、AirPods 类）。
- 第 2 赛道是外放（扬声器电话，**包括笔记本、台式机、手机的内置麦**）。
- 每个赛道的开发集和盲测集各 600 条【官方文档】。
- 每条都配有 10–30 s 的目标说话人注册语音。
- 开发集的分组与第 4 届相同：193 条情绪 / 737 条噪声 / 166 条邻座 + 噪声 / 347 条只有邻座（§3.2）。

**盲测集分组**（只列类别，**每组条数未查到**）：
- 副语言（清嗓、嗯、叹气、疲惫、中途变声等）
- 情绪（开心、悲伤、愤怒、喊叫、哭、笑）
- 强混响
- 强混响 + 噪声
- 噪声 + 邻座说话人
- 还特意变化了直达混响比、T60（靠改变人和干扰源的位置、有没有反射面）。**T60 的具体数值未查到。**

**盲测集噪声名单**（§3.3，没有占比）：
- 办公类：打字、空调、关门、咀嚼、复印机、椅子吱呀、通知音
- 家庭类：婴儿哭、狗、电视、暖气片、吹风机、厨房、水流
- 家电：洗衣机、烘干机、洗碗机、咖啡机、吸尘器
- 交通和户外：火警、汽车、停在繁忙路边的车内、车内邻座说话人、交通道路、机器和转向灯声
- 公共场所：**Café（咖啡馆）、咖啡机、搅拌机、背景人声嘈杂（babble）、Airport Announcements（机场广播）**

**和场景键的对应**【推断】：`cafe`、`transit-hub`、`car-passenger` 第一次以名字出现，但没有条数。第 2 赛道是唯一明说包含笔记本内置麦的赛道。

## 五、AEC 回声消除挑战（微软）

**ICASSP 2021：**
来源：【论文】https://arxiv.org/pdf/2009.04972v3 §2.1、§3、图 3

- 真实训练集按 6 种情形分：远端单讲（回声路径不变 / 改变）、近端单讲、双讲（回声路径不变 / 改变）、扫频（用来估 RT60）。
- 规模：2,500 个完整情形 + 1,000 个部分情形，共 1.8 万条；覆盖 2,500 多个不同环境和设备；**只有 Windows 设备**。
- 测试集和盲测集**各约 1000 条实录**，只分两组：「干净」（主观打分 MOS > 4）和「有噪」（近端和远端都有噪声）。**两组各几条：未查到。**
- 真实训练集的 RT60 分布（图 3，图中估读）：
  - 范围约 0.1–1.5 s。
  - 峰值在 0.2–0.25 s，约 660 条。
  - 大部分在 0.5 s 以下。

**ICASSP 2023：**
来源：【论文】https://arxiv.org/html/2309.12553v1 §5

- 开发测试集和盲测集各 800 条实录，每条 30–45 s。
- 难点类别有：长延迟或时变延迟、扬声器和麦克风失真、稳态和非稳态近端噪声、设备自带音频处理、卡顿、增益变化。
- **每类条数、设备类型的分布：未查到**。

**和场景键的对应**：不按地点分组。只能推断，众包录音以家里和办公室为主【推断】。

- 评测集：8 场，5 间房，25 人，交叠率 34.20%。
- 测试集：10 h。
- 录音时人为制造了点击、键盘、开关门、风扇、背景人声等噪声。

## 七、14 个场景键的覆盖总表

下表用来一眼看出每个场景键有没有挑战数据。「哪个挑战有」一列是读论文得到的；「判断」一列是我的推断。

| 场景键 | 哪个挑战有（条数或占比） | 判断【推断】 |
|---|---|---|
| `home-quiet` | DNS 2022「无噪声」5.3%（约 46 条）；风扇、打字类噪声 | 有，但没有作为一个地点单独分组 |
| `home-family` | DNS 2022 婴儿、狗、水流、餐具、洗碗机、咀嚼合计 29.1%；CHiME-5/6 和 DiPCo 的家庭聚餐；DNS 2023 列出电视、吹风机、吸尘器 | **覆盖最好** |
| `open-office` | DNS 2020 开发集「开放办公区」实录（在 300 条里，没有拆分）；DNS 2022 打字、鼠标、复印机、空调合计 24.2% | 有，但多是噪声标签，不是成组的地点 |
| `phone-booth` | 没有（Mixer 6 的两人访谈室最多算勉强沾边） | **无** |
| `meeting-room` | NOTSOFAR-1（30 或 38 间）、AliMeeting 13 间、ConferencingSpeech 2021 12 间、AMI 3 间、ICSI 1 间、DNS 2020 会议室实录 | 多，但全用专用会议设备或阵列，**没有「一台 MacBook 放桌上」的设置**；T60 都没有公开 |
| `cowork` | 没有 | **无** |
| `cafe` | DNS 2023 噪声名单里有「Café、咖啡机、背景人声」，没有条数；CHiME-4 有咖啡馆环境（不在本线范围，本次未核） | 只有标签 |
| `canteen` | DNS 2022「杂物碰撞声」3.5% 和「餐具」5.7% 可以借用 | **没有这个地点本身** |
| `transit-hub` | DNS 2023「机场广播」只有标签；URGENT 2025 的 TUT 声景只放在非盲测集 | 只有标签 |
| `car-passenger` | DNS 2022「车内（副驾）」0.9%（约 8 条）；DNS 2023「停在繁忙路边的车内」「车内邻座说话人」 | 少 |
| `rail-air-cabin` | 没有 | **无** |
| `street-outdoor` | DNS 2022「街道」4.2%（约 36 条）；DNS 2023「交通道路」；URGENT 2025 有风噪这一失真 | 少 |
| `hotel-room` | 没有 | **无** |
| `library-classroom` | 没有 | **无** |

**整体缺口**【推断】：
- **完全没有覆盖的 6 个地点**：`rail-air-cabin`、`phone-booth`、`hotel-room`、`library-classroom`、`cowork`、`canteen`。
- **只有噪声标签、没有条数的 2 个地点**：`cafe`、`transit-hub`。
- **所有挑战都没给的东西**：按地点分组的条数；各地点的 T60 实测值；「笔记本内置麦 + 视频会议」作为单独一组。DNS 2023 第 2 赛道包含笔记本，但没有拆分条数。

**本次没有核实的点**：
- NOTSOFAR-1 的房间数（30 还是 38）。
- CHiME-6 每场人数，以及 Interspeech 2021 DNS 的盲测条数。
- AMI 的房间尺寸。
