# 调研计划（022 · Mac 内置麦克风）

> 2026-11-03 · macmic 起草，等大总管回「可以」再起 workflow。
> 用途：说清这次调研分几路、每路查什么、谁来挑错，好让大总管批。

## 规模
共 8 个代理：4 路调研员 + 4 个怀疑派（每路 1 个）。流水线式：每路调研员一交稿，它的怀疑派就开审。汇总由我（macmic）亲手做，不另起代理。

## 写死在每个提示里的限制
- 不许构建、不许下载单个超过 50 MB 的文件、不许跑重活
- 不调用麦克风、不录音、不放声、不改系统音频设置
- 只读网页、论文、本机已有的 SDK 头文件与 `resources/` 源码；不写仓库文件，结果交回给我
- 每条结论标来源：【官方文档】【源码】【论文】【论坛 / 博客，个人说法】【推断】；带 URL 或文件:行号；查不到写「未查到」

## 四路

| 路 | 查什么 | 交回什么 |
|---|---|---|
| ① 官方 `apple` | 各代 MacBook Air / Pro、iMac、Studio Display 的麦克风规格原文（三麦阵列、定向波束成形、studio-quality、起始年份）；Core Audio HAL / VPIO / `AVCaptureDevice.MicrophoneMode` / 语音突显与宽频谱的文档；第三方 app 经 HAL 拿到的是处理前还是处理后；AirPods 在 Mac 上的通话链路采样率 | 机型 × 规格表；处理阶段图（哪一步谁做、第三方在哪一步取音） |
| ② 他人实测 `measure` | 内置麦频响测量、底噪、自动增益；录音对比（音频博客、Reddit、Apple 社区、YouTube 对比、播客圈）；Zoom 原声模式 / Teams / Meet 在 Mac 上再叠加的处理 | 数字表（频响拐点、底噪、AGC 时间常数），每条注明样本量和是不是个人说法 |
| ③ 模拟方法 `sim` | 设备脉冲响应 / 频响卷积（MicIRP 等）；DNS / URGENT 的设备增强怎么做；手机 / 笔记本设备仿真论文；波束成形后的空间特征（离轴、远处人声被压多少分贝）；自动增益与降噪的近似模型 | 每一步模拟的做法、参数范围、依据 |
| ④ 数据 `data` | 用 Mac / 笔记本内置麦录的、和**设备特性**相关的数据：设备响应集、Mac 录音对比样本、同步多设备重录（DR-VCTK 类）。会议场景大集归 mtgdata，发现了记下转交 | 数据清单：名称 · 链接 · 许可 · 大小 · 设备键 · 有无干净参考 |

## 怀疑派审什么
- 每个怀疑派只审对应那一路：出处是否真支持结论（回原文核）、个人说法是否被写成事实、样本量是否够、有没有漏掉反例
- 输出：逐条「成立 / 存疑 / 推翻」+ 理由
