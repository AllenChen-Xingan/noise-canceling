## 一句话结论

建议先做微调：延迟和占用都不变，本机就能训，第一个实验约 11 小时机器时间（多半是重测成绩单），另加一次终测。真正卡住的是数据——本机能合法训练的数据覆盖不了弱场景，要先下约 15 GB。

另外两条实测发现：
- **MPS 上 GTCRN 会算错**：PyTorch 的带空洞逐通道卷积有 bug（不是 GRU）。已找到等价写法绕开，带绕法后与 CPU 一致
- **数据读入和混音不是瓶颈**：比训练快约 20 倍
