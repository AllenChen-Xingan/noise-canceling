# 主观项拆解框架 + verifier 清单

> 2026-10-30 · evalstd。应 D44（人原话：「所有很多主观的东西我们都要分解成有确认系数或者说很客观的标准，这样程序就可以写算法或者 verifier 来打分」）。
> [S N] 见 `sources.md`；rubric 条目见 `specs/rubric/denoise.md`。**标〔建议值〕的数字没有出处，人没拍板前一律暂定。**

## 一、框架：一个主观词怎么变成一个程序

每个主观维度都走四层，任何一层写不出来，就停在那一层，交人耳：

| 层 | 问什么 | 例：「背景抽吸」 |
|---|---|---|
| 1 现象 | 人听到的是什么（用缺陷词汇表的话说） | 一开口背景被压下去，一停又涨回来 |
| 2 可观察量 | 现象在信号里留下什么痕迹 | 非语音段的噪声电平随语音起落而变化 |
| 3 算法 | 怎么从波形算出一个数 | P.1120 §11.14.5：35 ms 时间常数的噪声电平，在语音插入期间与之后的最大波动（dB）[S18] |
| 4 置信度 | 这个数和作者耳朵对得上多少 | 与人耳标签 `pumping_bg` 的一致率、与 H2 的秩相关，带 95% 区间 |

**两类 verifier，置信度来源不同：**

- **物理量**（延迟、耗时、掉帧、NaN、静音全零）：判的是事实，不需要人耳。置信度 = 重复测量的离散度（同一构建跑 5 次的 95% 区间）。直接 L3。
- **感知量**（其余全部）：判的是「人会不会觉得」。置信度只能来自人耳数据。**没有人耳数据的感知量 verifier 一律 L0，不管它在论文里多有名。**

## 二、定标状态（置信度怎么定）

### 2.1 四级

| 级 | 含义 | 判据 〔建议值〕 | 能拿来做什么 |
|---|---|---|---|
| **L0 未定标** | 没有或不够人耳数据 | 配对数 < 20，或片段数 < 30 | 报警、挑必听段、rlenv 的**约束**（不许变差），不能当奖励、不能当门禁 |
| **L1 方向对** | 它说 A 比 B 好时，耳朵大多也这么说 | 成对方向一致率的 Wilson 95% 下界 > 0.5，且配对数 ≥ 20 | 回归门禁的**报警**项；rlenv 的弱奖励（小权重） |
| **L2 排序对** | 它的排序与耳朵的排序相关 | 片段级 Spearman ρ 的 95% 下界 ≥ 0.5（Fisher z，SE = √(1.06 ÷ (n − 3))），且片段数 ≥ 30；**另需** L1 | 回归门禁的**阻断**项（感知类）；rlenv 奖励 |
| **L3 门禁级** | 排序对，且在已知失效情形上也没翻车 | L2 + P.1401 §7.7 rmse\*（逐实验一阶映射后）不大于作者重测抖动的 1.5 倍 + 第三节的「对抗样本」全部判对 | 对外报告可写「经作者听测定标」；rlenv 主奖励 |

物理量 verifier 直接记 L3（判据：5 次重复的 95% 区间半宽 < 档位间距的 1/4）。

**为什么是这几个数**：本机算过（Wilson 区间与 Fisher z）——

| n | 一致率 75% 时 Wilson 下界 | ρ = 0.7 时下界 | ρ = 0.8 时下界 |
|---|---|---|---|
| 12（exp003 一轮的屏数） | 0.47 | 0.19 | 0.40 |
| 20 | 0.53 | 0.36 | 0.54 |
| 30 | 0.57 | 0.45 | 0.61 |
| 40 | 0.60 | 0.49 | 0.65 |
| 60 | 0.63 | 0.54 | 0.68 |

所以一轮 12 屏连 L1 都判不了；**要 L2，真实相关得在 0.75 以上、且攒到 30–40 段**。这与 004 / 007 说的「攒 20–30 对」同量级，但现在有了明确的统计判据。

### 2.2 统计方法（全部本机、确定性、种子固定）

| 用途 | 方法 | 出处 |
|---|---|---|
| 两个 verifier 谁更贴近耳朵 | 逐实验一阶映射后比 rmse，F 检验（自由度扣减 n 取 1，原文 §7.6.4 与 §7.7 不一致，**我们定为一阶 n = 1**） | P.1401 §7.3.3、§7.6.4 [S13] |
| 一个 verifier 与耳朵的误差 | rmse\*（扣掉主观自身的 ci95）；单人时 ci95 用作者重测的离散度代替——**这只估同一个人的抖动，不等于标准要求的听者组 ci95**，结论只对作者成立 | P.1401 §7.7 |
| 排序一致 | 系统级与片段级 Spearman + Kendall τ；系统级为主（VoiceMOS 惯例），片段级用于 n 不够时 | VoiceMOS 2023 §4.1 [S42] |
| 成对方向一致 | 一致率 + Wilson 区间；**只用差距大的对**（VoiceMOS 2026：差距越小，预测器越难判对方向，CCR 最好 0.487）| [S42] |
| 一次门禁比很多格子 | Holm 校正 | P.1401 §7.6.5 |
| 作者自己的稳定性（天花板） | 每轮重放 2 段（rubric 4.1 已有），算重测一致率；verifier 的一致率不可能稳定高于它 | BS.1534-3 §4.1 [S7] |

### 2.3 防讨好（奖励被刷）

1. **定标集与验证集分开**：奇数轮的人耳数据用来定阈值与映射，偶数轮只用来验证（P.565 的「建库 / 训练 / 独立验证分开」思路 [S14]）。映射在验证集上不重拟合
2. **对抗样本**（每个感知 verifier 都要过）：rubric 第 7 节的三种人造劣化（削词首 50 ms、非语音段 −40 dB、1 kHz 低通）+ TS 103 281 表 D.1 的 NS Level 劣化锚点 [S25]。verifier 必须把劣化版判差
3. **训练用过的 verifier 降级**：rlenv 用某个 verifier 当奖励训练出的模型，在那个 verifier 上的分数不计入它自己的定标（Goodhart；007 已见 DNSMOS BAK 被刷高、arXiv 2402.01413 §6.2.5）。定标只用未拿它训练过的候选
4. **成对制衡**：每个奖励 verifier 配一个「制衡 verifier」（如压噪配吃字、MOS 配人声损伤），制衡项变差即奖励清零（rubric 硬规则 2 的推广）

## 三、verifier 清单

字段：**参考**＝需要什么输入（`clean` 干净参考 · `noisy` 带噪输入 · `out` 输出 · `tracks` 主讲人 / 干扰者 / 噪音三轨分存 · `text` 参考文字）· **成本**＝每 10 s 音频量级（DSP < 10 ms · 小模型 10–500 ms · ASR 秒级）· **可微**＝能否直接当训练损失（可微 / 可松弛＝换成软版本可微 / 不可微）· **初始级**＝今天的定标状态。

### 3.4 暂时拆不开的（只能靠耳朵）

金属声 / 机器人声（V-ROBOT 只是候选）· 颤音 · 附和声与笑声被吃（缺测试片段）· 「拿去开会能不能用」（H3，这是校准用的总标签，本身不拆）· 真会议里对方的感受（意向书真相源第 1 位，永远在 rubric 之上）。

## 四、给 rlenv 的接口

| 用途 | 放什么 | 条件 |
|---|---|---|
| **可行域（硬约束）** | V-LAT · V-FRAME · V-CPU · V-DROP · V-NAN · V-MUTE | 物理量，L3，越线即不可行 |
| **一票否决** | V-EAT-ASR（Δdel 区间下界 > 0） | 两家 ASR 任一触发 |
| **训练损失（可微且 ≥ L2）** | 候选：V-SPLVL · V-WEAK（软分位）· V-NR / V-DSN · V-ESTOI · V-SNG 模型 B | **今天都还是 L0** → 先只作正则项 |
| **奖励（不可微且 ≥ L2）** | 候选：V-SNG 模型 A · V-BGSTAB · V-MUSIC | 同上 |
| **约束（L0 / L1）** | 其余感知量，含 V-NRMOS | 只要求「不比基线差」，不鼓励刷高 |
| **人耳终审** | V-ROBOT 与 3.4 全部 · 所有 V-EAT-ASR 触发的片段 | — |

**rlenv 要遵守的**：第 2.3 节第 3 条（拿某 verifier 训练过的模型不参与该 verifier 的定标）；每个奖励项必须同时报它的制衡项。
