## 一、框架：一个主观词怎么变成一个程序

每个主观维度都走四层，任何一层写不出来，就停在那一层，交人耳：

| 层 | 问什么 | 例：「背景抽吸」 |
|---|---|---|
| 1 现象 | 人听到的是什么（用缺陷词汇表的话说） | 一开口背景被压下去，一停又涨回来 |
| 2 可观察量 | 现象在信号里留下什么痕迹 | 非语音段的噪声电平随语音起落而变化 |
| 3 算法 | 怎么从波形算出一个数 | P.1120 §11.14.5：35 ms 时间常数的噪声电平，在语音插入期间与之后的最大波动（dB）[S18] |
| 4 置信度 | 这个数和作者耳朵对得上多少 | 与人耳标签 `pumping_bg` 的一致率、与 H2 的片段内排序一致，带 95% 区间 |

**两类 verifier，置信度来源不同：**

- **物理量**（延迟、耗时、掉帧、NaN、静音全零）：判的是事实，不需要人耳。置信度 = 重复测量的离散度。直接 L3。
- **感知量**（其余全部）：判的是「人会不会觉得」。置信度只能来自人耳数据。**没有人耳数据的感知量 verifier 一律 L0，不管它在论文里多有名。**

## 二、定标状态（置信度怎么定）

### 2.1 四级

所有判级都用**累计的验证集**（见 2.3 第 1 条），不按单轮判——一轮只有约 12 段，单轮连 L1 都判不了。

| 级 | 含义 | 判据 〔建议值〕 | 能拿来做什么 |
|---|---|---|---|
| **L0 未定标** | 没有或不够人耳数据 | 有效配对数 < 20 | 报警、挑必听段、rlenv 的**约束**（不许比基线差），不能当奖励、不能当门禁 |
| **L1 方向对** | 它说 A 比 B 好时，耳朵大多也这么说 | 成对方向一致率的 95% 下界 > 0.5，配对数 ≥ 20；区间用**按屏聚类的 bootstrap**（同屏的配对不独立） | 回归门禁的**报警**项；rlenv 过渡期能否当弱奖励由人定（拍板 #9） |
| **L2 排序对** | 在同一片段里，它给候选的排序与耳朵一致 | **片段内**排序一致：每段内 verifier 与人耳对候选的 Kendall τ，跨段取均值；按片段 bootstrap 的 95% 下界 ≥ 0.2，验证集片段数 ≥ 30；另需 L1 | 回归门禁的**阻断**项（感知类）；rlenv 奖励 |
| **L3 门禁级** | 排序对，且误差小、对抗样本不翻车 | L2 + P.1401 §7.7 rmse\*（逐实验一阶映射后）达标 + 2.3 的对抗样本全部判对。**前提：人耳用了 P.835 三量表（拍板 #2），且有多轮累计的重测数据可估 ci95**——AB 选择与 3 级 H3 不是 MOS 刻度，算不了 rmse\* | 对外报告可写「经作者听测定标」；rlenv 主奖励 |

物理量 verifier 直接记 L3（判据：5 次重复的 95% 区间半宽 < 档位间距的 1/4）。

**为什么不用跨片段的相关**：一段里有 3 个候选，片段之间的 SNR 差异会同时拉动指标和耳朵——一个只量输入 SNR、根本分不出候选好坏的 verifier 也能拿到高相关。所以 L2 只比**同一片段内**的候选排序（或先扣掉片段均值）。

**配对从哪来**（L1）：① AB 页上被选为「最 X」的候选对同屏其他候选各一对（rubric 4.3，没被选的两个之间无信息）；② H3 在同屏里等级不同的两个候选。只用**人耳分差**达到预先冻结规则的对（如 H3 差 ≥ 1 级），**不按 verifier 自己的分差筛**——按自己的分差筛等于自证。

**样本量参考**（本机算的，**按独立样本的乐观估计**；聚类 bootstrap 的真实区间会更宽）：

| 配对数 n | 一致率 70% 时下界 | 75% | 80% |
|---|---|---|---|
| 12 | 0.42 | 0.47 | 0.52 |
| 20 | 0.48 | 0.53 | 0.58 |
| 30 | 0.52 | 0.57 | 0.63 |
| 40 | 0.55 | 0.60 | 0.65 |

所以一轮 12 屏判不了任何东西；一个感知 verifier 到 L1 至少要 2–3 轮验证数据，到 L2（验证集 ≥ 30 段）约 **5–6 轮**（定标与验证各占一半轮次）。**近期不会有感知类 verifier 达到 L2，rlenv 的感知项在相当一段时间里只能是约束。**

### 2.2 统计方法（全部本机、确定性、种子固定）

| 用途 | 方法 | 出处 |
|---|---|---|
| 两个 verifier 谁更贴近耳朵 | 逐实验一阶映射后比 rmse，F 检验（原文 §7.6.4 与 §7.7 对自由度扣减数 n 前后不一致，**我们定为一阶 n = 1**）；需要 MOS 刻度（三量表）| P.1401 §7.3.3、§7.6.4 [S13] |
| 一个 verifier 与耳朵的误差 | rmse\*（扣掉主观自身的 ci95）；单人时 ci95 用作者多轮累计重测的离散度代替——**这只估同一个人的抖动，不等于标准要求的听者组 ci95**，结论只对作者成立 | P.1401 §7.7 |
| 排序一致 | 片段内 Kendall τ（主）；候选够多时加系统级 Spearman（VoiceMOS 惯例）| VoiceMOS 2023 §4.1 [S42] |
| 方向一致 | 一致率 + 聚类 bootstrap 区间 | [S42]：差距越小越难判对方向（CCR 最好 0.487）|
| 一次门禁比很多格子 | Holm 校正（统计惯例；P.1401 §7.6.5 讲的是比较多个算法时的校正，只作旁证）| — |
| 作者自己的稳定性 | 每轮重放 2 段，**多轮累计**估作者的翻转率 f；理论上一个完全正确的 verifier 与作者的一致率约为 1 − f（而作者前后两次的一致率约为 (1 − f)² + f²，**比它低**）——所以重测一致率不是 verifier 的上限，而是用来换算「一致率能到多高」| BS.1534-3 §4.1 [S7] |

### 2.3 防讨好（奖励被刷）

1. **定标集与验证集分开、按轮累计**：奇数轮的人耳数据定阈值与映射，偶数轮只验证；判级与降级都用**历轮验证集的累计数据**。每轮挑段时一半随机、一半挑「verifier 之间打架」或「接近档位边界」的段——**判级只用随机那一半**（挑出来的段会让相关偏低或偏高）
2. **对抗样本**：每个感知 verifier 都要把下列劣化版判差——rubric 第 7 节三种人造劣化（削词首 50 ms、非语音段 −40 dB、1 kHz 低通）· TS 103 281 表 D.1 式的谱减劣化（实现见 decision 升级 #2 的说明）· **一份不进仓的隐藏集**（仓外存放，仓里只留哈希）· **rlenv 产出的高奖励样本**（见第 5 条）。固定、公开的对抗集会被策略和 verifier 一起过拟合
3. **训练用过的 verifier，不拿训练产物给它升级**：拿某个 verifier 当奖励训练出的模型，其输出不计入该 verifier 的**升级**数据（Goodhart；007 已见 DNSMOS BAK 被刷高、arXiv 2402.01413 §6.2.5）。但**降级**要看它（第 5 条）
4. **成对制衡**：每个奖励 verifier 配一个制衡 verifier（压噪配吃字、MOS 配人声损伤、电平配动态范围）。「制衡项变差」= 相对基线的配对 bootstrap 95% 下界 < −δ（δ 每个 verifier 单设，〔待人定〕）；变差即该步奖励清零
5. **同策略审计（rlenv 必做）**：每一轮人耳听测里，固定放 N 段（〔建议值〕N = 3）**当前 RL 策略奖励最高的输出**，与基线模型同屏比。人耳判它不比基线好、而奖励说好 → 该奖励 verifier 直接降到 L0，开 issue。理由：被刷的恰好是分布外的输出，只有把它们放回人耳面前才查得出

## 三、verifier 清单

字段：**参考**＝需要什么输入（`clean` 干净参考 · `noisy` 带噪输入 · `out` 输出 · `tracks` 主讲人 / 干扰者 / 噪音三轨分存 · `text` 参考文字）· **004 能否提供**＝现在的评测链有没有这份输入 · **成本**＝每 10 s 音频量级（DSP < 10 ms · 小模型 10–500 ms · ASR 秒级）· **可微**＝在我们 Rust + ONNX 路线下能否直接当训练损失（可微 / 可松弛＝换成软版本才可微 / 不可微）· 今天**全部感知量都是 L0**。

## 四、给 rlenv 的接口

| 用途 | 放什么 | 条件 |
|---|---|---|
| **可行域（硬约束）** | V-LAT · V-FRAME · V-CPU · V-DROP · V-NAN · V-MUTE | 物理量，L3，越线即不可行 |
| **一票否决** | V-EAT-ASR 的 Δ(del + sub)（区间下界 > 0；段数不足算区间时视为不通过）| 两家 ASR 任一触发 |
| **训练损失（可微或可松弛，且 ≥ L2）** | 候选：V-SPLVL · V-WEAK · V-NR / V-DSN · V-ESTOI · V-SNG 模型 B | **今天都是 L0** → 只能作正则项或约束 |
| **奖励（不可微，且 ≥ L2）** | 候选：V-SNG 模型 A · V-BGSTAB · V-MUSIC（后两者原版不可微，松弛版可作损失）| 同上 |
| **约束（L0 / L1）** | 其余感知量，含 V-NRMOS | 只要求「不比基线差」（2.3 第 4 条的 δ），不鼓励刷高 |
| **人耳终审** | V-ROBOT 与 3.4 全部 · 所有 V-EAT-ASR 触发的片段 · 2.3 第 5 条的同策略审计段 | — |

**近期事实**：按 2.1 的样本量，感知类 verifier 到 L2 约要 5–6 轮听测。在那之前，rlenv 的正向信号只能来自物理量和「不比基线差」的约束；L1 能否作弱奖励由人定（拍板 #9）。

**rlenv 要遵守的**：2.3 第 3、4、5 条；每个奖励项同时报它的制衡项。
