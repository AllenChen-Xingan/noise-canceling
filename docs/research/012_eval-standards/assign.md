## 每路共用的四件事

- **逐条核查**：每个标准写六栏——现行版本 · 管什么 · 怎么测（信号 / 条件 / 指标 / 通过线，带条款号）· 能否本机离线复现 · 许可费用 · 对我们有用的条款
- **证据格式**：官方明载（URL + 条款号）/ 论文（arXiv 或 DOI + 节号）/ 传言
- **字数上限**：调研 ≤ 2500 字，怀疑派 ≤ 1800 字
- **必须给判断**：本路最值得借的 3 件事（带条款号）

## 写死的护栏

- 子代理**不许构建或运行任何程序**、不许安装、不许写文件、**不购买付费标准**
- 只认一手：标准原文、标准组织官方页、厂商官方文档、论文；二手标「传言」
- 怀疑派默认怀疑：拿不出原文出处的一律「未能核实」；专核编号、版本、现行状态、条款号与数字
