# ASCEND（中英夹杂自发对话语料）

- **名称**：A Spontaneous Chinese-English Dataset for Code-switching in Multi-turn Conversation（ASCEND）
- **链接**：https://huggingface.co/datasets/CAiRE/ASCEND
- **许可**：Creative Common Attribution Share-Alike 4.0 International (CC-BY-SA 4.0)（HF 数据卡原文）→ 结论：只评测【官方文档】
- **大小**：10.62 h · 12,314 句（train 9,869 / validation 1,130 / test 1,315）· 26 场对话 · 23 人【官方文档 · 论文 摘要、§1】；GB 未查到
- **场景键**：other（香港一间安静教室）
- **设备键**：close-talk（每人一支 RODE SmartLav+ 领夹麦，夹在衣领上）
- **笔记本段**：没有。全部用领夹麦录，每人一路单声道 16 kHz WAV；无笔记本、无手机【论文 §3.1】
- **干净参考**：没有（发布的就是领夹近讲本身，论文称「clean speech」；无远场通道可配对）
- **转写**：有（人工逐句转写，中文汉字 / 英文字母混写；按语义边界或长停顿切句；HF 数据卡未见时间戳字段，未查到）【论文 §3】
- **语种**：普通话 + 英语（句内、句间夹杂）；说话人含香港、台湾、大陆多地口音
- **语体**：两人自发多轮对话（话题：教育、个人、哲学、体育、科技）；语气词按规范统一标作 ah / oh / um，HF 示例转写里可见「嗯」；笑声、附和（对）是否单独标未查到；情绪语音未查到【论文 §3】
- **获取方式**：直接下载（HF 页面未见申请门控）
- **与 D62 的关系**：真实录音（真人面对面对话，领夹近讲；非回放、非合成）。若开发阶段拿来评测，可用 test 1,315 句做中英夹杂口语的语音识别吃字检查底料（需自己叠噪声）；体积未查到，按 10.62 h、16 kHz 16-bit 单声道约 1.2 GB【推断】
- **出处**：https://huggingface.co/datasets/CAiRE/ASCEND【官方文档】; https://arxiv.org/abs/2112.06223 摘要、§1、§3.1【论文】

## 备注
- 本路原调研漏掉。对本项目的价值在「中文自发对话 + 夹英文术语」，接近开会时的说话方式；但录音是领夹近讲、安静教室，本身无噪声、无笔记本麦。
- 论文写 23 人，HF 预览里 `original_speaker_id` 编到 26，二者口径不一，未裁定。
- 怀疑派复核：本卡由怀疑派补写，许可读 HF 数据卡原文，设备与环境读论文 §3.1。
