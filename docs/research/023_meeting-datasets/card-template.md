# 数据卡模板（023 · check_cards.py 按此校验字段）

> 每份数据集一张卡，文件名 `cards/<英文小写-连字符>.md`。14 个必填字段，格式固定为 `- **字段**：值`，字段名一字不改、顺序不变。查不到写「未查到」，不许空着。
> 场景键、设备键只认 021 / 022 两份正本，见下节。

## 场景键与设备键
不在这里抄。场景键正本：`docs/research/021_meeting-scenes/catalog.md` 键表第一列；设备键正本：`docs/research/022_mac-mic/devices.md` 键表第一列。`check_cards.py` 只认本仓库这两处；合并前本仓库还没有时，设环境变量 `VDN_KEYS_DIR` 指向含它们的 docs/research 目录（多个用 `:` 分隔），没指就报错。`other` 只给数据卡用，不算开会场景。

## 卡片格式

```
# <数据集全名>

- **名称**：<全名（简称）>
- **链接**：<官方页 URL>
- **许可**：<许可原文名> → 结论：训练可 / 只评测 / 不可 / 未查到【来源标签】
- **大小**：<小时数 · GB · 条数>
- **场景键**：<键，逗号分隔>
- **设备键**：<键，逗号分隔>
- **笔记本段**：<有没有笔记本 / Mac 内置麦录的段 · 能不能按设备筛出来>
- **干净参考**：有 / 部分 / 没有（<说明>）
- **转写**：有 / 部分 / 没有（<有无时间戳>）
- **语种**：<语种>
- **语体**：<朗读 / 对话 / 会议；有无笑声、附和、情绪语音>
- **获取方式**：直接下载 / 注册 / 签协议 / 付费 / 已下架（<一句>）
- **与 D62 的关系**：<只列事实：它是真实录音还是回放 / 合成；开发阶段若用它评测会用到哪部分。不下结论>
- **出处**：<URL【官方文档 / 论文 / 论坛 / 推断】，多条用 ; 分隔>

## 备注
<自由文字：接近度、坑、怀疑派复核记录>
```

## 来源标签
【官方文档】【论文】【论坛 / 博客，个人说法】【推断】
