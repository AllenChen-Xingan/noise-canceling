**对我们（N = 3–5 个系统）意味着什么**（推导）：
- 主动选对的收益在 N 大时才显著（ASAP 的数字都是 N = 20 / 200）。N = 3 只有 3 对，「选哪对」退化成「**把题集中给后验最不确定（分差最小）的那一对**」，这正是 EIG 的极限行为。
- 我们真正的瓶颈不是排 3 个系统，而是**定标 verifier 的一致率**。这要的是「随机代表性的配对」，主动选对会让样本偏向难对（分差小、机器与人都更容易错），**让一致率系统性偏低**。所以：**主动层与随机层必须分开记**，一致率只用随机层算——与 `exp007-eval-suite/README.md:140` 所列未实现项「calib 只用随机那一半」是同一件事。
- 只排名次时，3 个系统、相邻对真实偏好 0.65 vs 0.5：单对检出（α = 0.05，功效 0.8）约需 (1.96 + 0.84)² × 0.25 / 0.15² ≈ **87 次**该对比较（推导，标准二项功效计算）。exp003 头对头胜负（dpdfnet2 vs gtcrn 2:5:5 平）离这个量还差一个数量级。

**把「重复不一致率」换成「单人上限」**（推导，假设噪声对称且两次独立）：
- 设作者对某对选「真偏好」的概率为 q，则同一对两次答得一样的概率 c = q² + (1 − q)²，于是 q = (1 + √(2c − 1)) / 2。
- 任何 verifier（哪怕完美知道作者的「真偏好」）与作者单次答案的期望一致率**上限就是 q**。
- 用 Wells 的 27%（每人 2 道重复）粗估：若每道重复独立不一致率为 x，1 − (1 − x)² = 0.27 → x ≈ 0.146 → c ≈ 0.854 → **q ≈ 0.92**（推导，人群平均，TTS 自然度，非我们的场景）。
- 我们的配对很多是**难对**（3 个降噪系统分差小，exp003 有 25–33% 的屏答「分不出」），作者的 c 很可能远低于 0.85。若 c = 0.7，则 q ≈ 0.82；c = 0.6 → q ≈ 0.72（推导）。**这就是「一致率 0.48–0.64」该拿来比的天花板**——目前不知道，必须测。

**解读**（推导）：
- 助听器那 10–20 次是在**低维参数空间**（≤ 4 维）找一个人的最优点，不是学一个通用的「这段降噪好不好」判别器——不能直接搬。
- 直接学成对偏好在**有 1.7 万对**时换数据集就掉到抛硬币附近（PrefNet 46.6%）。我们最多攒几百对，所以虚拟听众只能是**冻结大模型特征 + 极小的头**（例如 URGENT-PK 冻结 UTMOS 特征之上的逻辑回归 / Bradley–Terry 头），能学的只是「作者在已有特征里更看重哪几维」。
- 判它有没有用，看的是**留出轮次上的一致率**，要和作者自己的重测上限 q（③）比，而且必须过 012 的 L1（`verifiers.md:32`）。在过之前一律标「假设」。

| 主动层 | 2 | 按 Bradley–Terry 后验选 EIG 最大的系统对（N ≤ 5 时就是分差最小的那对），片段随机 | 排名次；**不进**一致率统计 |
| 重测 | 1 | 重放 ≥ 1 天前的某道随机层题，**左右对调** | 单人隔天重测信度 c |
| 空对陷阱 | 每 2 天 1 | 两边同一文件（应答「分不出」） | 场次有效性 |

- 答案选项：A 更好 / B 更好 / 分不出 + 两级信心（「确定」/「勉强」）。「分不出」在随机层记作 0.5 而不丢弃（推导：丢弃会让难对从一致率里消失，抬高一致率）。是否允许「分不出」影响统计口径，列入待拍板。
- 时长依据：AB 题约 20 秒 / 题（Wells 2024 §4.1，TTS）；我们的片段带原声参考，按 30–40 秒 / 题估（假设）→ 8 题约 4–5 分钟。
- 构建与揭盲表照 CLAUDE.md 第五节第 1 条：每场一个 build id、对照表进 `docs/experiments/<实验>/builds/`、答卷进 `results/`。

### 6.2 怎么测、怎么报信度

- **重测自一致率 c**：重测对数 ≥ 20 后报 c、Cohen κ、按天聚类的 bootstrap 区间；同时报单人上限 q = (1 + √(2c − 1)) / 2（推导）。
- **报 verifier 一致率时并列报 q**：「V-X 一致率 0.64 [区间]，作者自一致上限 q = …」；一致率接近 q 说明机器已经和作者自己一样准，剩下的是作者本人的噪声，再听也提不高。
- **锚点命中率**：每 10 场看一次；锚点被判错 > 1 次 / 10 场 → 暂停，检查耳机与环境。
- **漂移**：按周算随机层的 BT 分，若同一系统对的偏好方向翻转，标为「标准漂移」，不合并跨周数据。

### 6.3 作者再听多少题，一致率区间能缩到 ±0.1

本机蒙特卡洛（β-二项聚类、ρ = 0.33 使 9 屏时半宽 ≈ 0.20，贴合 exp003 实测 0.22；p = 0.5；聚类 bootstrap 300 次 × 60 次重复；脚本在 scratchpad，未入库）：

| 设计 | 半宽 ±0.1 所需 | 推导出处 |
|---|---|---|
| 照 exp003（一屏 4 个候选 → 约 5 对，聚类） | **约 40–45 个有信息的屏**（40 屏 → ±0.103；45 屏 → ±0.097）；按 25% 屏答「分不出」再加约 1/3 → **约 55–60 屏 ≈ 75–80 分钟**（按 80 秒 / 屏） | 【本机实测】（模拟） |
| 一题一对的随机层 2AFC（独立） | **约 100 题**（100 题 → ±0.096；解析式 1.96² × 0.25 / 0.1² ≈ 96） | 【本机实测】（模拟）+ 标准公式 |
| 按 6.1 每天 4 道随机层题 | **约 25 天**；若一天两场（10 分钟）约 13 天 | 推导 |

注意（推导）：
1. ±0.1 只保证区间宽 0.2；若真一致率只有 0.55，区间仍会跨过 0.5，**判不出 L1**。要证明一致率 > 0.5，真值 0.65 时需要下界 > 0.5 → 约 40 题独立 2AFC（012 `verifiers.md:44-49` 的样本量表同量级）。
2. 一屏多对看着题多，其实 DEFF ≈ 2.4，每屏只顶约 2 道独立题。**同样 5 分钟，一题一对比一屏四候选更省**（一屏 80 秒约换 2.2 道独立题 ≈ 36 秒 / 题；一题一对 30–40 秒 / 题，持平或略好，且无聚类、无「全屏答 same 浪费」）。
3. 重测与锚点开销约占 25–30%，已计入「每天 4 道随机层」的安排。

## ⑧ 待人拍板

1. 每日 5 分钟微场次是否可行（还是维持每轮约 20 分钟的大场次）？——默认：微场次，因为一题一对更省且能量隔天重测。
2. 答「分不出」是否保留？保留则记 0.5（推导上更诚实）；去掉则强迫选择，信息更多但难对噪声更大。——默认：保留 + 两级信心。
3. 虚拟听众要不要做：证据只够做「冻结特征 + 小头」的假设实验，公开文献没有单人少样本的成功先例（**未查到**）。——默认：等 V-SELF-RETEST 攒到 ≥ 20 道重测、知道 q 之后再做。
