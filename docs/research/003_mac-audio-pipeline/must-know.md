## 三、哪些看起来相关，但知道了也不改变这个决定

- 降噪模型本身选哪个（DFN3 / DPDFNet）——归 002 模型线，管线只要求「每 10 ms 一帧、固定大小、可替换」
- 评测指标怎么算——归 004 评测线
- 菜单栏 app 的 UI——设计稿 §16「无障碍」已定先做命令行（`:704-706`）
- 回声消除（AEC）的算法细节——本线只回答「参考信号拿不拿得到、时钟对不对得上」，不比 AEC 算法
- Neural Engine / CoreML 推理速度——归 002；本线只回答线程该放哪
- 多声道、空间音频、虚拟输出设备（我们只要一个单声道或立体声虚拟**输入**）
- Windows / Linux 的做法（意向书「不做什么」）
