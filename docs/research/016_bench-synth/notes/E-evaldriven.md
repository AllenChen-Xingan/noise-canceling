# E · 按评测格倒推训练数据的先例

> 016 子题 E。范围：「先定评测集 / 失败切片 → 再按它合成训练数据」的先例；单因素 / 多因素网格评测；防泄漏。
> 不重复 015 B-synth-data（Landini 2022、pDNS、URGENT 参数已在那里）与 012 verifiers（定标、P.1401）。
> 证据等级：【官方】【论文】【源码】【实测】【二手】【推断】。凡只读了摘要的标「摘要」。

## 开头 5 行结论

1. **最直接的语音先例是 CHiME-3/4**：模拟集逐条对齐真实录音（同一句子、同一 SNR、跟踪说话人位置生成时变延迟滤波、噪声取同一环境），并明确把判据定为「**模拟集上的相对提升能否预测真实集上的相对提升**」，而不是绝对 WER 相等；结果大多数方法一致，唯独 MVDR 在模拟上大涨、真实上几乎不涨（表 4，dev GMM 后端：无增强 真实 18.70 / 模拟 18.71 → MVDR 真实 18.20 / 模拟 10.78）。原因是**作者的归因**：模拟只用纯延迟、缺早期反射与混响；作者在结论节自己说补上这些后 MVDR 会怎样「是开放问题」，所以这条是假设，没有验证【论文 Vincent 2017 CSL §2.3.2、§3.1、§3.2.1、表 3–4、结论节】。这正是 016 缺的「合成格排名 ≈ 真实排名」检验，也给出了一种可能的失效模式：**合成器漏掉的物理因素会让某类方法在合成格上虚高**。⚠️ 迁移时注意：CHiME 量的是**多通道 ASR 的 WER**，MVDR 是多麦方法；本项目是单麦 SE，尺子是感知质量。所以这里只能借判据的形状，具体数字不能搬【推断】。
2. **「按评测格造训练数据」有明确的反面教训**：ImageNet-C 原文要求「不要在这些失真上训练」，另留 4 种验证失真（speckle/gaussian blur/spatter/saturate）【论文 arXiv 1903.12261 §4.1、附录 B】；Mintun 2021 证明与 ImageNet-C 感知相似的增强会虚高分数，换到「感知不相似」的 ImageNet-C̄ 后 AugMix 错误率 +3.2、Patch Gaussian +7.3 点，基线 −0.4【论文 arXiv 2102.11273 §5、表 1】。→ 016 必须有一份**生成器 / 素材都没见过的留出格**。
3. **ML 侧正解是「对齐统计量 / 只随机化虚假因素」，不是复制样本**：targeted augmentation 只随机化「随域变、但不预测标签」的特征、保留「随域变且有用」的特征。三个真实数据集上，它比**最强基线**的 OOD 成绩高 3.2–15.2 个百分点（这是对最强基线的差，不是对「不增强」的差）。其中 BirdCalls 是音频：把鸟叫贴到**同一地区**的其他训练录音上，再抖增益；消融实验里改成「不分地区」乱贴，OOD 降 4.1%【论文 arXiv 2302.11861 摘要、§3.1、§5.1】。理论部分（定理 1–4）只在线性设定下证明【论文 §4】；sim-to-real 一系（SimOpt、BayesSim、Meta-Sim、Learning to Simulate）都是用少量真实数据**反推模拟参数分布**，而不是把真实样本塞进训练【论文，均为摘要】。
4. **网格评测的标准形状是「因素 × 档位 + 自然场景并列」**：ImageNet-C 15 类 × 5 档 = 75 格、按 AlexNet 归一化成 mCE【论文 1903.12261 §4】；Speech Robust Bench 114 个场景、噪声类 4 档（表 2：30/20/10/0 dB），并把 CHiME-6 / AMI 真实录音作为「自然扰动」与合成扰动同表，指标 NWERD 用 DNSMOS/PESQ 估难度做归一化【论文 arXiv 2403.07937 §3.1–3.2、表 2】。交叉格的裁剪依据来自软件组合测试：多数故障由 1–2 个参数触发，t-way 覆盖可比穷举少 20–700 倍用例【官方 NIST ACTS 页】。
5. **空白**：没找到语音增强领域「先定失败切片 → 按切片合成训练数据 → 再验证真实排名」的完整闭环论文；没找到在 SE/ASR 鲁棒性 benchmark 里正式用正交表 / 部分因子设计挑交叉格的先例；没找到把 SimOpt/BayesSim 式参数反推用在音频合成器上的论文。DNS 2022 个性化赛道的 dev 测试集按「主讲+噪声 / 主讲+邻座+噪声 / 主讲+邻座无噪」分格，**而且这 1443 条是众包的真实录音**（按场景布置后实录，不是加法混合，台式机 / 笔记本录制）；盲测集正文没报格子分布【论文 arXiv 2202.13288 §3.2.2、§3.3】。→ 它可能是一份带场景标签的现场录音锚，许可要去 014 查【推断】。

## 二、ML 一般方法

| 方法 | 核心做法 | 数字 | 出处 · 等级 |
|---|---|---|---|
| **Targeted augmentation**（Gao 等） | 特征分三类：域无关 / 随域变但虚假 / 随域变且有用。只随机化「虚假的域相关特征」，保留「有用的域相关特征」。**BirdCalls（音频）**：用时频框切出鸟叫，贴到**同一地区**的空录音上（跨麦克风换背景，但保留地区栖息地噪声如虫鸣），再抖频谱色调模拟增益变化 | OOD（对**最强基线**，不是对不增强）：iWildCam Macro F1 33.3→36.5；Camelyon17 平均准确率 75.3→90.5；BirdCalls Macro F1 31.8→37.8。原文是「同地区的其他训练录音」，不是「空录音」；消融「不分地区」OOD −4.1%（BirdCalls）、−1.8%（iWildCam 不分背景） | arXiv 2302.11861 §3、§5【论文】 |
| 同上 · 理论与反例 | 训练域数 D < 域特征维度时欠定（定理 1）；targeted 增强后超额 OOD 风险 O(log D / D)（定理 2）。通用增强（RandAugment/MixUp/CutMix/SpecAugment）不随机化域特征，无限数据下等于不增强（推论 1），实验里 MixUp/CutMix/SpecAugment 有的反而变差；「域不变增强」把有用的域特征也抹了，OOD 风险不随 D 下降（定理 4） | — | 同上 §4.1–4.3【论文】 |
| **Slice-based Learning** | 用切片函数（slicing function）声明关键子集，给每个切片加专家表示 + 注意力合成 | 切片上最多 +19.0 F1，整体 +4.6 F1 | arXiv 1909.06349 摘要【论文·摘要】 |
| **Domino 切片发现** | 用跨模态嵌入 + 误差感知混合模型自动找表现差的连贯子集，并用自然语言命名 | 1235 个设置里找对 36%，比先前方法高约 12 点；35% 设置给出确切切片名 | arXiv 2203.14960 摘要【论文·摘要】 |
| **Domain randomization**（Tobin 2017） | 渲染参数随机化到「真实只是又一种变体」 | 纯模拟训练的检测器在真实中定位误差 1.5 cm | arXiv 1703.06907 摘要【论文·摘要】 |
| **Automatic DR**（OpenAI 2019） | 自动逐步扩大随机化范围，环境越来越难 | 未读正文，扩展规则细节没核 | arXiv 1910.07113 摘要【论文·摘要】 |
| **SimOpt**（Chebotar 2019） | 用少量真实 rollout 交替更新模拟参数分布，使模拟中行为贴近真实 | 未读正文 | arXiv 1810.05687 摘要【论文·摘要】 |
| **BayesSim**（Ramos 2019） | 无似然推断，从真实轨迹得模拟参数后验，用后验做随机化，优于均匀先验 | — | arXiv 1906.01728 摘要，RSS 2019【论文·摘要】 |
| **Meta-Sim**（Kar 2019） | 网络改场景图属性，最小化渲染输出与目标数据的分布差；有小标注验证集时再优化下游任务表现 | — | arXiv 1904.11621 摘要【论文·摘要】 |

## 对 016 的启示（可转成格子或检查项）

> 下面每条都是【推断】，由上表先例迁移而来，需 016 主线拍板。

**benchmark 格子**

1. **主表 = 因素 × 档位（单因素层）**，照 ImageNet-C / SRB：每个因素（噪声类型、SNR、邻座 SIR、混响 RT60、麦响应 / 增益、重叠率）固定 4–5 档，同档内样本随机化；分数按一个固定参考系统（如 RNNoise 或现有基线）归一，得「每因素相对误差」，再平均成单一数——便于跨版本比。
2. **自然场景格与合成格同表**（SRB 做法）：014 的真实录音（CHiME-6 / AMI 等）单列一栏「自然」，不混进合成平均。
3. **交叉层用 pairwise 覆盖**：NIST 经验是 1–2 因素交互占大头 → 多类层先做全部两两交叉的覆盖阵（而非全因子），三阶只挑「邻座人声 × 低 SNR × 混响」这类先验上交互最强的少数格。
4. **借 DNS dev 集的场景切法**：「主讲+噪声 / 主讲+邻座+噪声 / 主讲+邻座无噪」三格直接可用，补上「邻座无噪」这一常被忽略的格。

**合成数据检查项（verifier 候选）**

5. **排名一致性 verifier（CHiME 判据）**：不要求合成格绝对分 = 真实分，只要求「若干系统在合成格上的相对提升 / 排名」与真实集一致（如 Kendall τ），这是合成集合格的第一判据。没有真实录音的格写「尚无判据」。
6. **漏掉物理因素清单**：CHiME 的 MVDR 案例说明「合成器漏的因素 → 某类方法虚高」。每版合成器要附「未模拟因素」列表（如麦响应、早期反射、AGC、设备回采），并在真实格上专门盯依赖这些因素的方法。
7. **防泄漏三条硬检查**：① 测试格的语音 / 噪声素材源与训练素材源不重叠（按文件哈希 + 说话人 ID 核）；② 训练只对齐**统计量**（SNR 分布、重叠率、RT60 分布），不用测试样本本身；③ 留一套「训练用生成器没见过」的格（换噪声库 / 换 RIR 来源 / 换合成方法），照 ImageNet-C 验证失真与 ImageNet-C̄，难度对齐、感知不相似。若模型在主格涨、留出格不涨，判为过拟合评测格。
8. **只随机化虚假因素**（targeted augmentation）：对本项目，麦增益、设备频响、录音底噪属于可随机化的虚假因素；「咖啡馆 / 邻座人声」这类与场景绑定的背景属于有用的域因素，应按场景成套保留（BirdCalls「同地区背景」类比），不要全随机打散。
9. **参数反推而非手调**：可做一个有界实验——用少量真实录音的可测统计量（SNR、重叠率、RT60、频谱倾斜）当目标，按 BayesSim / SimOpt 思路调合成器参数分布，再用第 5 条检验排名一致性是否变好。
