## 五行结论

1. **分布对齐没有公认阈值**：LTAS、调制谱、电平、T60/DRR、FAD/KAD 都只能和「真实对真实」的距离比。可借的是 BAT 数据驱动阈值的**思路**：BAT 原文是把目标 benchmark 的「一致性分数」放进「其他 benchmark 对同一参考的一致性分数分布」里算 z，z > −1σ 算一致【论文 2407.13696 §4】；把它挪到「合成对真实的距离 vs 真实对真实的距离分布」是本笔记的移植【推断】，且距离越小越好，方向要反过来写成 d_sr ≤ 均值 + 1σ（或 ≤ 95 分位）。能用的感知 JND 只有两个：T60 约 5%【二手，ISO 3382-1 附录，未见原文】，DRR 在 0 / +10 dB 参考点 2.4 / 3.8 dB（宽带噪声、150 ms 起音；10 ms 起音时为 2.4 / 2.7 dB）【论文 Larsen 2008 Exp.1】。
2. **FAD 用在我们的规模上有偏，而且选错嵌入就错**：偏差按 O(1/N) 变化【论文 2502.15602 §2.1】，在音乐生成的逐曲 FAD 上，VGGish 与 AQ / MQ 听测 MOS「相关性不好」（原文 does not correlate well，数值只在图 5）【论文 2311.01616 §4.4】。要用就用 FAD∞ 外推，或者改用无偏的 KAD（MMD；Foley 生成任务、9 个系统上 Spearman 最高 −0.93，FAD 最高 −0.80）【论文 2502.15602 §4.1、图 3】——注意 −0.93 是在同 9 个系统上挑出的最好嵌入（PANNs-WGLM），n = 9 的置信区间很宽，而且不是语音增强任务。嵌入必须先在我们自己的人耳答卷上定标，否则一律记 L0。
3. **把排名一致当效度，ML 和语音都有先例，结果正反都有**：ImageNetV2 上排序「几乎完全保持」【论文 1902.10811 §1】；accuracy-on-the-line 的 R² 为 0.881–0.997【论文 2107.04649 表 1，注意表 1 只收「成线」的配对】，但 Camelyon17（真实的跨医院染色差异，不是合成劣化）和 CIFAR-10-C 各向同性高斯噪声（合成劣化）不成线【论文 2107.04649 §4.1、§4.2】。语音方面，Clarity 2023 的仿真评测集 Eval1 和实测房间评测集 Eval2 之间，10 个条目的 Kendall τ-a 为 **0.31**【实测，据 2311.14490 表 1 计算】；但这主要由 E28 一个条目塌掉（Ave 0.653 → 0.022）拉低，去掉它 τ = 0.53；10 个条目里有同队变体（E28/E28d、E29/E29r）不独立；而且 Eval2 也是「语音与噪声分开录、再按 SNR 混」，不是现场同时录音【论文 2311.14490 §2、§4】。CHiME-7 UDASE 上 DNSMOS 最好的 CMGAN 在听测里最差，原文归因于 CMGAN 训练时直接优化 DNSMOS（指标被刷）【论文 2402.01413 §6.2.5】。
4. **只靠系统数救不了 τ**：观测 τ = 0.8 时，要让 95% 下界过 0.5 得有 ≥ 10 个系统；τ = 0.7 要 ≥ 21 个；τ = 0.6 要 ≥ 86 个【实测（计算），Fieller 近似，复核已重算一致】。玩具模型蒙特卡洛显示，即使真实效度 ρ = 0.95，12 个系统、每格 30 段时 τ 中位数也只有 0.70，5 分位约 0.45–0.48【实测（模拟），噪声/差距比 1.5 是假设，不是测出来的；复核重跑得 0.70 / 0.45】。BAT 建议至少 10 个模型、随机抽，并报告多种粒度【论文 2407.13696 §4】。
5. **效度要分级记录，不能只记「合格 / 不合格」**：可以借 V3 框架（verification → analytical → clinical validation）【论文 Goldsack 2020 npj Digit Med 3:55】，再加上 012 的 L0–L3，排成 **S0 未检 → S1 分布对齐 → S2 劣化方向对 → S3 系统排名与真实录音一致 → S4 排名与人耳一致**。目前项目里所有片段都是加法混合，最高只到 S2；S3 和 S4 需要现场录音。

| FAD 的用法 ③ 逐条 | 逐条算 FAD 来抓离群样本 | 用来筛掉坏合成样本 | 2311.01616 摘要、§5【论文】 |
| KAD | 无偏 MMD²×100，RBF 核带宽取参考集两两距离的中位数 | 与样本量无关，不需要外推；DCASE 2023 T7 上 9 个系统，Spearman 最高 −0.93（FAD −0.80）；d = 2048、N = 100 时 CPU 耗时 6.8 ms（FAD 1776 ms）；但 d = 128、N = 10000 时 CPU 上 KAD 424 ms 反而慢于 FAD 6.9 ms（表 2），「便宜」只在高维 / 小 N 成立 | 2502.15602 §3.2、§4.1、表 2【论文】 |

| 「谱形匹配」与排名效度的关系 | — | 同样加高斯噪声：协方差与原数据匹配的噪声，ID/OOD 线性拟合 R² = 0.93；各向同性噪声只有 0.44 | 2107.04649 §4.2、图 4【论文】 |

**阈值怎么定（共性做法）**【推断，从 2407.13696 §4 的 z 分数规则移植；BAT 原文的分布是「多个 benchmark 的一致性分数」，不是距离】：把真实录音随机对半切 K 次，算出「真实 A 对真实 B」距离的分布 D_rr，再算合成对真实的距离 d_sr。**d_sr ≤ D_rr 的 95 分位**（或 d_sr 的 z ≤ +1σ；距离越小越好，不能照搬 BAT 的「z ≥ −1σ」）就算这个度量合格。这样不需要外部阈值，也不依赖嵌入的绝对尺度。

## 三、Kendall τ 的样本量与置信区间

公式【论文/教科书】：H0 下 Var(τ) = 2(2n+5) / (9n(n−1))。观测 τ 的区间用 Fieller–Hartley–Pearson 法：z = atanh(τ)，se = √(0.437/(n−4))。只有 n 个系统时，系统级 τ 的区间完全由 n 决定，片段数只决定每个系统的分有多准。下面三张表由本机纯 Python 计算【实测】（2 万次置换 / 每格 2000 次模拟，种子 16）。

**D. 蒙特卡洛：合成格与真实集两套测试的系统排名 τ（中位数 / 5 分位）**

读法【推断】：① 片段数超过约 100 后收益饱和，τ 的上限由 ρ∞ 决定；② 5 个系统时，即使 ρ∞ = 0.95，5 分位也只有 0.4，**5 个系统证明不了任何事**；③ 想在 ρ∞ ≈ 0.95 时让 5 分位过 0.5，大约要 n ≥ 12–20、m ≥ 30。

**人造劣化梯度（扩充系统数）**

- 做法有正式来源：MUSHRA 规定 3.5 kHz 低通是必选锚点，7 kHz 低通是可选锚点（ITU-R BS.1534-3）【官方】；FAD 原文用「各种人工失真」来验证度量【论文 1812.08466 摘要】。在我们这里可以是：同一个模型的不同衰减上限 / 后滤波强度、加白噪声、低通、量化。
- 风险 ①：**范围过宽会虚高 τ**。BAT 发现相邻排名模型之间的相关比随机抽样时低，抽样子集越小差距越大【论文 2407.13696 §3.2】。把很差的锚点和真实系统放在一起，τ 主要反映「锚点很差」这件事。对策：除了总 τ，还要单独报告**只看真实系统**和**相邻 5 个**的 τ。
- 风险 ②：**同族成一条线，跨族不一定**。iWildCam 上预训练模型和从零训的模型各成一条线【论文 2107.04649 表 1、§5】。同一模型的强度梯度只能证明「这个维度单调」，证明不了不同架构之间的排名【推断】。
- 风险 ③：**合成劣化本身可能不成线**。CIFAR-10-C 的高斯噪声是 ID/OOD 相关最差的几种腐蚀之一【论文 2107.04649 §4.2】。白噪声劣化尤其要小心。
- 建议【推断】：劣化梯度最多占系统数的一半，并单独标记成「锚点」；判断效度以真实系统子集的 τ 为准，锚点只用来查方向（S2）。

## 四、「预测效度」的分级先例

| 先例 | 分级 | 能借什么 | 出处 · 等级 |
|---|---|---|---|
| V3（数字生物标志物） | Verification（传感器 / 数据本身对不对）→ Analytical validation（算法输出是否测到了物理量）→ Clinical validation（是否对应有意义的临床结局），各级可以分开评 | 对应：合成器契约检查 → 分布对齐 → 排名与人耳一致 | Goldsack et al. 2020, npj Digit Med 3:55, doi 10.1038/s41746-020-0260-4【论文，摘要级】 |
| BetterBench | 46 条 benchmark 最佳实践，评了 24 个 benchmark，大多数不报统计显著性、难以复现 | 「报告 CI、可复现」作为 benchmark 的最低清单 | arXiv 2411.12990 摘要【论文】 |
| BAT | 数据驱动阈值 + 信度另查 | S3 的判法 | 2407.13696 §4、§8【论文】 |
| 012 L0–L3 | verifier 对人耳的定标等级 | S4 的人耳一侧直接沿用 | 012 `verifiers.md:31-36`【自有】 |
| TRL（技术成熟度） | 9 级，从原理到实地验证 | 只借「实验室 → 相关环境 → 实际环境」三段式 | NASA TRL 定义【官方，未逐字核对，二手】 |

**建议的 016 合成数据效度等级 S0–S4**【推断】：

| 级 | 判据 | 能做的结论 |
|---|---|---|
| S0 | 只过了合成器契约（电平、SIR、重叠率在配置范围内） | 只能说「按配方生成了」 |
| S1 | §一 的各项距离都落在真实对真实的分布内（d_sr ≤ D_rr 的 95 分位） | 「看起来像」，不说明能预测排名 |
| S2 | 人造劣化梯度上，各格的 verifier 单调（锚点 τ 的 95% 下界 > 0） | 「格子能分出好坏」 |
| S3 | ≥ 10 个真实系统，合成格排名对现场录音排名（用同一个 verifier）τ 的 95% 下界 > 0；目标 > 0.5 | 「合成格能代表真实录音」 |
| S4 | 合成格排名对人耳排名（012 的 L2 以上）τ 的下界过线 | 「合成格能代表人耳」 |

## 对 016 的启示（可转成格子或检查项）

1. **检查项 `dist-align`（S1）**：对每个合成格分别算 LTAS（1/3 倍频程）RMS dB 差、4 Hz 调制能量差、SNR/SIR 直方图的 W1 距离、重叠率、T60/DRR 直方图。阈值不用外部数字，用真实录音对半切 K = 20 次得到的分布（d_sr ≤ 95 分位）。T60 和 DRR 的分布差同时报告是否超过 JND（5% / 约 2.5 dB）。
2. **检查项 `kad`（S1）**：用 KAD 代替 FAD（无偏；高维嵌入、小 N 时 CPU 上很便宜，低维大 N 时反而比 FAD 慢）。嵌入至少用两种（例如一个通用音频 PANNs 类嵌入和一个语音 SSL 嵌入），**先用现有的人耳答卷检查嵌入距离和人耳方向是否一致，否则只记 L0**。如果用 FAD，必须做 FAD∞ 并报告 N。
3. **检查项 `c2st`（S1）**：用小分类器区分合成和真实。准确率接近 50% 才算过；准确率高时，看分类器依赖的特征（频带、调制）来指导合成器修改。
4. **格子 `anchor-ladder`（S2）**：每个基线模型做 3 档强度，再加 3.5 kHz 和 7 kHz 低通、白噪声锚点。只用于检查单调性，不计入 S3 的 τ。
5. **系统池最少 10 个，目标 12–20 个（S3/S4 的前提）**：DFN 各配置、RNNoise、Hush、传统谱减 / Wiener、商用对照（如果许可）。系统少于 10 个时，结论里只能写「方向」，不能写「排名一致」。
6. **每格片段数 ≥ 30，最好 100**（表 D 显示 100 以后基本饱和）。
7. **最关键的空缺：现场录音锚**。现在所有带人耳答卷的片段都是加法混合，S3 无从测起。需要一批**同场景实录**（笔记本内置麦、咖啡馆 / 邻座），哪怕没有干净参考，也能在上面跑无参考 verifier 排名，或者给人盲听。这一条需要人拍板：录多少、谁来录、隐私怎么处理。
8. **报告格式**：排名一致性一律报告 τ、95% CI、n 系统、m 片段，并分开报告「全部 / 只看真实系统 / 相邻 5 个」三种粒度（BAT §4）。Pearson 与 τ 不共用阈值。
9. **低 τ 先查信度**：先用同一测试集的两半测 split-half τ。如果信度本身就低，合成格和真实集的 τ 再低也说明不了效度（BAT §8）。
10. **教训清单**（写进负例）：DNSMOS 第一、人耳最后（UDASE）；合成集与实测集 τ = 0.31（Clarity），原因很可能是 RIR、换能器噪声和指向性。所以「麦克风底噪、Mac 内置麦响应、真实 RIR」应作为单类格子单独变量化。
