## 二、已做到哪【测】

### 2.1 数据侧（S1 · S2 · S3 · S6，不用名额）

S1 可复现 60/60 · S2 可控 12/12（实测 SNR/SIR 与名义差 0.0 dB）· S3 三轨残差 −148.8 dB · S6：合成杯碟、合成音乐**不过**，合成 babble 临界（A）/ 过（B），稳态类无真实参照（D0）。详见 exp008 README。

### 2.2 排名侧（S7 · S8，第一轮 12 + 1 个系统）

系统阶梯（全部只作对照、不进产品）：直通 · 谱减 · 维纳 DD · MMSE-LSA（C 族，自写 numpy）· GTCRN-VCTK（A′）· GTCRN · UL-UNAS · FastEnhancer-S / -M（A 族，同训练集）· DPDFNet base / 2 / 8（B 族）· GTCRN 湿干比 0.5（参数变体）· 理想掩码（作弊天花板）。去掉天花板和变体 = 12 个，**4 族**（C · A · A′ · B）；A′ 与 A 同架构只换训练集，B 族内是同一模型三档——**独立性弱**，按 synth-standard D3 的「≥ 4 个独立族」只是刚够，且 C 族四个共用同一个最小统计噪声估计。

**S7 生成器稳健**（每格每档：A 上的系统排名 vs B 上的，Kendall τ_b；信度 = 同一生成器内奇偶两半 3 段 vs 3 段的 τ）：

| 指标 | 12 系统 τ_AB 中位 | 信度 A / B 中位 | 过 S7（下界 > 0 且 τ_AB ≥ 信度 − 0.2） | 只看 8 个神经模型 τ_AB 中位 | 信度 A / B |
|---|---|---|---|---|---|
| DNSMOS OVRL | 0.85 | 0.85 / 0.85 | 29/29 | 0.79 | 0.79 / 0.79 |
| DNSMOS SIG | 0.79 | 0.76 / 0.79 | 27/29 | 0.79 | 0.71 / 0.79 |
| DNSMOS BAK | 0.79 | 0.79 / 0.76 | 29/29 | 0.64 | 0.57 / 0.57 |
| ESTOI | 0.79 | 0.67 / 0.85 | 23/29 | 0.79 | 0.64 / 0.93 |
| 无人声段压噪 | 0.79 | 0.85 / 0.73 | 28/29 | 0.50 | 0.64 / 0.43 |
| 主讲人电平 | 0.79 | 0.79 / 0.85 | 28/29 | 0.57 | 0.57 / 0.79 |
| 邻座段压制 | 0.82 | 0.79 / 0.85 | 9/9 | 0.57 | 0.50 / 0.64 |
| SI-SDR | 0.55 | 0.58 / 0.85 | 15/29 | 0.50 | 0.50 / 0.79 |

读法（只说数）：
1. 跨生成器的排名一致性**和同一生成器内两半的一致性差不多大**——生成器换了，排名变化没有超出「换一批片段」的变化。这是 D2 的条件。
2. 这有一半是「阶梯太宽」送的：直通到 DPDFNet-8 的差距很大，谁都排得对。只看 8 个神经模型，DNSMOS OVRL / SIG / ESTOI 还在 0.79，压噪、电平、SI-SDR 掉到 0.5–0.57——但信度也一起掉，**瓶颈是每格只有 6 段**（两半各 3 段），不是生成器。要分清神经模型之间的名次，每格至少要 30 段〔建议值，synth-standard D3〕。
3. 最差的格：M-SIRxSNR（SIR 0 / SNR 5）上 ESTOI、SI-SDR 的 τ_AB 只有 0.09 / 0.12，S-RT60 hall 的 SI-SDR 0.24、S-SNR −5 dB 的 ESTOI 0.27。都是「强干扰人声 / 强混响 / 极低 SNR」——系统都很差、差距小，排名被片段噪声主导。
4. SI-SDR 最不稳（15/29 过）：它对相位和延迟敏感，A / B 的 RIR 模型不同，直达声比例不同。

**S8 对人耳**（exp003 build f8c3：3 个系统 × 12 屏，48 个人耳配对；功效很低）：

| 指标 | 用「近似合成格」上的系统均值预测人耳配对 | 直接在 exp003 片段上算（calib round 1 口径） |
|---|---|---|
| DNSMOS OVRL | 0.33（n = 48） | 0.48（n = 46） |
| DNSMOS SIG | 0.35 | 0.56 |
| ESTOI | 0.35 | 0.52 |
| 无人声段压噪 | 0.35 | 0.52 |
| SI-SDR | 0.25 | 无（exp003 未存） |

读法：
1. 人耳在 exp003 上的偏好是 **GTCRN > FastEnhancer-M > DPDFNet-2**（GTCRN 在它参与的 37 对里赢 25 对）；而所有指标在合成格上的均值顺序正好反过来：DPDFNet-2 > FastEnhancer-M > GTCRN（OVRL 2.66 / 2.50 / 2.20；压噪 17.8 / 17.2 / 13.2 dB）。
2. **这主要说明 verifier 和人耳反着，不能怪到数据头上**：同一批指标直接在人听的那 12 段上算，一致率也只有 0.48–0.56（随机水平）。合成格平均之后噪声更小、更稳定地站在指标那一边，所以一致率更低。
3. 48 对不是 48 个独立证据：只有 3 个系统，所有配对加起来只够判一个 3 元排列（6 种可能里的 1 种）。**S8 的上限受人耳数据限制，不受系统数限制**——第二轮系统再多，exp003 的人耳也只判过这 3 个，48 对能重算、但不会多出新信息。要让 S8 有功效，下一轮听测必须覆盖更多系统（decision.md 待拍板第 3 条）。
4. 「压得多的被人嫌」是【假设】（与 D45「不能压得太狠」的直觉一致），没有 verifier 能判；它是 012 里「自然」尺子缺口的又一例。

## 四、做不到的（如实）

1. **整体层没造**：会话体语音、Lombard、真实重叠率本机都没有（S4 / S5 过不了），硬造只能 D0
2. **全部格子最高 D2，而且 D1 未满**：S6 只对齐了噪声；语音、RIR、设备链没有真实参照（`benchmark.md` 第五节「真实锚为零」）
3. 指标是近似口径；DNSMOS 本身 L0（exp007 calib：与人一致 0.48）
4. 每格 6 段，神经模型之间的名次分不清（见 2.2 读法 2）
