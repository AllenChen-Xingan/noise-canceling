# 016 · 合成数据标准：一份合成数据怎样才算「合格」

> 2026-10-31 · 手下 benchsynth · 草稿（成熟后由大总管决定是否升为 `specs/`）
> 本文件是**标准**（产出该长什么样）。每条检查写成「判什么 · 怎么算 · 过线 · 脚本」，能由机器判；判不了的标「人工层」。
> 〔建议值〕= 没有出处的数，待人拍板或定标后调。出处见 `notes/`（A–G）与 exp008。
> 已有脚本：`docs/experiments/exp008-bench-validity/checks.py`（S1 · S2 · S3 · S6）· `rankstat.py`（S7 · S8）。

## 零、核心（先看这 4 行）

1. **合成数据合不合格，最终只看一件事：在它上面排出来的系统名次，和在真实录音 / 人耳上排出来的一不一样**（预测效度，S8）。其余检查都是必要条件，不是充分条件。CHiME-3/4 把这条定为判据（「模拟上的相对提升能否预测真实上的相对提升」，E 篇【论】），DNS 2020 前 7 名上带混响合成集与真实集排名 SRCC −0.11（n = 7，p≈0.84，分不清有无关系；B 篇复核【测】）
2. **效度分五级 D0–D4，每格单独定级**；一个分数能拿来干什么 = min(verifier 的 L 级, 格子的 D 级)（`benchmark.md` 第四节）
3. **排名检验要够多、够独立的系统**：精确置换分布下，单侧 p < 0.05 要 n = 8 个系统时 τ ≥ 0.571、n = 12 时 τ ≥ 0.394；3 个系统怎么排都显著不了【测，exp008 scratch 精确计数】。同一模型的参数变体不是独立系统，会虚增 n（D 篇复核）
4. **今天全部格子最高 D2**：真实锚为零（`benchmark.md` 第五节），D3 / D4 无法检验

## 二、效度分级（每格单独定，进清单）

| 级 | 含义 | 判据 | 能拿来干什么 | 今天 |
|---|---|---|---|---|
| **D0 未检** | 只保证能跑 | S1 · S2 · S3 过 | 冒烟、调试、单元测试（CI 层的类语音就在这一级——它测确定性逻辑，不依赖素材像不像） | 全部 exp008 格 |
| **D1 统计对齐** | 素材统计量像真实 | D0 + S4 + S6 全组「过」（整体层另加 S5） | 训练增广的分布参照；诊断；感知量只作约束 | 本机只能对齐噪声；语音、RIR、设备链无参照 → **没有格完整到 D1** |
| **D2 生成器稳健** | 排名不随生成器变 | D1 + S7 过 | 模拟真值类（V-SIM-*）的回归门禁；感知量 ≥ L2 时报警 | exp008 S7 结果见 mvp.md（且 D1 未满，只能记「D2 条件满足、D1 未满」） |
| **D3 排名对真实** | 同一 verifier 在合成格与真实锚上排名一致 | D2 + S8（D3 口径）：τ 的 95% 下界 > 0，点估计 ≥ 0.5〔建议值〕；**≥ 12 个系统，其中 ≥ 4 个独立族**（族 = 架构或训练集不同；参数变体不计）；每格每边 ≥ 30 段〔建议值〕 | 该格上 ≥ L2 的 verifier 可作 QA 门禁；可对外说「模拟格经真实录音验证」 | 无法检验（真实锚为零） |
| **D4 排名对人耳** | 合成格排名能预测人耳在真实锚上的排名 | D3 + S8（D4 口径）：同上阈值；人耳数据按 012 §2.3 累计验证集，判级只用随机那一半 | 该格可替代人耳做预筛；≥ L2 verifier 在该格上可作 RL 奖励（013 / D43） | 无法检验 |

**为什么要 D2 这一级**（原诊断的 L0–L3 类比里没有）：它不需要任何真实数据就能做，而且是 D3 的必要条件——两套同样说得过去的生成器排名都对不上，这格在真实录音上也不可能对得上。CHiME-3 MVDR 的教训正是这种（模拟只用纯延迟，某类方法在模拟上虚高，E 篇【论】，作者归因未验证）。**D2 不能证明效度**：两套生成器可能犯同一种错（比如都是加法混合、都没有 Lombard、都是朗读）。

**样本量与系统数**（S8 / D3 / D4 的最低门槛）：

| 系统数 n | 单侧 p < 0.05 的临界 τ（精确） | 观测 τ = 0.8 时 95% 下界能否过 0.5 |
|---|---|---|
| 3 | 不可能 | 否 |
| 6 | 0.733 | 否 |
| 8 | 0.571 | 否 |
| 10 | 0.467 | 约在边上（D 篇：Fieller 近似 ≥ 10 个系统） |
| 12 | 0.394 | 是 |
| 15 | 0.333 | 是 |

临界 τ 为本机精确置换计数【测】；第三列来自 D 篇（Fieller 近似：τ = 0.7 要 ≥ 21 个系统、τ = 0.6 要 ≥ 86 个）【测·近似】。D 篇另做的蒙特卡洛【测·模拟，噪声比为假设值】：真实效度 ρ = 0.95、12 个系统、每格 30 段时，τ 中位只有 0.70、5 分位 0.48——**片段数和系统数都要够，单靠堆系统救不了**。

## 三、三层数据各自要过哪些

| 层 | 必过 | 用途 | 最低效度 |
|---|---|---|---|
| 单类（S-） | S1 · S2 · S3 · S9 · S10 · S11 · S12 | 测一个因素的斜率；针对性优化的靶子 | 诊断 ≥ D0；当判据 ≥ D2 |
| 多类（M-） | 同上；S2 改为「两个因素各自可控」 | 测交互 | 同上 |
| 整体（H-） | S1 · S3 · S4 · **S5** · S6 · S9–S12（不要求 S2，不配对） | 发版前总回归 | 当判据 ≥ D3；对外 ≥ D4 |
| 训练用合成（013 训练生成器） | S1 · S3 · S10 · S11；S6 用作**分布参照**（训练生成器与裁判生成器分开，015 B §3.1） | 训练 | 不定级（训练数据好不好，看在 D3+ 裁判格上的结果） |

## 四、清单字段（每个 build 一份，进 `docs/experiments/<实验>/builds/<build>/`）

`manifest.json`：build id · 生成脚本 sha256 · 素材索引 sha256 · 配方（基点、各轴档位）· 层 · 生成器 id · 效度级（每格）· 许可汇总。
`truth.jsonl`（每段一行）：格 · 档位 · 生成器 · 素材种子 · 名义条件 · 实测条件（SNR / SIR / T60 / DRR / 重叠率）· 素材出处（说话人 id、噪声文件 + 起点、RIR 参数）· 各轨样本哈希 · 逐 hop 标签 · 参考转写（若有）· 「三轨可加」标记。
音频只在仓外（主目录 `_tmp/<实验>/<build>/` 或 `~/vdn-data/`）。给人听的目录里不放清单和揭盲表（CLAUDE.md 第五节第 1 条）。
