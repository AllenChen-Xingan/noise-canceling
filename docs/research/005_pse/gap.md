# 两类发现 · 个性化降噪（PSE）：模型 · 自动注册 · 评测

> 2026-10-30 · 手下 pse。依据全在 `sources.md`（带出处）。分级：P0 最高、P3 最低，**P0 / P1 / P2 清零，P3 酌情**。
> 延迟口径同 002：① 窗 + 前瞻 · ② DNS 口径 = 窗 + 步长 + 前瞻 · ③ 端到端附加 = 管线直通 6–10 ms + ①。

## 先说结论

**能直接拿来用的开源 PSE 只有一个：VoxLock，而它的算力是预算的 3–5 倍。** 其余端到端 PSE（PVQE、TEA-PSE、pDCCRN、pDFN2、三星）全都**没有代码或没有权重**；有权重的 TSE 不是非因果、8 kHz，就是非商用许可。不训练的路只剩「通用模型 + 声纹门控」，但它唯一的对照证据（Personal VAD 的 SC 基线）是四种做法里最差的。

## 二、它们没做的

| 找过什么 | 结论 | 是哪一种 |
|---|---|---|
| **因果 + 开源权重 + 预算内**（≤ 2 ms/10 ms）的 PSE | **无人涉足**：TEA-PSE、PVQE、pDFN2 都没放代码权重；VoxLock 超预算 | **没顾上做**（学术界不放权重）→ 要么等，要么自训小模型（人定） |
| **「会议开头别人先说话」的注册防护** | **无人涉足**：VoxLock 锁第一个说话的人；Teams 让用户自己关；Apple 只警告「早期污染」；没有论文或代码专门处理 | 没顾上做 → 我们的机会，规则见下 |
| 物理线索判断主人（近场、DRR、回声参考） | 没有能实时用的开源实现；回声参考判主人**没找到任何依据** | 没顾上做（推断可行，需实验） |
| 「声纹相似度增益门 + 滞回」的效果数字 | 没有开源实现也没有评测；PVAD 的 SC 基线（最接近）最差 | 没顾上做 → 必须自己量 |
| 声纹模型在 babble / 远场下的 EER、在 Apple Silicon 上的耗时 | 只有干净 VoxCeleb 上的 EER、Xeon 上的 RTF | 没顾上做 |
| 许可干净、非 VoxCeleb、能用英文的声纹模型 | **没找到**（3D-Speaker 中文版 Apache 但训练数据来源不明；CN-Celeb 版 CC BY-SA 只有中文） | 做到的人少 |
| 主人音色变化（感冒、情绪、大声 / 轻声）下的误杀 | 只有 DNS4 dev 的 193 条情绪句可用；感冒**没有**公开数据 | 没顾上做 |
| VoxCeleb 许可原文 | 三个代理六次连接失败，只有 Praat 转引 | 不确定 |

### 注册规则（证据基础，供 M3 写注册器；每条有出处）

1. **冷启动用通用模型兜底**，个性化强度从 0 起（PVQE 零向量 = 通用模型 §4.3；Teams「a couple of meetings」；设计稿 §10）
2. **只在高置信度时更新**：c = αx + (1−α)c，得分 > τ 才更新；不像任何已知人的标「未知」（2205.00288 §4、§6.4）
3. **前期最容易被污染**：冷启动阈值更严，或等聚类稳定后再锁定主人（Apple 博客）
4. **多原型、设上限、滚动替换**（Apple 40 个）；保留初始锚点，偏离太远拒绝（设计稿 §10；AFW 锚点思路）
5. **重叠说话不进注册**（diart cannot-link，`clustering.py:138-140`）
6. **能删、能关、能重置**（Teams；设计稿 §10）
7. 「最常出现 + 最近场的簇 = 主人」（设计稿 §10）——**无外部证据**，需实验

### 该不该自己跑一个（本线不跑，报大总管另开）

| 判据 | 结论 |
|---|---|
| VoxLock 在 M5 单线程每 10 ms 要多久（int8 / fp32 × 块长 10 / 20 / 40 ms） | **跑它，最便宜也最关键**：决定它是「直接改造」还是「只当教师模型」。权重 int8 74 MB（< 500 MB），官方 Python 推理现成，套 exp001 的 bench 即可；要名额 |
| 声纹模型（WeSpeaker ECAPA512 / CAM++、3D-Speaker ERes2Net）在能效核上 2 s 段耗时 | 跑它，可与上一条同一个实验 |
| VoxLock vs DPDFNet-2 vs GTCRN 在咖啡馆录音上谁更清楚、误杀多少 | **跑它**：可并进 abtest 线的离线 AB 页（exp003）再加一列，人听一次就能看出 PSE 值不值 |
| 「开头别人先说话」时注册器会不会锁错人 | 跑它（合成场景，见 decision.md「评测」第 4 条），等注册器写出来再说 |
| 门控在主人与邻桌重叠时会不会误杀 | 跑它，M3 门控原型阶段 |
| TEA-PSE / PVQE 到底多好 | **不用跑**：没有权重，跑不了 |
