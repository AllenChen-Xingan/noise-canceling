# 030 · 不重训 GTCRN 的系统级手段（混回比例 · 判场景小模型）

> 2026-11-05 · 手下 aux（大总管 noise-canceling-74）· 分支 `research/030-gtcrn-aux` · issue #124
> 已定：D86（加训 GTCRN，不换模型）· D88（训练用云 GPU）· D89（旁人说话交给另外的小模型，本线只报不判）。

## 一句话结论

不重训补不上弱场景，只能补一小块：把说话时混回原声的量从 −6 dB 降到 −9 dB，可懂度涨约 0.007（弱场景约 0.01），
弱场景和候选模型的差距补上约四到六成，代价是字头多吃约 0.5 dB。按场景切比例的上限不比全局一个比例好，判场景小模型不建议为此而做。
能和加训叠加：加训出新权重后重扫一次比例（约 25 分钟）。
