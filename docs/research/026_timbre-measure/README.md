# 026 · 音色项该怎么量

> 2026-11-05 · 手下 timbre（大总管 noise-canceling-74）· 分支 `research/026-timbre-measure` · issue #119
> 人原话：「所以说到底是代码的逻辑正确还是文档的逻辑正确，我需要研究和证据支持 / 开手下做，然后如果有错误就修复」
> 管的实体：评测器里的音色项（V-TIMBRE）· 它的标准条文（rubric N4）· 它的判定线。

## 一句话结论

**代码和文档都不对，各漏一块**（实测，30 段干净人声）：
- 文档的四个频带中间空了 500 Hz–2 kHz。1–2 kHz 压低 12 dB，它只读 0.56 dB。
- 代码最低一带 100 Hz–1 kHz 太宽，又只取最差的一带。250 Hz 附近降 6 dB，它只读 0.49 dB。

业界被验证过的音色量（POLQA 染色分、HASQI、Moore 自然度模型）用的是第三种做法：
- 听觉刻度的密频带；
- 先去掉整体电平；
- 取各带差的标准差。

推荐改成这种：ERB 刻度 30 带，取标准差。同样大小的变化放在不同频率，读数只差 1.3 倍（代码差 10 倍，待对拍）。
它的弱点：在不扣残留噪声的那一路（干净人声那一路就是这样），对底噪比代码敏感得多。
它是那几种被验证量法的简化版，省掉了听觉模型那一层；省掉后和人耳相关多少，没有文献数，要人耳校。

分档线 1 / 2 / 3（> 3 不过）是**建议值**：只在听感研究测过的几种形状上锚定过，增益 dB 和带间标准差不能换算，要人耳校。不过线从 6 改到 3 要人定。
