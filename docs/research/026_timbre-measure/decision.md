## ① 答人：代码对还是文档对

**两边都要改**。各对一半，各漏一块。

| | 对在哪 | 错在哪（实测） |
|---|---|---|
| 代码 `v_timbre` | 频带从 100 Hz 连到 7.9 kHz，中间没有空档；先从输出里扣掉停顿帧估出的残留噪声（同 T1） | 最低一带 100 Hz–1 kHz 太宽。250 Hz 附近整个倍频程降 6 dB，只读 0.49 dB（判 A）。<br>合成只取四带里最大的那一个：同样大小的变化，放在 4 kHz 读 5.10 dB，放在 250 Hz 读 0.49 dB，差 10 倍 |
| 标准 N4 | 合成用均方根，近于 T4、T5 用的标准差；先把整体电平对齐，只比形状（同 T8 §6.3.2） | 四带中间空了 500 Hz–2 kHz，这一段约占语音重要性权重的 47%（T10，可懂度权重，借用）。<br>1–2 kHz 压低 12 dB，只读 0.56 dB（判 A）。<br>不扣残留噪声：白噪声在信噪比 20 dB 时，95 分位读 6.41 dB（判不过） |

被验证过、和人耳相关的频谱形状量（T1 POLQA 频响指标 → T2 染色分；T4 HASQI 线性项；T5 Moore 自然度模型）有三个共同点：
- 用**听觉刻度的密频带**（Bark 或 ERB，13–32 带，或每 0.5 Cam 一点），不用四个宽带；
- **先去掉整体电平，只比形状**；T1 只取语音帧（T4 是否只取有声帧，两份笔记说法相反，无法核实）；
- T4、T5 的合成用各带差的**标准差**，再加一项斜率差。T4 的源码同时算了最大差，但模型没用它。

**但这三者没有一个是本卡推荐的那种算法**（codex 第 1 轮 #4）：
- T1 是 Bark 带上的响度差积分；
- T4 是各自归一后的线性幅度差；
- T5 是激励模式，高于约 1.2 kHz 还降权。

本卡推荐的「等权矩形 ERB 功率带、dB 差的标准差」是取它们的共同结构，再省掉听觉模型那一层（激励模式、响度变换、高频降权）。**省掉之后和人耳相关多少，没有文献数，是待验证的建议**。验证办法见 ④ 末的人耳校准。

J5 的读法：
- 扣噪声时：信噪比 ≥ 20 dB，两种量法都 ≤ 0.2，低于 A 线 1.0（拿 A 线当容差）。到 10 dB，ERB 读 1.76–2.07、超过容差，**不满足 J5**；代码仍近于 0。
- 不扣噪声时（干净人声那一路就是这样），**ERB 比代码敏感得多**：白噪声 20 dB 读 2.21（判 C），95 分位 6.97（判不过）。原因（推断）：ERB 每带等权，最高几带人声能量弱，一点底噪就抬得很明显；四宽带取最大时，这几带被并进了 4–7.9 kHz 一带。
- 所以「不扣噪声」时 ERB 不过 J5。**改法（大总管要求实测后定）：干净人声那一路也扣，两边对称地扣**（run `20261105-094833`，列 `erb_std_sym`）：
  - 停顿帧取主讲人不在（外扩 30 ms）的帧，同带噪那一路的口径。模型在干净人声上自己加的底噪在停顿里，照常估出来扣掉。
  - 只扣输出不扣参考时，原样不改的一段（street-outdoor-c00-ext）也读 0.28：参考停顿里有混响尾巴，输出那边被扣了、参考这边没扣。所以参考也扣它自己停顿里的能量，两边同样处理，原样不改的 30 段全读 0。
  - 对真劣化的读数不变弱：所有非加噪劣化，对称地扣与不扣，逐段最大差 0.005。
  - 对底噪：白噪声 30 / 20 / 10 dB 从 0.55 / 2.21 / 5.27 降到 0.03 / 0.15 / 2.07；粉噪声 20 / 10 dB 从 1.90 / 3.78 降到 0.18 / 1.77。
  - 仍不过的：信噪比 10 dB 时扣完还剩 1.8–2.1。原因（推断）：最高几带人声弱，噪声与人声同量级时，按停顿估的噪声扣不干净。
- 结论：J5 ERB（对称扣噪）在信噪比 ≥ 20 dB 时过，10 dB 时不过。

读法：
- 粗体是该量法的盲区；
- 代码在 J1、J2 不过；文档在 J1、J2、J5 不过；ERB 在 J1–J4、J6、J7 过，J5 只在扣噪声、信噪比 ≥ 20 dB 时过；
- J2 是关键：同样大小的变化，代码按所在频率读出 10 倍的差别，ERB 只差 1.3 倍。

另两条：
- 代码和文档的分帧（512 / 1024 点）在同一套频带下差 ≤ 0.03 dB（子代理 A 的合成小实验，推断），不是冲突点。
- **对拍**：代码版 Python 移植与 Rust 旧 `v_timbre` 逐位对过：180 个文件（30 段 × 6 种劣化，不扣噪声的那一路），最大差 0.000 dB，容差 0.05 dB，过。
  - codex 对照源码读过：频带上沿都用「<」，扣噪下限都是原值的 10% 与 1e-20，分母都是四带功率和，没发现移植差异。分帧、掩码映射、`db10` 在别的文件，没核。
  - 旁证对不齐：在 480 段 GTCRN 真实输出上，移植读数中位数 1.20、90 分位 6.48；exp014 第一张成绩单上 Rust 记的是 1.19、6.98。90 分位差 0.5 dB，远超 0.05 dB 的容差。
  - 两边素材不同：这次读的是存给识别服务的 16 位副本，停顿掩码按干净轨自求；成绩单用的是浮点输出和场景真值。对拍过了，所以这 0.5 dB 来自素材不同，不是移植错。

## ③ 推荐量法（ERB 形状偏差）

每一处的出处如下。「建议值」是没有出处、本线定的数。

| 步骤 | 做法 | 出处 |
|---|---|---|
| 帧 | 只用主讲人有声帧（干净参考的真值掩码） | T1（§9.7.6 只取语音活动帧）。T4 是否如此无法核实：子代理 A 读到 HASQI 长时谱取整段，子代理 C 说只取有声帧，未回源码定论 |
| 分帧 | 1024 点 Hann，跳 512 | J7（每带 ≥ 2 个频点）；分帧本身无实质影响 |
| 频带 | ERB 数从 100 Hz 到 7 900 Hz 等分，带数 = 跨度（29.8 ERB）取整 = 30，每带约 1 ERB | T11 公式；T4（ERB）、T1（Bark）同类。等分方式、带数、两端是**建议值**（7 900 沿用现行代码，避开奈奎斯特频率） |
| 残留噪声 | 输出、参考各带功率各自减去自己停顿帧的平均功率，下限为原值的 10%。停顿帧：评分上下文给了「只有噪音」掩码就用它（带噪那一路）；没给（干净人声那一路）就取主讲人不在、外扩 30 ms 的帧 | T1 扣输出的噪声谱；参考也扣、两边对称是**建议做法**（J5 实测）。10% 沿用现行代码，30 ms 同 `runner.rs` 的外扩，都是**建议值** |
| 对齐 | 各带 dB 差先减中位数；截下限；再减平均值 | T4、T5（去掉整体电平只比形状）；T8。先减中位数是为了让截断点随整体增益平移（J4），**建议做法** |
| 单带下限 | 相对中位数最低记 −40 dB | **建议值**：不让低通后的空带读成 −100 dB 级 |
| 主值 | 各带差的**标准差**（dB），带等权 | T4、T5 用标准差；「等权、不降高频」是**建议**，T5 有高频降权，本卡没采用 |
| 旁报（只报不判） | 斜率差标准差 `slope_db`；最大绝对带差 `max_db`；高频平均偏差 `hi_db`（中心 ≥ 3.8 kHz，负 = 发闷）；低频平均偏差 `lo_db`（中心 < 500 Hz，负 = 发薄） | 斜率：T4、T5 的第二项。方向：T3 的两个主观方向；3.8 kHz 分界取自 T8 表 6.3；500 Hz 是**建议值** |
| 低采样率 | 上沿越过奈奎斯特频率的带不计；剩下不到一半（< 15 带）判「不知道」 | **新建议**，不是现行规则。现行 #110 是「四带至少剩三带」（`perceptual.rs` 约第 426 行）。新规则下 6 kHz 采样仍剩约 21 带，会照常打分；现行 `low_rate_tests.rs` 里要求判「不知道」的那条要跟着改。依据：沿用现行「剩下的带要过半」的意思（四带剩三带），推断，无外部出处 |

不采用：
- T4 的 0.579 / 0.421 权重：它的谱是线性幅度归一，和我们的 dB 刻度不同，权重不能直接搬。斜率先只报不判。
- 电信频响模板（T17–T20）当判定线：它们管的是终端的绝对频响、在安静里测、要求逐带都在窗内，和「处理前后的形状差」不是一个量，只作量级参照。

## ④ 推荐分档线

**全部是建议值，没有出处**。

⚠️ **单位不能换算**：文献里的阈值是「某个频段的增益变了几 dB」，我们的量是「30 个带的 dB 差的标准差」。同样的增益变化，ERB 读数随变化的宽度、位置、方向而变。所以下表只是**锚定**：把 T12 测过的那几种形状在 exp017 上过一遍，看它们落在哪。它不是从文献推出来的换算，也**推不出「读数 X 对任何形状都等于听得出」**（codex 第 1 轮 #1）。别的形状（窄谷、宽倾斜）在新量上的阈值，文献没有数。

| 劣化（exp017 定标组） | ERB 读数 |
|---|---|
| 一个倍频程 ±3 dB（250 / 1k / 4k Hz） | 0.87–1.14 |
| 两个倍频程 ±4 dB（150 / 600 / 4 800 Hz） | 1.33–1.79 |
| 一个倍频程 ±6 dB | 1.71–2.29 |
| 两个倍频程 ±6 dB | 1.98–2.69 |
| 整体倾斜 −2 dB/倍频程（现行代码读 6.02） | 3.35 |
| 一个倍频程压 12 dB（0.5–1k · 1–2k · 2–4k Hz） | 3.88–4.21 |

**T12 的阈值点逐条在 exp017 上模拟**（run `20261105-094442`，codex 第 2 轮 #1）。T12 只给了区间，没给每个条件各自的阈值。所以下表只把区间两端和 12.5 dB 那个点各自模拟出来，**不表示每个条件的阈值就在这里**：

读法与限制：
- 同一个增益，ERB 读数在 150 Hz 比 4 800 Hz 低约 25%；ERB 并不是对每个频段都一样。
- T12 的「去掉响度线索」是听测设计上的做法（具体怎么做本线未细核）；我们是在计算时去掉整体增益，**两者不是一回事**。所以不能说哪一行「更贴近我们」。
- 文献只到「人在这些条件下的阈值落在 3.5–7.3 dB」，**推不出任何 ERB 读数等于「听不出」或「听得出」**。

## ⑤ 改了之后成绩单上这一项会怎么变（推断）

1. **v2 成绩单（现在判的是干净人声那一路）**：
   - 原声直通、参考降噪器：输出就是输入，两种量法都读 0，不变。
   - GTCRN：现行代码读数中位数 0.07、90 分位 0.39，480 段里没有一段 > 4（run `20261105-005916-4ccf0638`，Rust 读数）。
   - 推断换成 ERB 后多半仍在 A / B。依据：exp017 里大多数线性劣化 ERB 读数不高于代码读数。例外有两种：
     - 低频改动，代码看不见，ERB 看得见；
     - 输出多出来的宽带底噪：改成对称扣噪后，信噪比 ≥ 20 dB 的底噪读 ≤ 0.2（见 J5）。
   - **没实测**：那次 run 没存干净人声那一路的输出。
2. **带噪那一路（v2 下只报，标「旧口径」）**：
   - 在 480 段 GTCRN 真实输出上，ERB 中位数 2.46、90 分位 5.71；代码移植是 1.20、6.48，。两者排序的相关 0.73（`runs/realout-20261105/`）。
   - 按新线，这一路多半会有更多段落在 C 或「不过」（推断，未按新旧分档逐段计数）。这一路不判，只影响旁报。
3. **不能只靠重新汇总看到变化**：新量法要重算音频。`--from-clips` 只能换判定线，换不了量法，要重跑成绩单（估时另报，要名额）。

## ⑥ 修法（已做，2026-11-05；结果见本节末）

1. `src/eval/src/verifiers/perceptual.rs` `v_timbre` 改成 ③。频带、分帧、下限做成 `pub const`，作为正本。先写会红的测试：
   - J1：低搁架 ±6 dB 要读 > 1；

## ⑦ 待人拍板

1. **几 dB 算听得出**：A / B 两条线是建议值。如果你不回，默认用 1.0 / 2.0；后果是这两条线可能偏严或偏松，但不影响过不过。要你盲听一页（约 10 分钟，按 ④ 的做法）。
2. **音色偏差多大算不过**：新量法下建议 > 3.0 不过。它会改变哪些段判不过：低频被改的段以前不过不了，以后会不过。如果你不回，默认「量法照改，不过线先保持暂定」：新量法下照样按 3.0 判过不过，只是标「暂定」（现有判定线本来也都是建议值、照判的，如旧的 6 dB）。后果：你定之前按 3.0 判；它比旧的 6 严，可能有组合从「过」变成「不过」或「待测」；候选模型和 GTCRN 用同一条线，比较仍然公平。
