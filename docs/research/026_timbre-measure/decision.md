## ① 答人：代码对还是文档对

**两边都要改**。各对一半，各漏一块；两边都不是业界验证过的做法。

| | 对在哪 | 错在哪（实测） |
|---|---|---|
| 代码 `v_timbre` | 频带从 100 Hz 连到 7.9 kHz，中间没有空档；先从输出里扣掉停顿帧估出的残留噪声（同 T1） | 最低一带 100 Hz–1 kHz 太宽。250 Hz 附近整个倍频程降 6 dB，只读 0.49 dB（判 A）。<br>合成取四带里最大的那一个，同样大小的变化放在 4 kHz 读 5.1 dB、放在 250 Hz 读 0.49 dB，差 10 倍 |
| 标准 N4 | 合成用均方根（同 T4、T5 的思路）；先把整体电平对齐，只比形状（同 T8） | 四带中间空了 500 Hz–2 kHz，这一段约占语音重要性权重的 47%（T10）。<br>1–2 kHz 压低 12 dB，只读 0.56 dB（判 A）。<br>不扣残留噪声：白噪声在信噪比 20 dB 时，95 分位读 6.41 dB（判不过） |

业界被验证过的做法（T1 POLQA、T4 HASQI、T5 Moore 自然度模型）有三个共同点：
- 用**听觉刻度的密频带**（Bark 或 ERB，13–32 带），不用四个宽带；
- **先去掉整体电平，只比形状**，只取语音帧；
- 合成用各带差的**标准差**，常再加一项斜率差。T4 的源码同时算了最大差，但模型没用它。

所以推荐第三种量法（下节）。代码和文档都改成它，正本放在代码里。

读法：
- 粗体是该量法的盲区，或被大幅稀释的读数；
- 代码在 J1、J2 不过，文档在 J1、J2、J5 不过，ERB 七条都过；
- J2 是关键：同样大小的变化，代码按所在频率读出 10 倍的差别，ERB 只差 1.3 倍。

另两条：
- 代码和文档的分帧（512 / 1024 点）在同一套频带下差 ≤ 0.03 dB（子代理 A 的合成小实验），不是冲突点。
- 代码版是 Python 移植，与 Rust 的逐位对拍要拿名额，**还没跑**（`src/eval/tests/timbre_parity.rs`）。旁证：在 480 段 GTCRN 真实输出上，移植读数中位数 1.20、90 分位 6.48；exp014 第一张成绩单上 Rust 记的是 1.19、6.98。两者素材不完全相同（这次读的是存给识别服务的 16 位副本）。

## ③ 推荐量法（ERB 形状偏差）

每一处的出处如下。「建议值」是没有出处、本线定的数。

| 步骤 | 做法 | 出处 |
|---|---|---|
| 帧 | 只用主讲人有声帧（干净参考的真值掩码） | T1、T4 |
| 分帧 | 1024 点 Hann，跳 512 | J7（每带 ≥ 2 个频点）；分帧本身无实质影响 |
| 频带 | ERB 数等距，每带 1 ERB 宽，100–7 900 Hz，共 29 带 | T11 公式；T4（ERB 32 带）· T1（Bark）同类；「1 ERB 宽」与 100 / 7 900 Hz 两端是**建议值**（7 900 沿用现行代码，避开奈奎斯特频率） |
| 残留噪声 | 输出各带功率先减去停顿帧估出的噪声功率，下限为原值的 10% | T1 做法；10% 沿用现行代码，**建议值**。干净人声那一路没有停顿掩码，不扣（同现行 `clean_view`） |
| 单带下限 | 每带偏差最低记 −40 dB | **建议值**：不让低通后的空带读成 −100 dB 级；J6 由此单调 |
| 对齐 | 各带 dB 差减去它们的平均值 | T5、T4（去掉整体电平只比形状）；T8 |
| 主值 | 去均值后各带差的**标准差**（dB） | T4、T5 |
| 旁报（只报不判） | 斜率差标准差 `slope_db`（T4、T5 的第二项）；最大绝对带差 `max_db`；高频平均偏差 `hi_db`（中心 ≥ 3.8 kHz，负 = 发闷，T3、T8 的分界）；低频平均偏差 `lo_db`（中心 < 500 Hz，负 = 发薄，T3） | 方向分项为 P.806 的两个主观方向，便于人耳回灌 |
| 低采样率 | 上沿越过奈奎斯特频率的带不计；剩下不到一半判「不知道」 | 同现行 #110 的做法 |

不采用：
- T4 的 0.579 / 0.421 权重：它的谱是线性幅度归一，和我们的 dB 刻度不同，权重不能直接搬。斜率先只报不判。
- 电信频响模板（T17–T20）当判定线：它们管的是终端的绝对频响、在安静里测、要求逐带都在窗内，和「处理前后的形状差」不是一个量。

## ④ 推荐分档线

**全部是建议值，没有直接出处**。做法：把听感研究里测过阈值的变化（T12–T15）在 exp017 上过一遍 ERB 量法，读出对应的数。

| 劣化（exp017 定标组） | ERB 读数 |
|---|---|
| 一个倍频程 ±3 dB（250 / 1k / 4k Hz） | 0.88–1.14 |
| 两个倍频程 ±4 dB（150 / 600 / 4 800 Hz） | 1.34–1.76 |
| 一个倍频程 ±6 dB | 1.73–2.30 |
| 两个倍频程 ±6 dB | 2.01–2.65 |
| 整体倾斜 −2 dB/倍频程（现行代码读 6.02，正好在旧的不过线上） | 3.29 |
| 一个倍频程压 12 dB | 4.15–4.27 |

| 档 | 线 | 理由（对应上表） |
|---|---|---|
| A | ≤ 1.0 | 小于「一个倍频程变 3 dB」。T13 倍频程的可察觉差是 2.8 dB |
| B | ≤ 2.0 | 最多相当于一个倍频程变约 5 dB、两个倍频程变约 4.5 dB，落在可察觉差的区间里（T12 3.5–7.3 dB） |
| C | ≤ 3.0 | 最多相当于两个倍频程变约 7 dB，到了 T12 区间的上沿 |
| 不过 | > 3.0 | 超过多数可察觉差的上沿。对整体倾斜，和旧的「> 6 dB 不过」大致同一处（−2 dB/倍频程：旧 6.02，新 3.29） |

要人耳怎么校（D44）：
- 用 exp017 的定标组做一页盲听：每种变化各做 3 个幅度，混进原声；
- 请人标「听得出 / 听不出」，求每个人的 50% 点，回灌改 A / B 两条线；
- 不过线（3.0）等真实候选的人耳打分出来再校。

## ⑤ 改了之后成绩单上这一项会怎么变（推断）

1. **v2 成绩单（现在判的是干净人声那一路）**：
   - 原声直通、参考降噪器：输出就是输入，两种量法都读 0，不变。
   - GTCRN：现行代码读数中位数 0.07、90 分位 0.39，480 段里没有一段 > 4（run `20261105-005916-4ccf0638`）。
   - 推断换成 ERB 后多半仍在 A / B。依据：exp017 里同一劣化 ERB 读数大多不高于代码读数。例外有两种：一是低频改动，代码看不见、ERB 看得见；二是输出里多出来的宽带底噪，这一路不扣噪声，ERB 比代码敏感（白噪声在信噪比 20 dB 时，ERB 1.71、代码 0.70）。**没实测**：那次 run 没存干净人声那一路的输出。
2. **带噪那一路（v2 下只报，标「旧口径」）**：
   - 在 480 段 GTCRN 真实输出上，ERB 中位数 2.36、90 分位 5.41；代码是 1.20、6.48。两者排序的相关 0.74（`runs/realout-20261105/`）。
   - 按新线，带噪那一路会有更多段落在 C 或「不过」。原因（推断）：低信噪比时高频带的语音本来就被压得多，四宽带取最大会被别的带稀释，ERB 不会。这一路不判，只影响旁报。
3. **不能只靠重新汇总看到变化**：新量法要重算音频。`--from-clips` 只能换判定线，换不了量法，要重跑成绩单（估时另报，要名额）。
