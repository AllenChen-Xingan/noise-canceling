# exp005 · P2 离线认人：VAD 快开慢关 · 零设置注册 · 不对称门控

> 意图：技术方案 `docs/plan/003_tech-design.md` 第二节、005 PSE 取舍卡「第 1 步」——不训练、不加延迟，认出主人，邻座单独说话时把他压低。
> 2026-10-30/31 手下 p2。数字全部本机实测（Apple M5 · macOS 27 · ort 2.0.0-rc.15 / ORT 1.31 · GTCRN simple · WeSpeaker ECAPA512），素材是合成的，**没有真人录音**。经三视角自审（代码 · 实验怀疑派 · 接入与规矩）后修了代码并重跑（第二轮，输出在 `_tmp/20261031-exp005/out-r2/`）。
> **人耳**：第一版盲听页（build 7448）人听后说「所有的都没降噪」，已作废（见文末）；第二版四候选盲听页待听。

## 一句话结论

- **认人能用**：8 段里 7 段在冷启动后 23–81 s 锁定（锁定前主人累计说了 20–28 s），可核对的 6 段都锁对主人，包括「会议开头邻座先说 25 s / 45 s」；c08（邻桌 4 人一直在聊）没锁——两个最大簇得分比 1.44，没到 1.5 倍门槛，规则选择了「不确定就不锁」。锁定后，主人独白的判断窗 211 次判成主人、0 次判成别人、3 次不确定；邻座独白窗 153 次判成别人、0 次判成主人、31 次不确定
- **保守设置压不干净**：锁定之后「只有邻座在说」的时刻，保守版的邻座残留相对输入是 −0.4 至 −3.8 dB，除 c01 外都比「只有 GTCRN」（−0.6 至 −5.6 dB）还高 0.2–2.9 dB——保守版混回了 −6 dB 原声（快开慢关），门控多压的那几 dB 大半是在抵消它。**人说「都没降噪」与此一致**
- **激进设置压得多一些**（不混回原声、门控下限 −20 dB、确认 1 次）：邻座残留 −0.9 至 −8.3 dB，比只有 GTCRN 再低 0.3–4.6 dB；代价是主人句首误压更多（见下）
- **代价在主人句首**：锁定之后主人说话的 hop 里，门控压低 > 3 dB 的比例保守版 0–6.0%、激进版 0.5–8.1%；**每句话开头 2 s 内**保守版 0–15.3%、激进版 1.3–19.0%（最差 c04）。按句转写（Qwen3-ASR，929 个词）删除：原声 1 · 只有 GTCRN 3 · 保守 1 · 激进 2——ASR 对整体压低不敏感，这个数说明「没被切掉整词」，**不说明句首没变轻**
- **快开慢关修好了「停顿里没人却开着」**：exp004 同 12 段上，非人声噪音（c09 杯碟）的停顿里 VAD 版开 6%，能量版 93%；但 12 段平均（71% → 73%）没变好，因为其中 8 段停顿里本来就有邻桌说话，VAD 判「有人声」是对的
- **延迟账**：VAD 包络与门控给 10 ms 实时回路加 **0 ms 算法延迟**（零前瞻，`latency_samples() = 0`）；每 16 ms hop 计算 p50 7.7 µs + 1.0 µs、最慢 22 µs + 11 µs。判断回路在另一个线程，每 0.5 s 一次 p50 6 ms（单线程，约占一个核的 1.2%），**不在声音通路上**

## 管线与四个版本

```
原声 ─► GTCRN（16 ms hop，延迟 256 样本）─► wet ─┬─► 只有 GTCRN（raw）
                                                  ├─► [VadEnvelopeStage 下限 −12 dB + 快开慢关 open −6 dB] ─► 个性化关（vad）
                                                  │        └─► [AsymGate 下限 −12 dB、确认 2 次、慢收 0.5 s] ─► 保守版（personal）
                                                  └─► [AsymGate 下限 −20 dB、确认 1 次、慢收 0.3 s] ─────────► 激进版（aggressive）
判断回路（另一线程，0.5 s 一次）：1.5 s 窗 → fbank → ECAPA → 注册器 / 打分 → SpeakerVerdict（两个门控共用同一份）
```

- **VAD**：earshot 1.2.2（纯 Rust、每帧零分配，256 样本 = 16 ms，正好 GTCRN 一个 hop），跑在降噪输出上，滞回 0.5 / 0.35
- **判断回路**：窗里 VAD 有声帧 < 30% → NoSpeech（门控保持）；否则算声纹。与主人余弦 ≥ 0.45 → Target，≤ 0.25 → Other，之间 → Unknown（放开）；上一份有人声的判决是 Other 且 < 0.35 维持 Other。判决按实测计算时间、单线程串行排队后生效
- **注册器**：只收「清楚的单人片段」（有声 ≥ 60%、与上一个窗声纹余弦 ≥ 0.6），时长按片段里新增的有声时间记。在线聚类（并入阈 0.5，簇中心 = 未归一化和再归一化），簇得分 = 按 5 分钟半衰的累计时长 × 近讲系数（比最响的簇每低 6 dB 减半；电平在**原声**上量）。锁定：首簇 ≥ 15 s、得分 ≥ 次簇 1.5 倍、连续 6 次居首、簇内平均相似度 ≥ 0.6；**只见过一个簇时要 30 s**。锁定后别的簇得分超过主人 2 倍且 ≥ 15 s 就改判。（`min_owner_s` 取 15 s 而非 003 §2.2 的 20–30 s：锁定还要 1.5 倍得分差与连续 6 次居首，实测锁定前主人累计 20–28 s，落在 003 的范围里）
- **门控**：起始 = 停顿 ≥ 0.3 s 后转有声（之后 100 ms 内都可判起始，句首软起音不错过），或 48 ms 短时电平比 1 s 背景高 8 dB（0.3 s 不应期）；**已知主人电平时，两种都还要短时电平 ≥ 主人电平 − 3 dB**（原声上量）→ 5 ms 内放开。判决 Other 且判决窗整个在最近起始之后、攒够确认次数 → 慢收；Target / Unknown → 50 ms 放开；NoSpeech → 保持
- **保守版确认 2 次的理由**：第一轮调参时确认 1 次比 2 次多压约 0.4 dB，但 c02（邻座只比主人轻 3 dB）主人句首误压从 2.5% 升到 11.4%；按「宁可漏噪音也不吃字」（003 §2.3）保守版取 2。激进版按大总管要求取 1，用来让人听这个取舍

## 结果

### 1. 对拍（`results/parity.json`）

| 段 | fbank 最大差（log 域） | fbank 平均差 | 声纹余弦（Rust vs Python） |
|---|---|---|---|
| c01 主人轨 3 s | 1.4e-4 | 4.6e-6 | 1.0000002 |
| c01 混合轨 3 s | 9.6e-5 | 4.5e-6 | 0.9999998 |
| c06 主人轨 1.5 s | 1.1e-4 | 4.9e-6 | 1.0000000 |

基准：kaldi-native-fbank 1.22.5 + Python onnxruntime 1.31.1 跑同一个 ONNX。fbank 选项与 WeSpeaker `resources/wespeaker/wespeaker/bin/infer_onnx.py:31-50` 一致（hamming、×32768、dither 0、窗内 CMN）。

### 2. 注册与判决（`results/scores.json` · `enroll` / `verdicts`）

| 段 | 锁定时刻 | 锁定前主人说了 | 锁对了吗 | 锁定后：主人独白窗 → 主人 / 别人 / 不确定 | 邻座独白窗 → 主人 / 别人 / 不确定 |
|---|---|---|---|---|---|
| c01 | 36.5 s | 23.7 s | ✅ | 27 / 0 / 0 | 0 / 38 / 0 |
| c02 | 23.5 s | 19.9 s | ✅ | 43 / 0 / 0 | 0 / 24 / 24 |
| c03 | 33.5 s | 21.7 s | 无主人独白窗¹ | — | 0 / 23 / 2 |
| c04 | 74.0 s | 24.3 s | ✅ | 16 / 0 / 0 | 0 / 18 / 0 |
| c05 | 81.0 s | 21.4 s | ✅ | 23 / 0 / 0 | 0 / 32 / 5 |
| c06 | 32.5 s | 27.9 s | ✅ | 71 / 0 / 3 | — |
| c07 | 46.0 s | 26.1 s | ✅ | 31 / 0 / 0 | 0 / 18 / 0 |
| c08 | **没锁** | — | — | — | — |

- 「锁对了吗」= 锁定后主人独白窗判成主人多于判成别人（判决对照时间表）。¹ c03 邻桌一直在说，没有主人独白窗；但锁定后邻座独白窗从未判成主人，说明没锁到邻座
- 判断窗定义：窗内主人有声 ≥ 60% 且邻座 < 10% 算主人独白，反之算邻座独白（`score.py`）
- 改判 0 次。全程（含锁定前）「主人在说的窗被判成别人」0–3 次 / 段；其中有的窗里没有邻座（如 c06 那 1 次），属于声纹误判，不全是重叠
- **防错锁的「单簇 30 s」规则没有被真正考验**：第一轮里 c05 邻座独白 45 s 没锁，实际原因是同一邻座被聚成了几个簇（最大 14 s），离 15 s 门槛只差 1 s——挡住错锁的是聚类不稳，不是规则。邻座更近、更响、独白更长时可能错锁；错锁后靠「得分超 2 倍」改判，本实验没触发过
- 另有一个参考字段 `enroll.final_owner`：用整段干净主人轨 / 邻座轨算的「真值声纹」与簇中心比余弦，普遍只有 0.1–0.6，c04、c05 还给出 `is_owner: false`。推断是真值对整条带大段静音的轨算声纹不可靠，**没验证**，所以不拿它判对错

### 6. 延迟与算力账

| 部件 | 在哪个回路 | 算法延迟 | 缓冲 | 计算（本机单线程） |
|---|---|---|---|---|
| VAD 快开慢关（earshot + 包络） | 实时，每 16 ms | **0** | 0（hop ≠ 256 时 VAD 内部重分块，判据最多晚 16 ms，声音不晚） | p50 7.7 µs，最慢 22 µs |
| 不对称门控 | 实时 | **0** | 0 | p50 1.0 µs，最慢 11 µs |

| 判决生效滞后 | — | — | 窗 1.5 s + 计算（串行排队，取整到 hop） | 「认出是别人」到门开始收约 1.5–2 s；这是决策滞后，不是声音延迟 |

## 已知局限

1. **合成素材**：RIR 合成、近场 / 远场差别比真实咖啡馆理想，主人比邻座响 3–9 dB 是设定的；没有作者自录。**近讲电平规则在邻座与主人一样近时失效**（c02）
2. **调参与报告用同一 8 段**（第一轮按重放扫过确认次数、慢收、判决窗、电平快路径），没有留出集；各组重放结果在 `results/scores.*.json`（第一轮），参数写在当轮日志 `gate` 字段（`_tmp`，未进仓）
3. **声纹确认要 1.5–2 s**：轮流说话、每段 3–8 s 的场景里，门有一大段时间来不及收；重叠语音（主人与邻座同时说）完全管不了（003 §2.3 已写明，交 M2）
4. 保守版快开慢关在「停顿里有旁人说话」时照样开着、混回 −6 dB 原声，这是它压不干净的主因；更合理的接法可能是把 open 也交给判决（Other 时不开），本批没做
5. 句首误压 0–19%（第 3 节），来源见第 3 节；没做「声纹变化」型起始线索
6. 防错锁规则没被真正考验（第 2 节）；c08 没锁住
7. ASR 只覆盖主人说话处、每文件一次、对句首变轻不敏感
8. earshot 权重来源未说明（009 发布阻断项）；ECAPA512 训练数据 VoxCeleb 需署名（发布前进 NOTICE）
9. **接入注意**（详见 `src/speaker/README.md`）：ort 一个进程只许一个 Environment（`ort-2.0.0-rc.15/src/environment.rs:514-516`），`Embedder` 已改成由调用方传入；时钟按 IO 采样率换算；VAD 全链只跑一份
10. 回归题待补（rlenv 建议）：「邻座说话中途你插话」「你连续说话、邻座同时开口」
