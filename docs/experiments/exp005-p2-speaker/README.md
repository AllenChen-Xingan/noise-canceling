# exp005 · P2 离线认人：VAD 快开慢关 · 零设置注册 · 不对称门控

> 意图：技术方案 `docs/plan/003_tech-design.md` 第二节、005 PSE 取舍卡「第 1 步」——不训练、不加延迟，认出主人，邻座单独说话时把他压低。
> 2026-10-30 手下 p2。数字全部本机实测（Apple M5 · macOS 27 · ort 2.0.0-rc.15 / ORT 1.31 · GTCRN simple · WeSpeaker ECAPA512）。合成素材，**没有真人录音、没有人耳结论**（盲听页已出，等人听）。

## 一句话结论

- **认人这一半成了**：8 段全部在冷启动后 22–79 s 锁定（锁定前主人累计说了 18–28 s），**锁的都是主人**，包括「会议开头邻座先说 25 s / 45 s」的两段；锁定后主人独白的判断窗 **0 次**被判成「别人」，邻座独白窗 154 次判成「别人」、1 次判成主人
- **压邻座这一半效果小**：开个性化后，锁定之后「只有邻座在说」的那些时刻，邻座残留电平平均再低 **约 1.2 dB**（各段 0.3–1.9 dB）；门控增益在这些时刻的均值是 −0.8 至 −4.5 dB，离 −12 dB 下限很远。原因是门要等声纹确认：判断窗 1.5 s 整个落在最近一次人声起始之后才作数，邻座一段话 3–8 s，前 2 s 左右门是开着的
- **没伤主人**：主人 929 个词，个性化开 / 关的吃字（删除）都是 1 个，替换 9 → 8，插入 4 → 4（Qwen3-ASR-Plus 1.7B）；主人说话的 hop 里门控增益 < −3 dB 的比例 0.1–2.9%，每句话开头 2 s 内 0.2–11.4%（最差是 c02：邻座只比主人轻 3 dB）
- **快开慢关修好了一半**：exp004 同样 12 段上，非人声噪音的停顿里 VAD 版只开 6%（能量版 93%，c09 杯碟）；**有旁人说话的停顿里 VAD 版照样开着**（98–99%），因为那里确实有人声——这一半只能靠认人来管
- **延迟账**：VAD 包络与门控给 10 ms 实时回路加 **0 ms 算法延迟**（零前瞻，`latency_samples() = 0`）；每 16 ms hop 计算 p50 7 µs + 1 µs，最慢 54 µs + 25 µs。判断回路在另一个线程，每 0.5 s 一次 p50 6 ms（单线程，约占一个核的 1.2%），**不在声音通路上**

## 管线

```
原声 ─► GTCRN（16 ms hop，延迟 256 样本）─► wet ─┬─► [VadEnvelopeStage] 衰减下限 −12 dB + VAD 快开慢关（open −6 dB）
                                                  │        └─► [AsymGate] × g，g ∈ [−12 dB, 0 dB]          ─► 输出
                                                  └─► 判断回路（另一线程，0.5 s 一次）：1.5 s 窗 → fbank → ECAPA → 注册器 / 打分 → SpeakerVerdict
```

- **VAD**：earshot 1.2.2（纯 Rust、每帧零分配，256 样本 = 16 ms，正好 GTCRN 一个 hop），跑在降噪输出上，滞回 0.5 / 0.35
- **判断回路**：窗里 VAD 有声帧 < 30% → NoSpeech（门控保持）；否则算声纹。与主人余弦 ≥ 0.45 → Target，≤ 0.25 → Other，之间 → Unknown（放开）；上一份是 Other 且 < 0.35 维持 Other
- **注册器**：只收「清楚的单人片段」（有声 ≥ 60%、与上一个窗声纹余弦 ≥ 0.6）。在线聚类（并入阈 0.5），簇得分 = 按 5 分钟半衰的累计时长 × 近讲系数（比最响的簇每低 6 dB 减半）。锁定：首簇 ≥ 15 s、得分 ≥ 次簇 1.5 倍、连续 6 次居首、簇内相似度 ≥ 0.5；**只见过一个簇时要 30 s**（开头只有邻座在说时防错锁）。锁定后别的簇得分超过主人 2 倍且 ≥ 15 s 就改判
- **门控**：起始（停顿 ≥ 0.3 s 后有声，或 48 ms 短时电平比 1 s 背景高 8 dB；**已知主人电平时还要短时电平 ≥ 主人电平 − 3 dB**）→ 5 ms 内放开；判决 Other 且判决窗整个在最近起始之后 → 0.5 s 慢收到 −12 dB；Target / Unknown → 50 ms 放开；NoSpeech → 保持
- 判决按实测计算时间延后生效（向上取整到 hop），模拟另一个线程

## 结果

### 1. 对拍（`results/parity.json`）

| 段 | fbank 最大差（log 域） | fbank 平均差 | 声纹余弦（Rust vs Python） |
|---|---|---|---|
| c01 主人轨 3 s | 1.4e-4 | 4.6e-6 | 1.0000002 |
| c01 混合轨 3 s | 9.6e-5 | 4.5e-6 | 0.9999998 |
| c06 主人轨 1.5 s | 1.1e-4 | 4.9e-6 | 1.0000000 |

基准：kaldi-native-fbank 1.22.5 + Python onnxruntime 1.31.1 跑同一个 ONNX。fbank 选项与 WeSpeaker `infer_onnx.py:31-50` 一致（hamming、×32768、dither 0、CMN 在窗内）。

| c01 | 29.0 s | 19.7 s | ✅ | 32 / 0 / 0 | 0 / 42 / 0 |
| c02 | 22.0 s | 18.4 s | ✅ | 46 / 0 / 0 | 1 / 24 / 23 |
| c03 | 32.0 s | 20.2 s | 无独白窗可判¹ | — | 0 / 19 / 6 |
| c04 | 71.0 s | 21.3 s | ✅ | 22 / 0 / 0 | 0 / 18 / 0 |
| c05 | 79.0 s | 19.4 s | ✅ | 27 / 0 / 0 | 0 / 32 / 5 |
| c06 | 29.5 s | 24.9 s | ✅ | 77 / 0 / 3 | — |
| c07 | 37.0 s | 21.7 s | ✅ | 35 / 0 / 0 | 0 / 24 / 0 |
| c08 | 46.5 s | 28.3 s | 无独白窗可判¹ | — | 0 / 15 / 0 |

¹ 邻桌一直在说，没有「只有主人」的窗；但锁定后邻座独白窗全判「别人」或「不确定」、从未判成主人，说明没有锁到邻座身上。
- **改判 0 次**；c04、c05 开头邻座独白时没有锁（c05 的 45 s 已超过单簇 30 s 门槛：邻座独白里声纹前后一致的窗不够多、电平也低，单簇时长没攒到 30 s——这道防线这次是**侥幸**过的，见局限 3）
- 全程（含锁定前）「主人在说的窗被判成别人」：0–3 次 / 段，都在主人与邻座重叠的窗里
- 收敛时间 = 锁定前主人累计说话 18–28 s，与 003 §2.2「累计 20–30 s」一致

### 3. 压邻座、伤不伤主人（只算锁定之后）

IRL = 只有邻座在说的样本上 10·log10(Σ输出² / Σ输入邻座²)，越负压得越多。「个性化关」= VAD 快开慢关 + 下限；「开」= 再加门控。

| 段 | IRL：模型原样 | 只开下限 | 个性化关 | **个性化开** | 门控增益均值（邻座独白时） | 主人被压 > 3 dB 的 hop | 其中每句开头 2 s 内 |
|---|---|---|---|---|---|---|---|
| c01 | −2.0 | −1.2 | −0.4 | **−2.4** | −4.3 dB | 1.4% | 4.2% |
| c02 | −2.3 | −1.6 | −0.8 | **−1.2** | −0.8 dB | 2.9% | **11.4%** |
| c03 | −4.3 | −2.5 | −0.9 | **−1.5** | −1.0 dB | 1.5% | 3.8% |
| c04 | −5.4 | −3.4 | −1.6 | **−3.3** | −4.5 dB | 2.5% | 6.7% |
| c05 | −5.6 | −3.4 | −1.5 | **−2.7** | −3.2 dB | 1.7% | 6.0% |
| c06 | — | — | — | — | — | 0.1% | 0.2% |
| c07 | −0.6 | −0.5 | −0.3 | **−0.6** | −1.4 dB | 0.6% | 1.7% |
| c08 | −3.8 | −2.5 | −1.3 | **−2.8** | −3.4 dB | 0.3% | 1.3% |

- **GTCRN 本身几乎不压邻座人声**（原样输出只低 0.6–5.6 dB），快开慢关的 −6 dB 混回原声再抬高一些；个性化把它压回到比模型原样略低的位置
- 「背景忽大忽小」：无人声时刻的输出电平，个性化开比关低 0–0.7 dB，没有明显抽动（数字，未经人耳）
- 调参记录（`--replay` 扫过的）：确认次数 2 → 1 多压约 0.4 dB、主人误压不变（锁定后主人独白窗 0 误判，所以敢只要一次确认）；慢收 0.7 → 0.3 s 再多 0.2–0.3 dB；判决窗 1.5 s → 1.0 s（每 0.25 s 一次）IRL 多 1 dB 但两段锁不上、主人窗出现误判，放弃；「持续轻人声就先收」快路径（门限 6 / 9 dB）几乎没有增益、主人误压略升，默认关。默认取确认 1 次、慢收 0.5 s（003 §2.3 写 0.5–1 s）

### 4. 吃字（`results/asr.json`，按主人每句话切段，参照 = 主人轨同段的转写）

| | 参照词数 | 删除 | 替换 | 插入 |
|---|---|---|---|---|
| 个性化关 | 929 | 1（0.11%） | 9（0.97%） | 4（0.43%） |
| 个性化开 | 929 | 1（0.11%） | 8（0.86%） | 4（0.43%） |

切段只覆盖主人说话的那几秒，所以测的是「门控有没有吃主人的字」，答案是没有；邻座漏进来的词大多在段外，这张表反映不了「压邻座」。每个文件只转写一次（没做两次一致性检查）。

### 5. 快开慢关：能量版 vs VAD 版（exp004 同 12 段，`results/envelope_compare.json`）

| 段（停顿里有什么） | 停顿里开着：能量版 | VAD 版 |
|---|---|---|
| c09 杯碟水声（非人声） | 93% | **6%** |
| c10 钢琴 | 24% | 14% |
| c01–c03 赌场（人声 + 机器） | 25–83% | 50–74% |
| c04–c08、c11、c12 邻座 / 邻桌说话 | 54–99% | **86–99%** |
| 12 段平均 | 71% | 73% |

均值 SI-SDR：只开下限 3.38 · 能量版 2.69 · VAD 版 2.71 dB（exp004 口径）。**VAD 只解决「停顿里没人说话却开着」**；exp004 那 12 段有 8 段停顿里本来就有邻桌在说，VAD 判「有人声」是对的。要让这些段停顿里收住，得靠本实验的认人门控，或把快开慢关的 open 也交给声纹判决（局限 5）。

### 6. 延迟与算力账

| 部件 | 在哪个回路 | 算法延迟 | 缓冲 | 计算（本机单线程） |
|---|---|---|---|---|
| VAD 快开慢关（earshot + 包络） | 实时，每 16 ms | **0** | 0（hop ≠ 256 时 VAD 内部重分块，判据最多晚 16 ms，声音不晚） | p50 7.4 µs，最慢 54 µs（≤ hop 的 0.3%） |
| 不对称门控 | 实时 | **0** | 0 | p50 0.9 µs，最慢 25 µs |
| 判断回路（1.5 s 窗：fbank + ECAPA + 注册 + 打分） | 另一线程，每 0.5 s | 不在声音通路上 | 1.5 s 音频环 + VAD 概率环 | p50 5.5–6.3 ms，最慢 8.8 ms → 约 **1.2% 个核** |
| 判决生效滞后 | — | — | 窗 1.5 s + 计算（取整到 1 hop） | 「认出是别人」到门开始收约 1.5–2 s；这是决策滞后，不是声音延迟 |

**合计给 10 ms 实时回路加 0 ms**，D32 的 45 ms 账不变。第一轮计时（与别的会话并发时）判断回路 p50 曾到 14 ms，最终数字取顺序重跑。

## 已知局限

1. **合成素材**：RIR 是合成的，近场 / 远场差别比真实咖啡馆更理想；没有作者自录，没有真人在场，近讲电平规则在真场景里可能不成立
2. **压邻座只有约 1–2 dB**：瓶颈是「声纹确认」的 1.5–2 s；在轮流说话、每段 3–8 s 的场景里，门有一半时间来不及收。重叠语音（主人与邻座同时说）完全管不了（003 §2.3 已写明，交 M2）
3. **防错锁那道「单簇 30 s」这次没被真正考验**：c05 邻座独白 45 s 也没锁，是因为他的独白里「前后一致的单人窗」攒不够 30 s，不是规则硬拦住的。邻座更近、更响、独白更长时会错锁；错锁后靠「得分超 2 倍」改判，本实验没有触发过
4. **c02（邻座只比主人轻 3 dB）**：近讲电平分不开，门很少收（−0.8 dB）、主人句首被误压 11.4%——邻座和主人一样近时，这套规则既压不住邻座又更容易伤主人
5. VAD 快开慢关在「停顿里有旁人说话」时照样开着；更合理的接法可能是把 open 也交给判决（Other 时不开），本批没做
6. 锁定判断只用了「判决 vs 时间表」；整段干净主人轨的声纹与降噪后窗口的声纹余弦普遍只有 0.1–0.6（`final_owner` 字段），不能直接当真值，原因没查（推断：GTCRN 输出与 1.5 s 短窗的分布差异）
7. ASR 每文件转写一次；切段只覆盖主人说话处
8. earshot 权重来源未说明（009 发布阻断项）；ECAPA512 训练数据 VoxCeleb 需署名
9. **接入注意**：ort 一个进程只许一个 Environment（`ort-2.0.0-rc.15/src/environment.rs:514-516`），vdn-models 与本 crate 各建一个会冲突。离线时降噪拆成单独子命令绕开；接入 engine 时要由一处建好 Environment 共用
