## 已知局限（如实）

1. **阳性对照是半循环的**：A 的 cafe / clatter / traffic 用的是 DEMAND 前 60% 时段，参照中心也由前 60% 算——它们过线只证明检查本身没坏，不证明什么
2. **线压在噪声底上**：真实录音自己互比，过线率也只有 88–100%；所以设了「临界」档（0.5–0.8）不判。每类只有 1–3 个真实环境，类中心不稳；要 014 的真实集（WHAM! 噪声、ACE、CHiME-4 CAF）才能把参照做厚
3. **只对齐了噪声**：语音素材（LibriSpeech 朗读 vs 会话体）、RIR（T60 / DRR 分布）、设备链、重叠率都还没有真实参照可比——本机没有任何现场录音（016 decision 第一节「真实锚为零」）
4. **S6 的三组统计量是自选的**〔建议值〕：没有证据说这三组距离小就等于「对降噪排名的影响小」；这正是 S7 / S8 要回答的
5. 设备链 `laptop`（100 Hz 高通 + 7 kHz 低通）是假设，等待人拍板 1-3（回放重录）实测替换
