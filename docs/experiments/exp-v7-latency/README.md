# exp-v7-latency · 链路延迟判据 V7（机器判）

> 问的是：GTCRN 实时链路（送音 → 共享内存 → 降噪 → 共享内存 → 虚拟麦）能不能把跨进程缓冲余量 `lead` 压到 ≤ 192 样本（4 ms，目标 144），且不欠载。
> 判据正本：`../noise_canceling-skeleton/_tmp/20261102-b8-rust/latency-fix.md`「修复目标」。测量代码：`src/cli/src/main.rs` 的 `vdn v7`、`src/cli/src/chain.rs`。

## 判据

- release 构建，`vdn v7`：GTCRN，连续 10 次 × 10 s，空闲一组 + 后台压力一组（7 个忙线程，本机 10 核）
- 欠载 0：处理后欠载（送音端取不到处理后的、用延迟原声补）、虚拟麦欠载、心跳过期都算
- lead ≤ 192 样本；GTCRN 链路 L_total ≤ 36 ms（1728 样本）
- 不算在 L_total 里的：虚拟麦读 Out 的相位（chain-test 里 1.5 个 IO 块）

## 结果

| 目录 | 日期 | 版本 | 一句结论 |
|---|---|---|---|
| `results/20261102-wake/` | 2026-11-02 | 唤醒（`Bus::wait` / `notify`）代替轮询；跳过 Raw 积压；送音端自建 Out 总线；其余同基线 | **过（lead 192，压线）**。192 空闲 / 压力各 10 次全部无欠载，GTCRN L_total 1728 = 36.00 ms。144 空闲 10/10 仍有欠载。空闲时推理那块仍约 2.9 ms（压力时 0.6 ms）：唤醒没改变卡点 |
| `results/20261102-poll-baseline/` | 2026-11-02 | 降噪线程 0.5 ms 轮询、未接唤醒、未加入 Audio Workgroup；IO 块 96、降噪块 96、预热 64 块、三个线程 time-constraint 优先级 | **不过**。lead 96 / 144 空闲 10/10 次都有处理后欠载；压力组 144 无欠载。空闲时每块处理慢 2–3 倍（推理那块约 3 ms），推断是降频或落到能效核（未核实）。空闲 3 次加扫：192–384 无欠载 |

### 20261102-wake 明细

和基线只差：降噪线程用唤醒代替 0.5 ms 轮询 · 降噪落后时跳过 Raw 积压（零占位 + 缺口计数）· Out 总线由送音端自建 · 纠漂移读方开着（同一时钟，不该动手）。

|---|---|---|---|---|---|---|
| 144 | 空闲 | 10 / 10 | 86 016 | 0 | 2.92 / 3.09 ms | 0.17 ms |
| 144 | 压力 | 0 / 10 | 0 | 0 | 0.60 / 1.17 ms | 0.06 ms |

| 96（粗扫 3 次） | 压力 | 0 / 3 | 0 | 0 | 0.60 / 0.62 ms | 0.05 ms |
| 288（粗扫 3 次） | 空闲 | 0 / 3 | 0 | 0 | 2.82 / 2.90 ms | 0.18 ms |
| 288（粗扫 3 次） | 压力 | 0 / 3 | 0 | 0 | 0.57 / 0.57 ms | 0.05 ms |

- 负载（`uptime` 1 分钟，核数 10）：开始 2.00 · 正式跑完 7.38 · 粗扫完 5.33，都不超核数，作数
- 文件：`v7-wake.{json,txt}`（正式 + 粗扫的终端输出都在 txt 里）· `sweep-wake.json`（粗扫）
- 另：16:31 有一次没跑完的（第一次 10 s 内停掉，为让另一位大总管的计时基准），不作数，没进仓
- GTCRN 链路 L_total：Pipeline 1536 + lead → 144 时 1680（35.00 ms）· 192 时 1728（36.00 ms）
- **结论**：V7 过线值 lead 192（4 ms）；目标 144（3 ms）没达到。卡点没变：空闲时单块最长约 2.9 ms（压力时 0.6 ms），和轮询基线一样 → 推断（未核实）是空闲降频 / 降噪线程落到能效核，人定 D68：低频运行、不追提频，lead 192（4 ms）为定值

## 复测命令

```
cargo build --release -p vdn-cli
./target/release/vdn v7 --model-path <gtcrn_simple.onnx> --leads 96,144,192 --runs 10 --seconds 10 --json <路径>
```
跑前后记 `uptime`；1 分钟负载超过核数的那一轮标「受外部负载影响」，不作结论。
