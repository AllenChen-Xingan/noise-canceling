# 场景试听 · GTCRN 降噪效果（2026-11-04）

每段 12 秒，来自场景测试集第五版（exp013）。每段有 3 个文件：

- `1原声`：麦克风收到的声音（说话人 + 环境噪声 + 设备链模拟）
- `2降噪后`：GTCRN 处理后的最终输出（和成绩单测的是同一份）
- `3干净参考`：只有说话人、没有噪声（理想效果，用来对照）

都是 16 kHz（降噪模型的采样率），所以听起来比真实通话略「闷」一点，这是采样率的问题，不是降噪造成的。

挑法：全部 480 段里，同时满足下面几条的只有 38 段，每个场景取最好的一段：

- 噪声压得比原声少很多

## 请留意听

- 降噪后噪声少了多少，剩下的噪声听着自不自然（有没有「真空感」、有没有「叮、啾」声）
- 说话人有没有变小、变闷、字头有没有被削
- 旁人说话（06 车厢广播、08 车站）有没有被压掉：GTCRN 只分人声和噪声，**旁人的声音它会留着**
