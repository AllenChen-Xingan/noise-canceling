## 4. 观察到的取舍（描述性，不判读）

- **红线和评分方向相反**：多留背景的候选（c1 / c5：下限 −6 dB）红线通过率最高（调参半 0.91 / 0.93，默认 0.77），但两个评分模型都给低分：调参半 A 均分 c1 2.809 / c5 2.782（c0 2.898），报分半 B 均分 c1 2.702 / c5 2.669（c0 2.802）。按场景调表和在线闭环常挑到它们，于是红线占比升到 0.854、评分降 0.02–0.05
- 这与人耳记录方向一致：作者在咖啡馆场景偏好「留一点背景」（`docs/experiments/human-prefs/scene-defaults.md` #1，低置信），而 ears 实测评分模型与作者在 48 对上只有 0.38–0.56 一致。**哪边对，评分模型判不了，要人耳**
- 次比较：按场景调好的表比查表更差（B −0.048）；在线闭环（部分反馈）比按场景调好的表 B 高 0.020（区间 [0.013, 0.030]），但吃字率差区间上界 1.09 个百分点超过非劣效界，判「无法判定」

## 5. 这说明什么、不说明什么

说明（只在模拟内）：

1. 在 GTCRN / FE-M 之后只动「下限 · 门控灵敏度 · 湿干比」三项，评分模型几乎分不出好坏（上界 +0.008 分）。用评分模型逐窗去调它们，收益是负的
2. 「只有部分反馈」与「全信息」都更差 → 问题不在反馈方式，在于可调空间里没有评分模型认可的收益

不说明：

1. 不说明「调节模型」整体没用：本实验没动模型选择、修音预设、认人门控，也没有真实录音（D62）
2. 不说明人耳听不出差别：红线与评分方向相反的那部分取舍（留背景 vs 压干净），正是评分模型与作者分歧的方向
3. 红线是理想红线（用了干净参考）且 V-ONSET / V-SPLVL 还是 L0
