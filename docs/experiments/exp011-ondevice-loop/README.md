## 2. 处理链（每段每组参数）

```
noisy ─► 模型（按路由表：GTCRN，或 babble / music 用 FE-M；只跑一次，缓存）
      ─► 修音链（路由预设；「固定默认」用 GTCRN + 预设 9）
      ─► 衰减下限 / 快开慢关：out1 = w + m·(dry − w)，m 由 OpenCloseEnvelope 对**未修音的模型输出**判（与 engine.rs:355 一致）
      ─► 湿干比：out = dry + strength·(out1 − dry)
```

- `strength` 全仓还没实现（r5），这里放最后一步；**先后顺序是本实验的选择，不是规约**
- 驱动 `driver/`：独立小 crate，按路径依赖 `vdn-dsp` · `vdn-eval`，不改 `src/`；编译 `CARGO_TARGET_DIR=<仓库根>/target cargo build --release --manifest-path driver/Cargo.toml`。另需 `cargo build --release -p vdn-eval` 与 `-p vdn-polish --example polish_offline`

## 4. 评分与红线

| 角色 | 用什么 | 说明 |
|---|---|---|
| **奖励 A**（本机小评分模型的替身） | DistillMOS v7（pip `distillmos`，ears 装在主目录 `_tmp/exp009-venv`） | 每 2 s 出一分，看最近 4 s |

## 5. 七种做法（报分半）

选择时**只用调参半的信息**，报分半的红线与留出分一概不看：

- **安全集合**：调参半上红线通过率不低于默认（c0）的候选。所有挑选都只在这里面挑（对应护栏「只在出厂验证过的配置里选」）

| 做法 | 怎么选参数 |
|---|---|
| default 固定默认 | GTCRN + 预设 9 + c0 |
| table 查表 | 路由模型 + 路由预设 + c0（现在的 `route.rs`） |
| table_tuned 按场景调好的表 | 路由模型 + 路由预设 + 每个细场景一组：调参半同场景 A 均分最高的安全候选（查表的上界） |
| tuned 调好的固定参数 | 路由模型 + 路由预设 + 一组：调参半 A 整段均分最高的安全候选 |
| **online_bandit 在线闭环（部分反馈，主）** | 第一窗用 table_tuned；之后每窗只拿到**正在用的那组**上一窗的 A；先验 = 调参半同场景均值（伪计数 1），置信上界选下一组（探索系数 0.1，事先定） |
| online_full 在线闭环（全信息，上界） | 每窗看所有安全候选上一窗的 A 选最高——要并行跑 8 条链，用户电脑上做不到，只当上界 |
| oracle_A 事后最优（A 挑） | 每段用 A 整段分挑安全候选 |

窗间 50 ms 等增益交叉淡化。拼接取自各候选「整段恒定参数」的输出，切换时包络状态的过渡没有模拟（局限）。

另算三种事后最优，都相对 tuned：A 挑 A 量（含「挑最大再量」的偏高）· A 挑 B 量 · **B 挑 B 量（真上界，判停用）**。

## 6. 判读规则（事先写定，结果出来后不改）

报分半 41 段、10 个说话人。区间 = 按说话人整簇重抽的 bootstrap 95%；另报按说话人整簇翻符号的置换检验 p 值。

对每个比较「X − Y」：

| 判读 | 条件 |
|---|---|
| **更好** | B 配对差区间下界 > 0，**且**红线「Y 过而 X 不过」的段 ≤ 1，**且**吃字率差区间上界 < 0.5 个百分点 |
| **更差** | B 配对差区间上界 < 0 |
| **无法判定** | 其余；**不等于「不比 Y 好」** |

- 主比较只有两个：online_bandit − tuned（主）、online_full − tuned。其余比较只作描述
- **讨好信号**：A 配对差区间下界 > 0，同时（B 区间上界 < 0，或 C_sig 区间上界 < 0，或吃字率差区间下界 > 0）
- **判停**（decision.md 待定题 2）：「B 挑 B 量」相对 tuned 的区间上界 < 0.1 分 → 支持「不做按声音自动调」；区间下界 > 0.1 → 支持「值得做」；其余 → 无法判定
- 在线闭环第一窗等于查表起点，会稀释差异 → 另报 B_tail（去掉前 2 s）当描述

## 9. 局限（先写下）

- 合成数据、单一作者听感未参与；结论只在模拟内成立（D62）
- 红线用干净参考，用户电脑上没有 → 是理想红线；且 V-ONSET / V-SPLVL 都是 L0
- 吃字的参考是干净参考的转写，不是真值文本；删除 + 替换的回溯同代价先走对角线，绝对值可能偏高，各做法同一口径
- 只隔离了目标说话人（见第 1 节）；报分半只有 10 个说话人，区间会宽
- DistillMOS 与 SCOREQ 训练来源可能重叠，错法未必独立（ears 2026-11-02）；ears 另实测：在作者听过的 48 对上，三个评分模型彼此一致 0.76–0.81，与作者只有 0.38–0.56（机器偏 DPDFNet-2、作者偏 GTCRN）
- 拼接没有模拟切换时的包络状态过渡
