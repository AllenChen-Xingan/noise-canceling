## 零、先看这 5 条

1. **规模**：15 个地点 × 16 段（常见 10 + 压力 6）× 12 s × 2 个设备 = 480 段（每设备 48 分钟）。第一版 build 4 进程 18 s 出完，仓外 3.2 GB（float32，每段 7 条以上的轨）【实测】。
2. **素材**：两批下载已由大总管批准并完成（实测约 447 MB，第二节），车内、地铁、候车厅都用真实 DEMAND 底噪；只有 `rail-air-cabin` 的舱噪是合成的。
3. **防泄漏**：exp006 训练用了 LibriSpeech test-clean 偶数位 20 人、6 个 DEMAND 环境的前 60% 时段、`sim.py` 的合成噪声函数。本集只用另外 20 人、后 40% 时段，合成声音全部自写，不 import `sim.py`。生成后跑交集检查，交集必须为空（第四节）。
4. **设备链**：`mba-builtin` 为主（022 的 9 步链），每个场景另出同一批素材的 `external-mic` 对照（不加设备链），蓝牙后做。参数只放一份参数文件，模块和 022 文档的数字由测试比对。
5. **还要人定的**：会议室「近处几个人都要留下」，这和其他场景「只留我」相反，需要先定这个场景怎么判（第六节第 1 题）。

**每段怎么组**（组法写进 `scenes.json`，正本见第五节）：
- 每段必有：主说话人 + 本地点底噪；再从「有规律 / 突发 / 旁人」三栏按概率各抽 0–2 种。压力档至少抽 2 栏。
- 主说话人：每段约 70% 时间在说话〔建议值〕，句间停顿 0.3–1.0 s；**每段开头 1.5 s 留空**，给门控类 verifier 量底噪。
- 语种：英文为主；每地点 2 段用中文主说话人（素材见第二节，人数少，标限制）。
- 突发声音在 12 s 里放 1–4 次，避开 / 压在说话上各半〔建议值〕，这样能分开量「说话时」与「停顿时」。

## 三、难度怎么抽

- **两档**：常见档（10 段）在第一节「常见」范围内均匀抽；压力档（6 段）在「压力」范围内抽，且至少加一种额外声音。压力档成绩单单列，不和常见档平均。
- **抽哪些量**：SNR · SIR（有旁人时）· T60 · 主说话人距离 0.4–0.8 m（默认 0.5，022 第 1 步）· 旁人距离与方位角 · 主说话人电平（022 第 6 步：−28 dBFS 为中心，σ 6 dB；`library-classroom` 用第一节的低电平）。
- **SNR / SIR 定义**（016 S2④）：都在**设备链之后**量。SNR = 主说话人活动段电平 ÷ **稳态**干扰（底噪 + 有规律 + babble + 设备底噪）整段电平，突发声不算、按各自 `rel_db` 单设（清单另给含突发声的 `snr_all_db`）；SIR = 主说话人 ÷ 听得清的旁人语音（旁人、电视、导航、广播人声）之和。
- **设到名义值的办法**：设备链除削波外都是线性的，所以每条轨先单独过链（增益 1），再按链后电平算缩放量。生成用帧门限 RMS 设增益，自检用另一个算法（ITU-T P.56 式活动电平）独立量（016 S2③，避免同一个函数自证）；容忍见第九节第 2 条。
- **削波**（022 第 8 步，概率 0.03）只进压力档；削过的段标「三轨不可加」，另存削波前的分轨。

对照对象：exp006 场景分类器训练 build `44df` 的清单（`docs/experiments/exp006-scene-sim/builds/`）。项目里的降噪模型都没用这批训练过；这里防的是将来拿 exp006 配方训练的模型在本集上虚高（016 S10）。

| 素材 | exp006 训练用了 | 本集只用 |
|---|---|---|
| LibriSpeech test-clean | 40 人按编号排序后偶数位 20 人 | 奇数位 20 人；再按人分两池：10 人只当主说话人，10 人只当旁人 / babble / 电视 / 广播 |
| DEMAND 6 个环境 | 每路前 60% 时段 | 每路后 40% 时段 |
| DEMAND 没被合成用过的 OOFFICE · TMETRO · PSTATION · TCAR | 没用 | **按时段切**（016 S10①「无说话人的按录音场次 / 时段」，大总管 2026-11-03 定）：前一半留作测试份（只测、不当任何合成原料），本集只用后一半；`leak.py` 起点落在前一半即判不过 |
| 合成噪声 | `sim.py` 的 `synth_*` 函数 | 本线自写，函数名、实现都不同；种子空间另起（基种子 20261103） |
| 房间冲激响应 | `sim.make_rir` | 本线自写（016 允许 RIR 函数相同，本线也不复用） |

- 每个 build 生成后自动跑交集检查（说话人 id · DEMAND「环境 / 通道 / 时段」· 合成函数名），对照 `44df` 清单；交集不为空 = 该 build 作废，不发。
- 本集用过的素材写进 build 目录的排除表 `exclude.json`。将来任何训练配方都要先减掉它（016 S10 第 3 条，裁判原料永不训练）。
- 已知限制：可用的英文说话人只有 20 人、都是朗读，没有会话体（016 S4 今天不过）；中文主说话人只有 2 人。
- **本集与 exp006 的评测份（test / seq）同池**：说话人 20 / 20 都在 exp006 test / seq 里出现过，DEMAND 也有时段重叠（数字在每个 build 的 `manifest.json` → `leak_check.exp006_eval_overlap`）。exp006 曾用 test / seq 选场景分类器的滞回参数，所以 **exp006 场景分类器（及任何用 exp006 test / seq 调过参的东西）不能在本集上评**。降噪模型不受影响：没有一个用 exp006 素材训练或调参过【读源码 + 016 S10】

## 九、实现与上面方案的偏差（2026-11-03，实现后补）

1. **全链在 16 kHz 上算**：022 第 9 步本来就重采样到 16 kHz，8 kHz 以上的频响点对输出没有影响；参数文件里仍保留，供与 022 比对（`device_chain.json` 的 `_偏离`）
2. **SNR / SIR 核对分两层**：生成用 gated 电平设增益，自检用 P.56 独立量（016 S2③ 不许同一函数自证）。两种算法对稀疏人声本来就会差：480 段里 95% 差 ≤ 1 dB，最大 1.5 dB【实测，build 前冒烟】。所以测试改成：①管线核对：从 wav 读回、用生成时的定义重算，≤ 0.1 dB；②独立算法：≥ 95% 段 ≤ 1 dB、全部 ≤ 1.5 dB
3. **SNR 只算稳态干扰**（底噪 + 有规律 + babble + 设备底噪），突发声按各自 `rel_db`（相对主说话人，常见 −18 到 −6、压力 −10 到 +2 dB〔建议值〕）单设；清单另给 `snr_all_db`
