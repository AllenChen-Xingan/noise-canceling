## 一句话

**人耳定「什么算好」→ 合成数据把它放大成大量带真值的格子 → 尺子和评委按格子打分 → 优化器在硬红线内把参数调到分最高 → 闸门挡退步 → 人耳抽查回灌，修正尺子和合成器。** 作者的耳朵只做校准（D51），「什么好」的大头来自众人评分 + 合成好坏配对。

### ⑥ 回灌（越用越准）

- 人工层结果 → 重算尺子 / 评委的一致率 → 改级别（`vdn-eval calib`）
- 失败片段 → 能力集新任务 → 对应合成格加权
- 合成格预测效度不过 → 回 ② 改合成器（不是改尺子去迁就）
- 偏好变化 → `specs/rubric/preferences.md`

## 一次改动走一遍

改一个参数或模型 → CI 合成格全过、不比基线差 → QA：评委分升、红线不破、真实锚不退 → 攒够一批改动后人盲听（含锚点题）→ 结果回灌定级 → 合并 / 发版。
