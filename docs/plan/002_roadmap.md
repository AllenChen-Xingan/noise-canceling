## 不变的原则

- **先能量，再优化**（设计稿 §16「优化的顺序」）：评测（阶段 B）排在写实时代码之前；之后按回报排序：微调 → 调度 → 延迟 → Neural Engine
- **每件产出至少让一把尺子变好，另两把不变差**（`.42cog/intent.md`）
- **从不吃字优先于降噪更干净**：任何阶段，出事时送原声，不送静音

## 会改这张图的事

- exp003 听测结果：若你选 ≤45 ms，主模型是 GTCRN，阶段 C 起步更快但效果上限低；若选 ≤75 ms，主模型是 DPDFNet-2
- 005 结论：若有合格的个性化模型能直接替代通用模型，M2 可能并进 C / M1
- M0 实测延迟：若管线那一跳超出 20 ms 预算，M3 插件要改读共享内存（003 二期）
