收口条件（全部满足才算这件大事做完）：
1. 两组候选各冻结一个（权重哈希进清单），各上一次开发评测
2. 有一份结论：过线 / 不过线，带评分项名 · 配对差 · 95% 区间（第五节第 3 条）
3. 训练代码、数据切分表与哈希、云机器配置都在仓里，换一台云机器能复现

## 五、验收怎么判（沿用 027 第四节，口径合一）

1. 只微调组对原版、加注意力头组对只微调组，都用配对差 + 按源片段成组 bootstrap 95% 区间
2. 要涨：街边场景 ESTOI 均值 ≥ +0.01，区间下界 > 0；两个评分模型都 ≥ +0.05 才算听感变好
3. 不许退：字头 · 背景跳变 · 音色退步区间上界 ≤ 1 · 2 · 1 dB（R-2 默认，待你定）；吃字 · 人声被压低不新增否决段
4. 终测（独立场景集）只在冻结最终候选后跑一次，本大事里不跑，收口时列为下一步
