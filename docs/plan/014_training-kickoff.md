收口条件：
1. 缺口表出了（不混回基线，场景 × 评分项）
2. 两组候选（A 只微调 · B 微调 + 时间注意力头）各冻结，用配对比较判过 / 不过，带区间与种子噪声底

## 三、验收

1. 用第 0 步的配对比较：A 对原版、B 对 A；按源片段成组 bootstrap 95% 区间
2. 噪声底：同一配置两个种子互比，差异当「运气」的尺度；候选的进步要明显大于它
3. 要涨：目标场景可懂度均值 ≥ +0.01、区间下界 > 0；两个评分模型都 ≥ +0.05 才算听感变好
4. 不许退：字头 · 背景跳变 · 音色退步区间上界 ≤ 1 · 2 · 1 dB；吃字 · 人声被压低不新增否决段；其他场景不新增「不过」；延迟仍 43.7 ms
5. 人耳：不做盲听（D99）；结论写明「人耳未测」，并注明评分模型之一抓坏段比例只有 0.20（031）
6. 只在合成场景集上判时，结论写明「只在合成集上判」；真实会议集定了再补跑
