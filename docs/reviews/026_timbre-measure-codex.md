  - 处理：改成先减中位数、再截下限、再减均值。新加劣化「低通 4 / 2 kHz 后再 ±20 dB」，读数与不改音量逐位相同（J4）

  - 处理：① 新加一段写明「推荐量法是共同结构的简化，省掉听觉模型那一层，相关多少无文献数，待验证」；③ 把等权、不降高频标为建议；T15 改为只作量级参照
