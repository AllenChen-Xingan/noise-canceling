# 助手回复对照 ASD-STE100 的审查（2026-10-31）

> 结论：最伤清晰度的是三件事：对人用没解释的编号、同一个词有几个意思、整段英文。规则已写进 `CLAUDE.md` 第七节，本文只放依据。

## 范围

- **材料**：本项目全部 29 个会话（2026-10-29 至 10-31，约 1950 条消息），用 `42plugin chat export --session <id>` 导出。项目从 10-29 才开始，所以这已是全部历史，凑不满 30 个会话。
- **谁说的话**：只有 8 个主目录会话（大总管）里有人的原话，最强的证据来自 `a484e9ed`（622 条，人发了约 75 条）和 `c3cf2d29`。其余 21 个是手下会话，那里的「User」是大总管或子代理。
- **方法**：5 个子代理分组逐条读助手回复，按 ASD-STE100（简化技术英语）的写作规则改成中文版来对照，并记录人表现出困惑的地方。分组明细在本目录 `group1.md`–`group5.md`。

## 做得好的写法（照着做）

- 先给结论：「结论：你的耳朵和机器分方向相反」（`3f8799ec:876`）。
- 拍板题改写成人能感知的四档毫秒数，并写出超过国际电信联盟建议的 150 ms 会怎样（`867e4cc6:484`）。
- 先写白话，术语放括号：「零件包（crate）」（`878b2dbe:533`）。
- 人问「这些数据有啥用呢」，回复第一句点题，再分六条讲用途，人回「李姐了」（`c3cf2d29:561`）。
- `cbc3062d` 全篇：第一句讲原因，数字带基准（负载 26，超过 10 就排队），三个选项各写后果，最后问人要不要动手。
