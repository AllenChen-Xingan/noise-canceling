人原话（2026-11-02）：「记住，必须我们有办法完全榨干硬件的性能，以及非常低能耗 / 必须保证这个东西非常清亮」（「清亮」AI 理解为「轻量」，待人确认）。同日先定 D69：整机 CPU 目标 ≤ 1% 个核、硬上限 2%。

**为什么**：别家常开 ML 降噪公开 CPU 在 2–5% 个核（019 `notes/references-products.md`）；人要明显更低，且不以快换电。

**怎么用**：
1. 榨干硬件：每个模型都要试遍可用的计算单元（NEON 向量指令 · Accelerate/AMX · BNNS Graph · 神经引擎 · GPU），选最快的；不能「ORT 能跑就行」
2. 能耗：以「每帧耗电」比，不只比快；快而费电不算赢（019 BE-POWER）
3. 轻量：安装包体积 · 常驻内存 · CPU（D69）都要有数字和过线值；新加部件先说它占预算多少
4. 一切测速从 Rust 调（D68）
