# 调研产出不写本机绝对路径

**规则**：调研笔记、怀疑派记录、原始报告（`raw/` · `findings/` · `notes/`）里不写本机绝对路径——`/Users/<用户名>/…`、`/private/tmp/claude-…`、`~/.claude/…` 都含用户名。临时文件写「本会话临时目录（不入库）」，仓库内文件写相对路径（如 `resources/…`、`src/…`）。

**为什么**：铁律 12 外发检查。2026-11-03 b10 批次两条线（021 scenes 4 处 · 022 macmic 10 处）都在子代理写的原始报告里留了含用户名的缓存路径，验收才拦下；同类第二次 → 改做法。

**怎么做**：
- 起 workflow 时提示里写死「交回的文字不写本机绝对路径」
- 手下报「可以收尾」前自己跑：`grep -rnE "/Users/|/private/tmp|~/.claude|<用户名>" <你的目录> docs/reviews/<你的评审> state/handoff/<你>.md`，结果为 0
- 大总管验收清单照跑同一条 grep
