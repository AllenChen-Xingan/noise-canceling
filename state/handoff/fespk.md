## 待人拍板

背景：认人说话时约占一个核的 0.6%（本次实测；exp005 的旧数是 1.2%），目标 0.15%，差约 4 倍。共用频谱实测最多省约 5%（大总管已定不做）。三项合用的估算见 exp015 README 第 3 节：1 s 判一次 + 1.0 s 窗，不量化约 0.21% 个核；再加量化快 2.5 倍约 0.09%。但 exp005 多出的约 3 ms 来源不明；如果它是每次判断固定要花的，同样配置约 0.39%，到不了线。所以「能到线」要先在真实流程里复测判断回路才算数。要省更多，只能动下面这些。下面「省多少」都是按「耗时与每秒处理的帧数成正比」推断，没实测。

1. **认人多久判一次？** 现在 0.5 s 一次。
   - 选项：保持 0.5 s · 改 1 s（省一半）· 同一人一直说时 2 s 一次、有人起头再恢复 0.5 s（省 1.5–4 倍，看说话方式）
   - 你能感知的后果：改 1 s 后，旁人开口到他的声音开始被压低，从约 1.5–2 s 变成约 2–2.5 s。「判稳后降频」时，如果换人中间没停顿，要等下一次判断（最多 2 s），而那一次的窗里可能还混着上一个人，可能还要再等一次，总共晚多久未量化。另外，开会开头「认出谁是主人」可能要更久，认错后改回来也可能更慢（多久未量化，选定后要在 exp005 素材上重测）
   - 如果你不回，默认保持 0.5 s，后果是认人仍约占 0.6–1.2% 个核（两次测量不一致，待查），超过分给认人的 0.15%
2. **认人一次听多长？** 现在 1.5 s。
   - 选项：保持 1.5 s · 缩到 1.0 s（省约 1/3）
   - 你能感知的后果：听得短更容易判「不确定」，那时门开着，旁人声音漏得更多；认出主人要多久、认错后多久改回来也会变（都未量化，要在 exp005 素材上重测）
   - 如果你不回，默认保持 1.5 s
3. **声纹模型要不要做省算力的实验？** 现在用 ECAPA512 原样（32 位浮点）。
   - 选项：不做 · 另起一条实验线试 8 位整数量化（不重训，推理那一截能快几倍待测）和更小的模型，用等错率判是否认得更差
   - 你能感知的后果：选对了，认人耗电少、发热少；选错了，主人被当成旁人压低的次数变多。上线前会有判据把关
   - 如果你不回，默认不做，后果同第 1 题

三题默认值合起来 = 现状不变，互不矛盾；也不碰已定的决策（D71 只管频谱共用）。
