# 降噪 rubric：一个降噪实现能不能用、排第几

> 规约 · 被路径引用，不编号、不带日期，版本走提交链。起草：手下 rubric（2026-10-30，批次 20261030-b2）。
> 调研依据：`docs/research/007_denoise-rubric/`（must-know · sources · gap）。用它打分的结果：同目录 `decision.md`。
> **标 〔建议值〕 的数字是 AI 估的、没有出处，等人拍板**（见 `decision.md` 末节）；标 〔有出处〕 的给了来源。

## 0. 怎么用

拿到一个候选（模型 + 推理代码），按顺序走四关，每关的输入都是已有的文件，不需要人临场判断：

| 关 | 判什么 | 谁判 | 输入 | 不过的后果 |
|---|---|---|---|---|
| **一 否决** | 有没有一票否决项（第 2 节） | 脚本 + AI 查文档 | 候选登记表（第 8.1 节）· 机器打分 · AB 导出 | **不入围**，不再往下打分 |
| **二 机器分** | 三把尺子 11 个维度各落哪一档（第 3 节） | 脚本 | 机器打分（exp003 `scores.json` 及以后的 eval 输出） | 得出机器总分 M（0–100） |
| **三 人耳分** | 作者盲听的四项（第 4 节） | 人答、脚本算 | AB 页导出 JSON（exp003） | 得出人耳分 H（0–100）与「有效 / 打折 / 作废」 |
| **四 裁决** | 合成排名，处理人耳与机器打架（第 5、6 节） | 脚本按规则 + 人复核矛盾段 | 上面三关的输出 | 排名 + 「能用 / 待听 / 只作参照」 |

这是 CLAUDE.md 第三节「三层验证」的中间那层：**规则判**（否决与落档，脚本做）→ **判据判**（本文）→ **实效判**（作者听、真会议用）。rubric 判不了真实会议里对方的感受，那一层永远在 rubric 之上（`.42cog/intent.md`「真相源与权重」第 1 位）。

### 打分单位：场景组

所有机器指标先**按场景组**算，再汇总。场景组对齐 exp003 素材（`docs/experiments/exp003-offline-ab/make_clips.py` 的 `cat` 字段）与 004 评测矩阵：

| 组 | exp003 片段 | 为什么单列 |
|---|---|---|
| G1 非人声噪音 | c09 杯碟 · c10 背景音乐 | 通用模型的本职 |
| G2 单个干扰说话人 | c04 · c05 · c12 | 意向书「真难题」1；PSE 的主战场 |
| G3 多人 babble | c01–c03 · c06–c08 · c11 | 咖啡馆主场景 |
| G4 中文 | c11 · c12（与 G2/G3 重叠） | 中文吃字单独看 |

**吃字类维度取最差组**（只要一个场景吃字就是吃字）；其余维度取各组均值，但**最差组比均值低两档以上时，整维降一档**（防「平均掩盖短板」）。

## 1. 三把尺子 × 维度总览

| 尺子 | 维度 | 主指标（004 选定的量具） | 交叉 / 制衡 | 权重 〔建议值〕 |
|---|---|---|---|---|
| **清楚** 40 | C1 吃字 | 删除率差 Δdel = 候选 − 原声直通（Qwen3-ASR，D28） | 脑补率差 Δins；人耳 H4 | **18** |
| | C2 压噪 | 非语音段噪音衰减 `noise_att_db` | 残留相对电平 `resid_rel_db` | 8 |
| | C3 人声损伤 | 语音帧能量损失（dB） | ESTOI 对原声的差 | 8 |
| | C4 干扰者残留 | 干扰者残留电平 IRL（005 #1） | 声纹相似度（005 #2） | 6 |
| **自然** 35 | N1 整体听感（无参考 MOS） | SCOREQ natural NR | UTMOS；DNSMOS OVRL 只作冒烟 | 8 |
| | N2 伪影 | 人耳缺陷标签率（AB 页 `tags`） | NISQA DIS/COL（用户自装，可缺） | 10 |
| | N3 背景稳定 | 非语音段 100 ms 短时响度的标准差 + 跳变次数 | 人耳标签 `pumping_bg` · `vacuum` | 9 |
| | N4 音色 | 与干净参考的 LTASS 分频带偏差 | LUFS 差；人耳 `muffled` | 8 |
| **轻快** 25 | L1 附加延迟 | 端到端附加延迟 ③（002 口径） | 互相关实测 ① | 9 |
| | L2 最坏一帧 | 合计 max ÷ 周期（exp001 口径） | p99.9 | 6 |
| | L3 耗电 | 平均每帧耗时 ÷ 周期（单核占比，近似 CPU） | 能效核实测（待测） | 5 |
| | L4 落地 | 许可 · Rust 逐帧 · 维护 · 采样率（定性四项） | — | 5 |

**防讨好的三条硬规则**（理由见 `docs/research/007_denoise-rubric/must-know.md`）：

1. **任何单一指标在总分里不超过 18 分**；三个无参考 MOS（SCOREQ / UTMOS / DNSMOS）合计不超过 8 分
2. **制衡对必须同时看**：C2 压噪拿 A 档、而 C3 人声损伤或 C1 吃字落 C 档以下 → 记「过度抑制」，C2 降为 C 档（压得狠不算本事）；N1 MOS 拿 A 档、而 N2 人耳伪影落 C 档以下 → N1 记 C 档（MOS 被讨好）
3. **交叉指标与主指标方向相反**（一个说变好、一个说变差，各超一档）→ 该维度标「矛盾」，不计分，挑片段进人耳复核（第 6 节）
4. **好输入不许修坏**：最高 SNR 的片段（exp003 c08，10 dB）上，候选的删除率不得高于原声直通、ESTOI 不得低于原声直通 0.02 以上；违反 → C1、C3 各降一档。依据：AATC 2025 的基线把高 SNR 输入的 WAcc 从 0.989 拉到 0.929（arXiv 2509.12974 §D）
5. **无参考分高 + ESTOI 低于原声 = 疑似重合成 / 幻觉**（URGENT 2025 分析的建议信号，arXiv 2507.11306 §4.2）→ N1 记 D，并把该段送人耳逐字核对
6. **DNSMOS 只取 BAK 作 C2 的旁证，SIG / OVRL 只报警不计分**：DNSMOS 被当训练目标时「指标最好、听测最差」（CHiME-7 UDASE，arXiv 2402.01413 §6.2.5），在 hybrid 系统上 SIG/OVRL 与 MOS 反向（AATC 2025，只有 4 个点，方向性证据）

## 2. 一票否决项

任何一条成立 → **不入围**。分「硬事实」（人耳也推翻不了）与「可复核」（人耳定向复核可以撤销）两类。

| # | 否决项 | 判法 | 数据从哪来 | 类 |
|---|---|---|---|---|
| V1 | **非因果** | 推理需要未来超过声明前瞻的样本，或需整句 / 整段输入 | 代码与论文；流式逐帧跑一遍与整段跑结果比对 | 硬事实 |
| V2 | **端到端附加延迟 ③ 超上限** | ③ = 管线直通 6–10 ms + ①（窗长 + 前瞻）；上限 **待 D01 拍板：45 ms 或 75 ms** | 002 decision 延迟表；互相关实测 | 硬事实 |
| V3 | **最坏一帧超周期一半** | exp001 口径（M5 单线程，模型 + STFT 合计 max） > 周期 × 50% 〔有出处：与 DNS 2023 / AEC 2023 实时赛道「单线程 RTF ≤ 0.5」同线（arXiv 2303.11510 · 2309.12553 §III-B）；002 decision「单线程推理预算」。我们用最坏一帧而不是平均，更严〕 | exp001 / 同法实测 | 硬事实 |
| V4 | **许可不兼容** | 代码或权重与 GPL-3.0 不兼容（NC、禁止再分发、无许可）。**许可「不明」不否决，记「挂起」**：可以评测，不能进发布 | 仓库 LICENSE · 模型卡 · issue | 硬事实 |
| V5 | **不能在 Rust 里逐帧跑** | 既非 Rust 原生，也没有状态显式的单帧 ONNX（或可导出成这样） | 002 命门 3 | 硬事实 |
| V6 | **数值失效** | 任一片段出现 NaN / Inf、整段静音（输出比输入低 40 dB 以上）、或掉帧 | 推理日志 · `scores.json` | 硬事实 |
| V7 | **比原声更吃字** | 任一场景组：Δdel > **+1 个百分点** 〔D10 已拍板试跑值〕，**且**配对 bootstrap（按句重采样 10000 次）的 95% 置信区间不含 0。句数不足 30 时只报「疑似」，不否决 | `scores.json` 的 `del_rate`（候选列与 `noisy` 列） | 可复核 |
| V8 | **人耳判不能用** | 有效会话里，该候选在 ≥ **1/3** 的非陷阱段被选「不能用」〔建议值〕 | AB 导出 `by_model.usable` | 可复核（隔天再听一次可撤销） |

V7 的复核：挑出删除数差最大的 5 句，作者对照原声定向听；作者判「没吃」≥ 4 句 → 撤销否决，记一行「ASR 与人耳不一致」（这条数据用来校准 ASR，见第 6 节）。理由：真相源权重里人耳 AB（第 2 位）高于专项自动指标（第 3 位）；而 Qwen3-ASR 是 LLM 解码器，可能把伪影「听成」删除，也可能把吞掉的字脑补回来（D28 风险）。

## 3. 机器维度：四档锚点

四档：**A 好（3 分）· B 可用（2 分）· C 勉强（1 分）· D 不可用（0 分）**。维度得分 = 档分 ÷ 3 × 权重。
每档写两样：**指标落在哪**（脚本用）和 **听起来是什么样**（人复核时对照）。

### 清楚

**C1 吃字**（主：Δdel = del_rate(候选) − del_rate(原声直通)，百分点；取最差场景组）

| 档 | 指标 | 听起来 |
|---|---|---|
| A | Δdel ≤ −2，且配对 CI 上界 < 0（显著比原声少丢字） | 原声里被噪音盖住的字，处理后能听出来 |
| B | −2 < Δdel ≤ 0 | 和原声一样能听全，没有新丢的字 |
| C | 0 < Δdel ≤ +1，或 +1 以上但不显著 | 偶尔一个字头发虚，要回放才确定 |
| D | 触发 V7 | 句子里有字被抹掉、句尾被截，对方会问「你说什么」 |

另记 **Δins（脑补率差）> +1 个百分点** → 标「ASR 可能脑补」，C1 不升档，只能降档或持平，并把这些句子放进人耳复核。

**C2 压噪**（主：非语音段 `noise_att_db`，各组均值；交叉 `resid_rel_db`）

| 档 | 指标 〔建议值；依据：设计稿 §5 衰减下限 12–20 dB〕 | 听起来 |
|---|---|---|
| A | ≤ −20 dB | 停顿时几乎听不到背景，但不是死寂（见 N3） |
| B | −20 < x ≤ −12 | 背景明显变小，仍听得出在咖啡馆 |
| C | −12 < x ≤ −6 | 背景小了一些，邻桌说话仍清楚可辨 |
| D | > −6 dB | 跟原声差不多 |

制衡：见第 1 节硬规则 2。**babble 组的 C2 只算非人声部分**（人声噪音交给 C4），否则通用模型会因「保留了邻桌人声」被重复扣分。

**C3 人声损伤**（主：语音帧能量损失 = 候选 ÷ 干净参考，只在参考有语音的帧、按 004 统一前处理对齐后算；交叉 ESTOI(候选) − ESTOI(原声)）

| 档 | 指标 〔建议值〕 | 听起来 |
|---|---|---|
| A | 损失 ≤ 1 dB，且 ΔESTOI ≥ +0.05 | 人声饱满，和干净录音一样响 |
| B | 损失 ≤ 2 dB，且 ΔESTOI ≥ 0 | 人声略薄，但不费劲 |
| C | 损失 ≤ 4 dB，或 −0.05 ≤ ΔESTOI < 0 | 人声变小、变远，句尾变弱 |
| D | 损失 > 4 dB，或 ΔESTOI < −0.05 | 人声被一起压下去，像隔着墙 |

**词首 50 ms 单看**：每个词首（参考 ASR 时间戳或能量起点）的能量损失比全帧平均多 3 dB 以上 → 标「吞字头」，C3 降一档（门控类模型最常见的伤）。

**C4 干扰者残留**（只在 G2 / G3；主：IRL，005 #1 口径，只算「只有干扰者在说」的段）

| 档 | 指标 〔建议值；005 第 1 步失败线「IRL 改善 < 6 dB」作 C/D 分界〕 | 听起来 |
|---|---|---|
| A | ≤ −15 dB | 邻桌说话只剩模糊的底，听不出内容 |
| B | −15 < x ≤ −10 | 邻桌在，但比你小很多 |
| C | −10 < x ≤ −6 | 邻桌小了点，内容仍可辨 |
| D | > −6 dB | 邻桌和原来一样 |

**通用模型在这一维落 C / D 是预期的**（002 decision「babble 不是这个选择能解决的」），不否决；它决定的是要不要上 PSE。

### 自然

**N1 整体听感**（主：SCOREQ natural NR，与干净参考同指标比；交叉 UTMOS）

| 档 | 指标 〔建议值〕 | 说明 |
|---|---|---|
| A | 候选 ≥ 干净参考 − 0.3 | SCOREQ 与 UTMOS 同向才算；**没有 SCOREQ 时最高给 B**（UTMOS 在真实录音 CHiME-7 上逐句 SRCC 只有 0.33，SCOREQ 0.75，arXiv 2601.18438 表 10）；DNSMOS 不进 N1（硬规则 6） |
| B | 候选 ≥ 原声 + 0.5 | |
| C | 原声 ≤ 候选 < 原声 + 0.5 | |
| D | 候选 < 原声 | |

真相源第 4 位：只作筛选。所以权重低，且受硬规则 2 制衡。

**N2 伪影**（主：人耳缺陷标签率 = 该候选被打了 `metallic` / `clipped_onsets` / `pumping_voice` 任一标签的段数 ÷ 非陷阱段数；交叉 NISQA DIS/COL）

| 档 | 指标 〔建议值〕 | 听起来 |
|---|---|---|
| A | ≤ 10%，且无一段被标 `metallic` 两次以上（重听） | 没有怪声 |
| B | ≤ 25% | 个别段有一点水声 / 发颤，不影响 |
| C | ≤ 50% | 一半的段能挑出怪声 |
| D | > 50% | 怪声是常态 |

没有人耳数据时：N2 记「待听」，机器总分按剩余权重归一（第 5 节），并在结果里标出。**这一维没有可靠的自动指标**（must-know 第 9 条），所以不拿 NISQA 单独定档。

**N3 背景稳定**（主：非语音段 100 ms 短时响度（LUFS-M 口径）的标准差 σ 与「200 ms 内变化 > 6 LU」的跳变次数 / 分钟；交叉人耳 `pumping_bg` · `vacuum`）

| 档 | 指标 〔建议值〕 | 听起来 |
|---|---|---|
| A | σ ≤ 原声 σ + 1 LU，跳变 ≤ 原声 | 背景像原声一样平稳，只是更小 |
| B | σ ≤ 原声 σ + 3 LU，跳变 ≤ 原声 + 2 / 分钟 | 偶尔一下背景「吸」上来 |
| C | σ ≤ 原声 σ + 5 LU | 每次停顿背景先没了再涌回来（抽吸） |
| D | 更大；或非语音段输出比底噪低 40 dB 以上（真空） | 一说话背景就出现、一停就死寂；像电话断了 |

**N4 音色**（主：LTASS 偏差 = 候选与干净参考的长期平均谱在 100–300 / 300–500 / 2–5 k / 5–8 k Hz 四个频带的差（dB）的均方根；16 kHz 模型不算 8 k 以上；交叉 LUFS 差、人耳 `muffled`）

| 档 | 指标 〔建议值；目标音色见设计稿 §9：圆润 100–300 Hz、通透 2–5 kHz〕 | 听起来 |
|---|---|---|
| A | ≤ 1.5 dB | 和干净录音的音色一样 |
| B | ≤ 3 dB | 稍薄或稍闷 |
| C | ≤ 6 dB | 明显发闷 / 发尖 |
| D | > 6 dB | 像电话听筒或隔着被子 |

### 轻快

**L1 附加延迟 ③**（002 口径：管线直通 6–10 ms + 窗长 + 前瞻；取区间上沿）

| 档 | ③ | 依据 |
|---|---|---|
| A | ≤ 30 ms | 002 延迟档 1 |
| B | ≤ 45 ms | 档 2；单向总计约 145 ms，在 ITU-T G.114 的 150 ms 内 〔有出处〕 |
| C | ≤ 75 ms | 档 3；单向总计越过 G.114 |
| D | > 75 ms | 也是 V2 的候选线 |

**L2 最坏一帧**（合计 max ÷ 周期）：A ≤ 10% · B ≤ 20%（即 10 ms 帧 ≤ 2 ms，002 命门 1c）· C ≤ 50% · D 触发 V3。

**L3 耗电**（平均每帧耗时 ÷ 周期，单个性能核）：A ≤ 5% · B ≤ 10% · C ≤ 20%（005 拍板 #3 选项 A「一个核的约 1/5」）· D > 20% 〔建议值〕。能效核实测出来后改用实测 CPU%。

**L4 落地**（四项各记 ✅ / 部分 / ❌：许可清晰兼容 · Rust 逐帧现成 · 近一年有维护 · 采样率 ≥ 16 kHz 且与 engine 一致）：A 四项 ✅ · B 一项部分 · C 两项以上部分 · D 任一 ❌（V4 / V5 已否决的不会走到这里）。

## 4. 人耳维度：作者一个人、约 10 分钟

### 4.1 流程（与 exp003 AB 页对齐，页面由 abtest 实现）

| 步 | 做什么 | 为什么 |
|---|---|---|
| 准备 | 固定耳机（建议有线、同一副）、固定音量，安静房间；**听之前不看任何分数**；开始前随便听 1 段原声定音量，不计分 | 防先入为主；音量变了尺度就漂 |
| 主体 | 每段一屏：A / B / C（候选数从 manifest 读）+ 原声，可随时切换、循环；每个候选都听过才能答 | 隐藏身份；原声当参照（MUSHRA 的「参照」思路，简化） |
| 每段问 | ① 哪个最**清楚**（或差不多）② 哪个最**自然**（或差不多）③ 哪几个**吃字**（多选或都没有）④ 每个候选「**拿去开会**：能用 / 勉强 / 不能用」⑤ 可选缺陷标签 | ①② 排序；③ 对 C1；④ 绝对锚，给 V8；⑤ 对 N2 / N3 / N4 |
| 量 | 12 段 + 2 道陷阱 ≈ 14 屏，每屏 40 s 左右 ≈ 10 分钟 | 产品派约束 |
| 防疲劳 | 第 7 屏后页面提示可以停 1 分钟；单次不超过 15 分钟；不重听已答的段 | |
| 顺序 | 片段顺序随机；候选在槽位上按拉丁方轮换（每个模型在每个位置次数平衡） | 位置效应 |
| 陷阱 | `trap-identical`（同一文件，应答「差不多」）· `trap-degraded`（低通 1 kHz + 白噪劣化版，应选原样那份） | 查「有没有认真听」 |
| 揭盲 | 导出 JSON 之后才揭盲 | |

### 4.2 会话有效性

| 陷阱结果 | 判定 | 后果 |
|---|---|---|
| 两道都过 | **有效** | 人耳分全额 |
| 只错 `trap-identical`（听出了不存在的差别） | **打折** | ①② 的偏好只取「显著」的（4.3），「倾向」不算；③④ 照用 |
| 错 `trap-degraded` | **作废** | 换一天重听；本次只留备注 |
| 另：平均每屏 < 15 s 或某屏有候选播放 0 次 | 该屏作废 | 不计入 |

### 4.3 人耳四项怎么算

记非陷阱、未作废的段数为 n，每个候选：

| 项 | 怎么算 | 档（A / B / C / D） |
|---|---|---|
| **H1 清楚** | 成对胜负：一段里被选「最清楚」的候选算赢其余候选，「差不多」不计。两两之间做符号检验 | 对每个对手都**显著**赢 A · 至少**倾向**赢、没有显著输 B · 互有胜负 C · 被某个对手显著赢 D |
| **H2 自然** | 同 H1，用「最自然」 | 同上 |
| **H3 可用** | 能用 = 2、勉强 = 1、不能用 = 0，取平均 u | u ≥ 1.6 A · ≥ 1.2 B · ≥ 0.8 C · 更低 D（且看 V8） |
| **H4 吃字** | 被勾「吃字」的段占比 e | e ≤ 5% A · ≤ 15% B · ≤ 30% C · 更高 D |

**显著 / 倾向**（单侧符号检验，平局剔除；数已本机复算，见 `docs/research/007_denoise-rubric/must-know.md` 第 1–2 条）：去掉「差不多」后剩 m 段，赢 k 段。

| m | 两个候选（α = 0.05） | 三个候选两两比（Bonferroni，α = 0.05/3） |
|---|---|---|
| 12 | k ≥ 10 | k ≥ 11 |
| 10 | k ≥ 9 | k ≥ 9 |
| 8 | k ≥ 7 | 必须 8:0 |
| 6 | 必须 6:0 | 怎么赢都不够 |

**k > m/2 但不到显著线 = 倾向**。一个人一轮 12 段，多数比较只能到「倾向」——这是单人听评的天花板，不要把倾向写成结论。要分出接近的两家（真实偏好约 80%），检验力到 0.8 需要**每对累计约 18 段**，也就是隔天再听一轮（must-know 第 2 条）。结论只对作者这双耳朵、这批片段成立（BS.1534-3 §4.2）。

人耳分 H = (H1 × 30 + H2 × 25 + H3 × 30 + H4 × 15) ÷ 3 〔建议值〕，0–100。

## 5. 总分与排名

1. **过否决**（第 2 节）。不过的直接「不入围」，写原因
2. **机器分 M**（0–100）= Σ 维度得分；缺数据的维度不计入分母，按剩余权重归一，并在结果里列「缺 X、Y」。**缺的权重超过 30 分时 M 只报不排**
3. **人耳分 H**（0–100）：有有效会话才有
4. **合成**：
   - 有有效 H：**总分 = 0.6 × H + 0.4 × M** 〔建议值；依据：真相源权重人耳 AB（第 2 位）高于专项指标（第 3 位）和 MOS（第 4 位）〕
   - 没有 H：总分 = M，结论一律标「待听」
5. **入围线**（「至少一把变好、另两把不变差」的 rubric 版）：清楚、自然、轻快**每把尺子的得分率都 ≥ 50%**（即平均在 B 与 C 之间以上），且总分 ≥ 60 → **能用**；总分 ≥ 75 且没有维度落 D → **首选**；其余 → **只作参照**
6. **同分或差 < 5 分**：按真相源顺序比——先比 H3 可用，再比 C1 吃字，再比 L1 延迟

## 6. 人耳和机器打架时怎么判

总原则（`.42cog/intent.md`「真相源与权重」）：真会议听感 > 人耳 AB > 专项指标（吃字率、延迟 p99.9、掉帧）> 无参考 MOS > 论文分数。但**延迟、耗时、许可、因果是物理事实，不是「听感」**，人耳不能推翻（V1–V6）。

| 冲突 | 裁决 | 记录 |
|---|---|---|
| ASR 说更吃字（C1 低），作者说没吃（H4 好） | 定向复核 5 句（第 2 节 V7 复核）；作者确认没吃 → 以人耳为准，C1 按 B 计 | 记一条「ASR 假报」，攒到 10 条后看 Qwen3-ASR 在伪影上的偏差 |
| ASR 说没吃，作者勾了吃字 | **以人耳为准**，C1 降到 C；把这些段的 ASR 转写对一遍，看是不是脑补（Δins） | 记一条「ASR 漏报」；漏报比假报更危险（意向书：从不吃字） |
| MOS 高（N1 A）、作者说不自然（H2 C/D 或 N2 标签多） | 以人耳为准，N1 按 C 计（硬规则 2） | 记「MOS 被讨好」，该 MOS 在这类模型上降权 |
| 压噪强（C2 A）、作者说背景忽大忽小或真空（`pumping_bg` / `vacuum`） | N3 取机器与人耳中较差的那一档 | |
| 机器总分排序与人耳排序相反 | 人耳排序为准，**前提是至少一对达到「显著」**；只有「倾向」时两者都不作结论，挑矛盾最大的 4 段补听一轮 | |
| 两个人耳项打架（更清楚选 X、能用选 Y 更高） | 不合并，在结果里两项都写；选型时按「清楚 > 自然」（意向书「从不吃字」优先） | |

**校准飞轮**（004「仍未补齐的缺口」）：每轮 AB 后，把每个机器维度的排序与人耳排序对比，记一致 / 不一致。攒到 20–30 对后，一致率 < 60% 的机器维度权重减半，并在本文提交记录里写明。

## 8. 写成脚本的规格

### 8.1 候选登记表（每个候选一份，`candidate.json`，AI 查文档填，人可改）

```json
{"id": "dpdfnet2", "name": "DPDFNet-2 16k",
 "causal": true, "lookahead_ms": 40, "window_ms": 20, "hop_ms": 10,
 "latency_e2e_ms": [66, 70],
 "frame_ms": {"period": 10, "p999": 0.84, "max": 0.89, "mean": 0.75, "source": "exp001"},
 "license": {"code": "Apache-2.0", "weights": "Apache-2.0", "status": "ok|pending|incompatible", "source": "..."},
 "rust_frame": "native|onnx_explicit_state|no",
 "maintained_within_12mo": true, "sample_rate": 16000}
```

### 8.2 输入与输出

- 机器打分：exp003 `scores.json`（`per_clip[clip][version]`：`SIG`/`BAK`/`OVRL`/`ESTOI`/`SI_SDR_dB`/`noise_att_db`/`resid_rel_db`/`del_rate`/`sub_rate`/`ins_rate`，`version` 含 `noisy` 即原声直通）。SCOREQ、语音帧能量损失、词首损失、N3 波动、LTASS、IRL 现在**还没有**，见 `gap.md`
- 人耳：AB 页导出（abtest 定稿字段：`answer.usable{A,B,C}` · `answer.tags{A,B,C}` · `answer.eaten` · `plays{A,B,C,ref}` · `switches` · `started_at` · `answered_at`；揭盲后 `by_model.*`）
- 输出 `rubric_result.json`：每个候选 `{veto: [...], dims: {C1: {grade, value, flags}}, M, H, H_validity, total, verdict, missing: [...], conflicts: [...]}`

### 8.3 算法骨架

```
for cand in candidates:
    veto = check_V1..V6(candidate.json, logs)
    veto += check_V7(scores, paired_bootstrap(n=10000, ci=0.95), min_sentences=30)
    session = validate(ab_export)            # 有效 / 打折 / 作废（4.2）
    veto += check_V8(session, cand)
    if veto: verdict = 不入围; continue
    for dim in DIMS: grade[dim] = anchor_table[dim](metric_by_group, worst_group_rule)
    apply_hard_rules(grade)                  # 过度抑制 / MOS 被讨好 / 矛盾
    M = weighted(grade, available_only=True)
    H = human_score(session, cand) if session != 作废 else None
    total = 0.6*H + 0.4*M if H else M
    verdict = 首选 | 能用 | 只作参照 | 待听
```

**自检**：第 7 节的三种人为劣化必须排在原输出之后；`trap-degraded` 的劣化版在机器分上必须低于原样版。任何一条不成立，说明锚点或权重有错，先修 rubric 再打分。
