# 降噪 rubric：一个降噪实现能不能用、排第几

> 规约 · 被路径引用，不编号、不带日期，版本走提交链。起草：手下 rubric（2026-10-30，批次 20261030-b2），已过三视角自审（怀疑派 · 实现派 · 产品派）并修改。
> 依据：`docs/research/007_denoise-rubric/`（must-know · sources · gap）。用它打分：同目录 `decision.md`。
> **标 〔建议值〕 的数字是 AI 估的、没有出处，人没拍板前一律「暂定」**（`decision.md` 末节）；标 〔有出处〕 / 〔类比〕 的给了来源。

## 0. 怎么用

拿到一个候选（模型 + 推理代码），按顺序走四关：

| 关 | 判什么 | 谁判 | 输入 | 结果 |
|---|---|---|---|---|
| **一 否决** | 有没有一票否决项（第 2 节） | 脚本 + AI 查文档 | 候选登记表（8.1）· 机器打分 · AB 导出 | 不入围 / 疑似（必听）/ 过 |
| **二 机器分** | 12 个机器维度各落哪一档（第 3 节） | 脚本 | eval 输出（现在是 exp003 `scores.json`） | 机器分 M（0–100）+ 缺哪些 |
| **三 人耳分** | 作者盲听的 5 项（第 4 节） | 人答、脚本算 | AB 页导出 JSON | 人耳分 H（0–100）+ 有效 / 打折 / 作废 |
| **四 裁决** | 合成排名，处理打架（第 5、6 节） | 脚本按规则 + 人复核必听段 | 上面三关 | 首选 / 能用 / 只作参照，另标是否「待听」 |

这是 CLAUDE.md 第三节「三层验证」的中间层：规则判（脚本）→ **判据判（本文）** → 实效判（作者听、真会议用）。真实会议里对方的感受永远在 rubric 之上（`.42cog/intent.md`「真相源与权重」第 1 位）。

### 0.1 小词表

| 词 | 意思 |
|---|---|
| 原声直通 | 不降噪，只过同样的延迟与重采样；所有「比原声好 / 坏」都以它为基准（scores.json 里的 `noisy` 列） |
| 吃字率 / Δdel | ASR 转写比干净参考少掉的字（词）占比；Δdel = 候选 − 原声直通，单位百分点 |
| ESTOI | 有参考的可懂度指标，0–1，越高越好 |
| 无参考 MOS | 不看参考、只听输出就估「好不好听」的模型分（SCOREQ、UTMOS、DNSMOS）；只作筛选 |
| ③ 端到端附加延迟 | 降噪给通话多加的延迟 = 管线直通 6–10 ms + 窗长 + 前瞻（002 口径） |
| 显著 / 倾向 | 人耳偏好过了统计门槛 = 显著（可以下结论）；赢得多但没过 = 倾向（不能下结论） |
| 必听段 | 机器发现可疑、要作者对照原声和参考文字逐字听的片段 |

### 0.2 场景组

机器指标先按场景组算再汇总。exp003 按片段 id 写死（`make_clips.py` 的 `category` 字段只作核对；G4 按 `lang == "zh"`）：

| 组 | exp003 片段 | 为什么单列 |
|---|---|---|
| G1 非人声噪音 | c09 杯碟 · c10 背景音乐 | 通用模型的本职；**压噪（C2）只在这一组算**（见 C2） |
| G2 单个干扰说话人 | c04 · c05 · c12 | 意向书「真难题」1；个性化（PSE）主战场 |
| G3 多人 babble | c01–c03 · c06–c08 · c11 | 咖啡馆主场景 |
| G4 中文 | c11 · c12 | 中文按字算；与 G2/G3 重叠，**只参与「最差组」比较，不进均值** |

### 0.3 通用落档规则（脚本照此实现，顺序固定）

1. **组内落档**：每个维度先在每组上算指标值（组内合并方式见各维度），再按锚点表落档。**从 D 往 A 判，先命中的生效**；A 档还必须同时满足 B 档的条件
2. **组间汇总**：吃字类（C1）取最差组。其余维度：G1–G3 的指标值不加权平均后落档（「均值档」）；若某组（含 G4）的档比均值档低 ≥ 2 档，整维降一档
3. 依次套硬规则 4 → 2 → 5 → 3（第 1 节）
4. 有人耳数据时，套第 6 节的人耳覆盖
5. 每一步改了档就在结果里记一条 `flags`（谁改的、从几档到几档）

| **自然** 35 | N1 整体听感 | SCOREQ natural NR | UTMOS | 8 |

| | N4 音色 | LTASS 分频带偏差 | LUFS 差 | 8 |
| **轻快** 25 | L1 附加延迟 | ③ | 互相关实测 | 9 |

| | L4 落地 | 许可 · Rust 逐帧 · 维护 · 采样率 | — | 5 |

人耳的缺陷标签只进人耳分（H5），不进机器分，避免同一份数据算两次。

**硬规则**（防讨好；依据见 `must-know.md` 第 12–15 条）：

1. **封顶**：任何单一指标在总分里 ≤ 18 分；无参考 MOS（SCOREQ / UTMOS）合计 ≤ 8 分 〔建议值；调研建议 ≤ 20%〕
2. **制衡对**：C2 拿 A、而 C1 或 C3 落 C 或 D → 记「过度抑制」，C2 改为 C。N1 拿 A、而人耳 H5 落 C 或 D → N1 改为 C（MOS 被讨好）
3. **矛盾**：下列主 / 交叉指标方向相反且超过差值线 → 该维度取两者中较差的一档，标「矛盾」，相关片段列入必听段：C3「能量损失 ≤ 1 dB」而「ΔESTOI < −0.05」· N1「SCOREQ 比原声高 ≥ 0.3」而「UTMOS 比原声低 ≥ 0.3」（或反过来）· C2「`noise_att_db` ≤ −12」而「`resid_rel_db` 比原声高」 〔差值线为建议值〕
4. **好输入不许修坏**：最高 SNR 片段（exp003 c08，10 dB）上，候选删除数 > 原声直通，或 ESTOI 比原声低 > 0.02 → C1、C3 各降一档 〔0.02 为建议值；依据：AATC 2025 基线把高 SNR 输入 WAcc 0.989 拉到 0.929，arXiv 2509.12974 §D〕
5. **疑似重合成 / 伤人声**：任一片段 DNSMOS OVRL 比原声高、而 ESTOI 比原声低 > 0.05 → 该片段列入必听段，C3 不得高于 C 〔0.05 为建议值；信号依据 arXiv 2507.11306 §4.2〕
6. **DNSMOS 只报警**：SIG / OVRL 不计分（只用于第 5 条触发），BAK 只作 C2 旁证。依据：被当训练目标时「指标最好、听测最差」（arXiv 2402.01413 §6.2.5）；在 hybrid 系统上与 MOS 反向（arXiv 2509.12974，仅 4 个点）

**响度**：所有给人听的音频与 N4 都先做响度对齐（exp003 已统一到 −26 LUFS）；C3 的能量损失在**未对齐**的输出上算，但**增益为正（输出比参考更响）时记 0 dB**，整体调大音量拿不到分。

## 2. 一票否决项

| # | 否决项 | 判法 | 数据 | 类 |
|---|---|---|---|---|
| V1 | **非因果** | 需要超过声明前瞻的未来样本，或需整句输入；流式逐帧与整段跑的输出差 > −60 dB（相对输出能量）即可疑 | 代码 · 论文 · 对拍 | 硬事实 |
| V2 | **③ 超上限** | 上限**待 D01 拍板：45 ms 或 75 ms** | 002 延迟表；M0 实测后更新 | 硬事实 |
| V3 | **最坏一帧 > 周期一半** | exp001 口径（M5 单线程，模型 + STFT 合计 max）〔类比：DNS 2023 / AEC 2023 实时赛道「单线程 RTF ≤ 0.5」，那是**平均**，我们用最坏一帧，更严〕 | exp001 / 同法实测 | 硬事实 |
| V4 | **许可不兼容** | 代码或权重与 GPL-3.0 不兼容（NC、禁止再分发）。**「不明」不否决，记「挂起」**：能评测，不能进发布 | LICENSE · 模型卡 · issue | 硬事实 |
| V5 | **不能 Rust 逐帧** | 既非 Rust 原生，也没有状态显式的单帧 ONNX（或可导出成这样） | 002 命门 3 | 硬事实 |
| V6 | **数值失效** | 在 wav 层查：NaN / Inf；整段输出比输入低 40 dB 以上（含语音段，不同于 N3 的「真空」）；掉帧 > 0 | 推理日志 · wav | 硬事实 |
| V7 | **比原声更吃字** | 见下 | scores.json | 可复核 |
| V8 | **人耳判不能用** | 有效会话里，≥ 1/3 的非陷阱屏被选 `no`（不能用）〔建议值〕 | AB 导出 | 可复核：隔天再听一轮可撤销 |

**V7 的算法**（每个场景组分别算）：

- 统计量：**合并删除率差** Δdel = (Σ 候选删除数 − Σ 原声删除数) ÷ Σ 参考字（词）数 × 100，单位百分点。`asr_stable = false` 的片段剔除，记 flag
- 置信区间：**按片段**配对重采样 10000 次，种子 20261030，取 2.5% / 97.5% 分位
- **片段数 ≥ 30**：Δdel > +1 〔D10 已拍板试跑值〕且 95% 区间下界 > 0 → **否决**
- **片段数 < 30**（exp003 每组 2–7 段，永远在这里）：不否决，按点估计落 C1 档；Δdel > +1 → 记 `v7_suspect`，该组 Δ 最大的片段列入必听段

**撤销**（V7、V8 都是「可复核」）：作者**对照参考文字和原声**逐字听必听段，判「没吃」≥ 4/5 → 撤销，C1 最高给 C（不给 B），记「ASR 假报」。必须逐字对照：URGENT 2025 的 T13 主观第 1、总名次第 13，不看参考的听感罚不到「内容说错」（arXiv 2505.23212 §4.3）。

## 3. 机器维度：四档锚点

A 好 = 3 分 · B 可用 = 2 · C 勉强 = 1 · D 不可用 = 0；维度得分 = 档分 ÷ 3 × 权重。阈值除特别注明外都是 〔建议值〕。

### 清楚

**C1 吃字**（组内：合并 Δdel；组间：取最差组）

| 档 | 指标 | 听起来 |
|---|---|---|
| D | Δdel > +3；或片段数 ≥ 30 时触发 V7 | 句子里有字被抹掉、句尾被截 |
| C | 0 < Δdel ≤ +3（> +1 时带 `v7_suspect`） | 偶尔一个字发虚，要回放才确定 |
| B | −2 < Δdel ≤ 0；或 Δdel ≤ −2 但片段数 < 30 | 和原声一样能听全 |
| A | Δdel ≤ −2，片段数 ≥ 30，且 95% 区间上界 < 0 | 原声里被噪音盖住的字，处理后听得出来 |

Δins（脑补率差）> +1 → 标「ASR 可能脑补或漏进旁人的话」，C1 不得升档，相关片段进必听段。

**C2 压噪**（只用 G1；G2/G3 的非语音段里有干扰人声，要等三轨分存的合成集才能拆出非人声部分，在那之前记「缺」）

| 档 | G1 `noise_att_db` 均值 〔依据：设计稿 §5 衰减下限 12–20 dB〕 | 听起来 |
|---|---|---|
| D | > −6 dB | 跟原声差不多 |
| C | −12 < x ≤ −6 | 背景小了一些 |
| B | −20 < x ≤ −12 | 背景明显变小，仍听得出环境 |
| A | ≤ −20 dB | 停顿时几乎听不到背景 |

压到 −40 dB 以下不再加分，而是触发 N3 的「真空」（见 N3）。

**C3 人声损伤**（组内：语音帧能量损失 = 10·log10(候选 ÷ 干净参考)，只在参考有声帧上算，对齐后；ΔESTOI = 候选 − 原声，片段均值）

| 档 | 指标 | 听起来 |
|---|---|---|
| D | 损失 > 4 dB，或 ΔESTOI < −0.05 | 人声被一起压下去，像隔着墙 |
| C | 损失 > 2 dB，或 ΔESTOI < 0 | 人声变小、变远，句尾变弱 |
| B | 损失 ≤ 2 dB 且 ΔESTOI ≥ 0 | 人声略薄，但不费劲 |
| A | 损失 ≤ 1 dB 且 ΔESTOI ≥ +0.05 | 人声饱满 |

能量损失缺失时只按 ΔESTOI 落档，最高给 B。**词首**：用干净参考按 score.py 的 VAD（20 ms 帧、−35 dB 门限）找每段有声起点，取起点后 50 ms 的能量损失；比全有声帧平均损失多 3 dB 以上 → 标「吞字头」，C3 降一档。

**C4 干扰者残留**（只在 G2 / G3；IRL = 「只有干扰者在说」的段上 10·log10(输出能量 ÷ 输入干扰能量)，005 口径）

| 档 | IRL 〔C/D 分界取 005 第 1 步失败线「改善 < 6 dB」〕 | 听起来 |
|---|---|---|
| D | > −6 dB | 邻桌和原来一样 |
| C | −10 < x ≤ −6 | 邻桌小了点，内容仍可辨 |
| B | −15 < x ≤ −10 | 邻桌在，但比你小很多 |
| A | ≤ −15 dB | 邻桌只剩模糊的底 |

通用模型在这一维落 C / D 是预期的（002 decision），不否决，也不影响「首选」（第 5 节）。

### 自然

**N1 整体听感**（SCOREQ，片段均值；与原声、干净参考同指标比）

| 档 | 指标 |
|---|---|
| D | 候选 < 原声 |
| C | 原声 ≤ 候选 < 原声 + 0.5 |
| B | 候选 ≥ 原声 + 0.5 |
| A | 满足 B，且候选 ≥ 干净参考 − 0.3，且 UTMOS 同向（也比原声高） |

**没有 SCOREQ 就记「缺」**（UTMOS 在真实录音 CHiME-7 上逐句 SRCC 0.33，SCOREQ 0.75，arXiv 2601.18438 表 10；DNSMOS 按硬规则 6 不进 N1）。

**N2 分项伪影**（NISQA DIS 与 COL 取较低者，片段均值；NISQA 是用户自装，D20）：D < 2.5 · C < 3.0 · B < 3.5 · A ≥ 3.5。没装就记「缺」。NISQA DIS 与人耳在模型层面只有 0.31（arXiv 2303.06566 Table 13），所以权重给了但常缺，伪影主要靠人耳 H5。

**N3 背景稳定**（非语音段：干净参考 VAD 判为无声的帧；把各片段的非语音段拼起来算，每段只有约 1.5 s）

- 电平序列：100 ms 不重叠窗的 RMS（dB）
- σ = 序列标准差；跳变 = 相邻两窗差 > 6 dB 的次数，连续的算一次；按每 10 s 非语音折算
- **真空**：G1 的 `noise_att_db` ≤ −40 dB（停顿处比原声底噪低 40 dB 以上）

| 档 | 指标 | 听起来 |
|---|---|---|
| D | 真空；或 σ > 原声 σ + 5 dB | 停顿处死寂像断线；或背景一说话就出现、一停就消失 |
| C | σ ≤ 原声 σ + 5 dB，跳变 > 原声 + 2 | 每次停顿背景先没了再涌回来（抽吸） |
| B | σ ≤ 原声 σ + 3 dB，跳变 ≤ 原声 + 2 | 偶尔一下背景「吸」上来 |
| A | σ ≤ 原声 σ + 1 dB，跳变 ≤ 原声 | 背景像原声一样平稳，只是更小 |

σ 与跳变缺失时：命中「真空」就记 D，否则记「缺」。

**N4 音色**（只用参考有声帧；先把候选与干净参考的有声段整体电平对齐，只比形状；16 kHz：1024 点 Hann、跳 512；四个频带 100–300 / 300–500 / 2–5 k / 5–8 kHz 的平均功率差（dB）取均方根）：D > 6 · C ≤ 6 · B ≤ 3 · A ≤ 1.5（目标音色见设计稿 §9）。

### 轻快

| 维度 | D | C | B | A |
|---|---|---|---|---|
| **L1** ③ 取区间上沿 | > 75 ms | ≤ 75 ms（档 3；单向总计约 170 ms，推算，越过 G.114 的 150 ms） | ≤ 45 ms（档 2；单向约 145 ms，推算，在 G.114 内） | ≤ 30 ms（档 1） |

## 4. 人耳维度：作者一个人

### 4.1 流程（与 exp003 AB 页对齐，页面由 abtest 实现）

| 步 | 做什么 | 依据 |
|---|---|---|
| 准备 | 同一副耳机（建议有线）、固定音量、安静房间；**听之前不看任何分数、不看 `decision.md` 的预演**；先随便听 1 段原声定音量，不计分 | 防先入为主 |
| 每屏 | 原声 + A / B / C（候选数从 manifest 读），可随时切换、循环；切换时约 5 ms 淡出 / 淡入，不交叉淡变；每个候选都听过才能答 | BS.1534-3 §5.3 |
| 每屏问 | 「最清楚」「最自然」各选一个或「差不多」（两问上下顺序每屏随机，导出 `qorder`）· 哪几个吃字（多选或都没有）· 每个候选「拿去开会：能用 / 勉强 / 不能用」· 可选缺陷标签 | P.835 维度顺序随机 |
| 量 | 12 段 + 2 道陷阱 = 14 屏；片段 ≤ 12 s | BS.1534-3 §5.1 |
| 时长 | 一屏 = 原声 + 候选数路，每路约 10 s，判吃字常要听两遍，加上点选：3 路约 80–100 s，**exp003 现为 5 路（4 个候选）约 100–120 s，14 屏约 25 分钟**，超过「约 10 分钟」的目标，见 `decision.md` 待人拍板 #4 | P.800 B.3：会话最好 ≤ 20 分钟 |
| 防疲劳 | 第 7 屏后提示可停 1 分钟；单次 ≤ 20 分钟 | P.800 B.3 |
| 顺序 | 片段顺序随机；候选槽位按拉丁方轮换（abtest 定稿版；若页面实际是随机打乱，结果里记录实际分配） | P.800 E.5 |

| 揭盲 | 导出 JSON 之后 | |

### 4.2 有效性

| 情况 | 判定 | 后果 |
|---|---|---|
| 两道陷阱都过 | 有效 | 全额 |
| 只错 `trap-identical` | 打折 | H1 / H2 只认「显著」，「倾向」按平计；H3–H5 照用 |
| 错 `trap-degraded`（含劣化版被判 `ok`） | 作废 | 换一天重听 |
| 单屏 `answered_at − started_at` < 15 s，或某候选 `plays[槽位] == 0` | 该屏作废 | 不计入 n（注意 `answered_at` 是最后一次改答案的时间） |

n = 有效会话里、非陷阱、非自录（`kind == "self"`）、非重测重复、未作废的屏数。

### 4.3 五项怎么算

**成对胜负**（H1、H2）：一屏里被选为「最 X」的候选，对同屏每个其他候选各记 1 胜；没被选的两个候选之间**无信息**（不算平、不进 m）；「差不多」= 同屏所有候选两两平（不进 m）。所以每一对的 m 各不相同。

**显著 / 倾向**：对每一对，m = 该对的有效胜负数，k = 胜数；`binom.sf(k−1, m, 0.5) ≤ α` 为显著，α = 0.05（两个候选）或 0.05 / 3（三个候选两两比，Bonferroni）。**脚本用公式判，不查表**；下表只供人读（本机复算）：

| m | 两个候选 | 三个候选 |
|---|---|---|
| 12 | k ≥ 10 | k ≥ 11 |
| 10 | k ≥ 9 | k ≥ 9 |
| 8 | k ≥ 7 | 8:0 |
| 6 | 6:0 | 6:0 |

k > m/2 但不显著 = 倾向。每对结果 ∈ {显著赢, 倾向赢, 平, 倾向输, 显著输}。一个人一轮多数只到「倾向」；分出接近的两家要每对累计约 18 段（must-know 第 2 条）。结论只对作者这双耳朵、这批片段成立（BS.1534-3 §4.2）。

| 项 | 怎么算 | D | C | B | A |
|---|---|---|---|---|---|
| **H1 清楚** | 成对胜负（「最清楚」） | 有任一对显著输 | 其余情况 | 每对都至少倾向赢 | 每对都显著赢 |
| **H2 自然** | 同上（「最自然」） | 同上 | | | |
| **H3 可用** | `ok` = 2、`marginal` = 1、`no` = 0，平均 u | u < 0.8 | ≥ 0.8 | ≥ 1.2 | ≥ 1.6 |
| **H4 吃字** | 被勾吃字的屏占比 e | > 30% | ≤ 30% | ≤ 15% | ≤ 5% |
| **H5 伪影** | 被打 `metallic` / `clipped_onsets` / `pumping_voice` / `pumping_bg` / `vacuum` / `muffled` 任一标签的屏占比 t | > 50% | > 25% | ≤ 25% | — |

H5 没有 A 档：标签是可选的，「没勾」不等于「没有」，只能当扣分证据。

**人耳分** H = (H1 × 25 + H2 × 20 + H3 × 30 + H4 × 15 + H5 × 10) ÷ 3，0–100 〔建议值〕。

## 5. 总分与排名

1. **否决**：不过的「不入围」，写原因；`v7_suspect` 不是否决，但该候选在必听段听完前标「待听」
2. **机器分 M** = Σ 维度得分 ÷ 可用维度权重和 × 100。**缺失的权重 > 30 分时 M 只报不排**；「矛盾」维度按较差档计入，不算缺失
3. **人耳分 H**：有效或打折会话才有
4. **合成**：有 H 时 **总分 = 0.6 × H + 0.4 × M**（M 只报不排时，排名只用 H，M 只作旁注）〔建议值；依据真相源顺序。比赛三种做法见 must-know 第 11 条〕；没有 H 时只有 M，结论一律「待听」
5. **入围**（「至少一把变好、另两把不变差」的 rubric 版）：三把尺子各自的得分率（该尺子已有维度得分 ÷ 已有维度权重）都 ≥ 50%，C2 在套硬规则**之前**的档 ≥ B（真降了噪；过度抑制已由硬规则 2 扣过，不重复扣），且总分 ≥ 60 → **能用**；在此基础上总分 ≥ 75、除 C4 外没有维度落 D → **首选**；其余 → **只作参照** 〔50% / 60 / 75 均为建议值〕
6. **相邻名次差 < 5 分**（只比相邻两名）：按 H3 可用 → C1 吃字 → L1 延迟依次比 〔5 分为建议值〕

**防过拟合**：阈值在作者揭盲前冻结（记 rubric 的提交号）；揭盲后的校准（第 6 节）只用于**下一轮**新片段，不回头改本轮结论。

## 6. 人耳和机器打架时

总原则：真会议听感 > 人耳 AB > 专项指标 > 无参考 MOS > 论文分数（`.42cog/intent.md`）。**人耳只能改「清楚」「自然」两把尺子；延迟、耗时、许可、因果是物理事实，人耳推翻不了**（V1–V6、L1–L4）。

| 冲突 | 裁决 |
|---|---|
| ASR 说吃字（C1 低 / `v7_suspect`），作者逐字听说没吃 | 第 2 节撤销规则：C1 最高给 C，记「ASR 假报」 |
| ASR 说没吃，作者勾了吃字（H4 差） | **以人耳为准**，C1 降到 C；核对 Δins 看是不是脑补。记「ASR 漏报」——漏报比假报危险（意向书：从不吃字） |
| MOS 高，人耳说不自然（H2 或 H5 落 C/D） | 硬规则 2：N1 改为 C；该 MOS 在这类模型上降权 |
| 压噪强，人耳标了 `pumping_bg` / `vacuum` | N3 取机器与人耳中较差的一档（被标的屏占比 > 25% 记 C，> 50% 记 D） |
| 机器与人耳在「清楚 + 自然」上的排序相反 | 至少一对达到「显著」→ 以人耳为准；只有「倾向」→ 两者都不作结论，挑矛盾最大的 4 段补听一轮 |
| 两个人耳项打架（更清楚选 X，能用 Y 更高） | 都写进结果；选型按「清楚 > 自然」（从不吃字优先） |

**校准飞轮**（004「仍未补齐的缺口」）：每轮把每个机器维度的排序与人耳排序比一致 / 不一致，攒到 20–30 对后一致率 < 60% 的维度权重减半，写进本文提交记录 〔数字为建议值〕。

## 8. 写成脚本的规格

### 8.1 候选登记表 `candidate.json`（AI 查文档填，人可改）

`id` 必须与 scores.json 的版本键、AB 导出 `by_model` 的键是**同一个字符串**。

```json
{"id": "dpdfnet2", "name": "DPDFNet-2 16k",
 "causal": true, "stream_vs_offline_db": null, "lookahead_ms": 40, "window_ms": 20, "hop_ms": 10,
 "latency_e2e_ms": [66, 70],
 "frame_ms": {"period": 10, "p999": 0.84, "max": 0.89, "mean": 0.746, "source": "exp001"},
 "dropped_frames": 0,
 "license": {"code": "Apache-2.0", "weights": "Apache-2.0", "status": "ok|pending|incompatible", "source": "..."},
 "rust_frame": "native|onnx_explicit_state_shell_needed|exportable|no",
 "maintenance": "ok|partial|no", "sample_rate": 16000, "engine_sample_rate": 16000}
```

L4 映射：`rust_frame` 为 `native` → ✅，`onnx_explicit_state_shell_needed` / `exportable` → 部分；`maintenance` 直接对应。

### 8.2 输入与输出

- **机器打分**：scores.json，`per_clip[clip][version]` 含 `SIG` `BAK` `OVRL` `ESTOI` `SI_SDR_dB` `noise_att_db` `resid_rel_db` `asr_stable` `ref_len` `del` `sub` `ins` `del_rate` `sub_rate` `ins_rate`；`version` 含 `noisy`。现在**没有**：SCOREQ、UTMOS、NISQA、语音帧能量损失、词首损失、N3 电平序列、LTASS、IRL（见 `gap.md`）
- **人耳**：AB 导出（abtest 定稿）。每屏 `answer.usable{A,B,C}`（值 `ok` / `marginal` / `no`）· `answer.tags{A,B,C}` · `answer.eaten`（槽位数组或 `["none"]`）· `plays{A,B,C,ref}` · `switches` · `started_at` · `answered_at` · `qorder`；揭盲后 `by_model.*`
- **输出** `rubric_result.json`：

```json
{"rubric_commit": "...", "inputs_sha256": {"scores": "...", "ab_export": "...", "candidates": "..."},
 "bootstrap_seed": 20261030, "session": {"build": "...", "validity": "valid|discounted|void", "reasons": []},
 "candidates": {"<id>": {
   "veto": [], "v7_suspect": false, "license_pending": false,
   "dims": {"C1": {"grade": "C", "value": 2.28, "by_group": {"G1": 0.0}, "flags": []}},
   "missing": [], "missing_weight": 0, "M": 0, "M_rankable": false,
   "human": {"H1": {"grade": "B", "pairs": {"<对手id>": {"k": 0, "m": 0, "result": "倾向赢"}}}},
   "H": null, "total": null,
   "verdict": "首选|能用|只作参照|不入围", "needs_listening": true, "must_listen": ["c11"]}}}
```

### 8.3 算法骨架

```
for cand in candidates:
    veto = check_V1_to_V6(candidate.json, wav_logs)
    v7 = pooled_delta_del(scores, cand, group, unit="clip", seed=20261030)   # 第 2 节
    veto += v7.veto_if_n_ge_30
    session = validate(ab_export)                     # 4.2
    if session is not None and session.validity != "void":
        veto += check_V8(session, cand)
    if veto: verdict = "不入围"; continue
    grade = {d: grade_by_group(d, scores, cand) for d in DIMS}   # 0.3 第 1–2 步
    apply_hard_rules(grade, order=[4, 2, 5, 3])                  # 0.3 第 3 步
    H = human_score(session, cand) if session is not None and session.validity != "void" else None
    apply_human_override(grade, H)                               # 第 6 节，只动清楚/自然
    M, missing_weight = weighted(grade, available_only=True)
    total = 0.6 * H + 0.4 * M if H is not None else M
    verdict = classify(total, grade)                             # 第 5 节
    needs_listening = H is None or bool(must_listen)
```

自检：第 7 节单元测试全过才输出结果。

## 附录 · 降噪听感缺陷词汇表

AB 页标签用括号里的英文键。「指标」一列：**机器判** = 有出处的指标能抓；**预警** = 自算量，阈值没校准，只能挑片段给人听；**只能靠耳朵** = 没有可靠自动指标。出处见 `docs/research/007_denoise-rubric/sources.md`。

| 缺陷 | 听起来 | 怎么听出来 | 指标 | 维度 |
|---|---|---|---|---|
| 吃字 | 字被抹掉、句尾被截 | 对照参考文字逐字听 | **机器判**：ASR 删除率；TSOS 过度抑制（arXiv 2110.09625） | C1 · V7 · H4 |
| 吞字头字尾（`clipped_onsets`） | 句首辅音、句尾轻声被削 | 只听每句首尾音节，和原声比 | 预警：词首 50 ms 能量损失 | C3 · H5 |
| 人声被压低 | 整体变小、变远 | AB 切换比音量 | **机器判**：语音帧能量损失、LUFS 差（NISQA LOUD 与人耳模型层面 0.78，arXiv 2303.06566） | C3 |
| 发闷（`muffled`） | 像捂着嘴，s / f / ch 没有空气感 | 听擦音 | 机器判（推断）：LTASS 高频段偏差 | N4 · H5 |
| 齿音丢失或刺耳 | s 被吃或变尖 | 听含 s / sh 的词 | 预警：LTASS 4–8 kHz 两个方向 | N4 |
| 音乐噪声 | 停顿里冒出随机「叮、啾」 | 只听停顿段 | 预警：峰度比（与感知弱相关，arXiv 2105.13079） | H5（标 `metallic`） |
| 金属声 / 机器人声（`metallic`） | 像隔着铁管说话 | 听长元音圆不圆 | **只能靠耳朵** | H5 |
| 颤音 | 「呜哇」抖动 | 听长元音与稳态背景 | **只能靠耳朵** | H5（写备注） |
| 抽吸（`pumping_bg`） | 一开口背景压下去、一停又涨回来 | 盯每句结束后 0.5 s 的背景 | 预警：N3 的 σ 与跳变 | N3 · H5 |
| 背景跳变 | 背景一档一档地跳 | 听非语音段连不连续 | 预警：N3 跳变（NISQA DIS 模型层面 0.31，不用） | N3 |
| 真空感（`vacuum`） | 停顿处死寂，像断线 | 听停顿 | 预警：G1 `noise_att_db` ≤ −40；**DNSMOS BAK 可能反而给高分** | N3 · H5 |
| 人声忽大忽小（`pumping_voice`） | 同一句话里音量被调制 | 对照原声听包络 | 预警：语音段包络比方差 | H5 |
| 残留 babble（可懂） | 停顿时还能听懂邻桌的话 | 停顿时去听旁人的词 | **机器判**：ASR 插入（arXiv 2303.11510 §4.3）；IRL | C4 |
| 混响被切 / 残留 | 句尾干涩，或含糊 | 听句尾 200 ms | 预警：句尾能量衰减斜率 | N4 |
| 爆音 / 咔嗒 | 短促「咔」、瞬间中断 | 全程留意 | **机器判**：样本一阶差分离群点、掉帧计数 | V6 |
| 幻觉 / 音色漂移 | 冒出原声里没有的音节，或换了个人 | 逐字对照、听是不是同一个人 | 预警：硬规则 5；常规非侵入指标常漏（arXiv 2601.12254） | 硬规则 5 |
| 笑声、附和声被吃 | 「嗯」「哈哈」没了，像你一直沉默 | 用含附和声的片段 | **只能靠耳朵**（现在没有测试片段，见 gap） | — |
